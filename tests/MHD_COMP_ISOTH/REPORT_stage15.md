## 1. 結論

事前に固定した規則による K の判定は、M_s = 1 で「差が決まらない」である。
H-256 は H(8)、H(32) とも完走しなかったので、細則どおり参照を ES-256 だけにし（4 組、3 組以上で読む）、判定に印を付けた。
参照が ES と同じ方式なので、この判定は ES に有利な側にずれうる。

- K（M_s = 1、128³）: ES の κ は 4 組中 3 組で 0.71–0.74（k_× = 30–32）で、B* = H(8) の 0.48–0.53 より 0.21–0.25 大きい。E_m の W2 では ES が 0.44、H(8) が 0.56 で、ES が小さい。参照に ES を使わない (64, 128) の自己収束でも、ES の κ は同じ 3 組で H(8) より大きく、E_m の W2 だけで小さい（6.2 節）。[3, 32] での |ln T| の平均 D は、4 組すべてで ES のほうが小さい。
- 閾値 δ は 0.65–0.85 で、各組の |κ_ES − κ_B*| の 3.4 倍以上ある。δ を決めた σ は、記録ごとのスペクトルを参照の窓平均と比べるので、窓の中の減衰を測ってしまった（6.1 節）。σ の項を除くと、ES が大きい組が 3、H(8) が大きい組が 1（E_m の W2）になるので、判定は変わらない。
- 費用対効果: 128³ の 2τ0 までの費用は ES が H(8) の 3.0 倍で、(k̄_ES/k̄_B*)⁴ = 2.44 を超える。事前の規則では費用対効果はない。
- C（完走）: M_s = 1 では、ES は同じ係数のまま 64³、128³、256³ で完走した。H が完走に要る r は 64³ で 2、128³ で 8 と上がり、256³ では r = 32 でも完走しなかった。L は 64³、128³ で梯子の最下段から完走したが、κ の平均は 0.13 以下で、ES（0.66）の 1/5 に満たない。R0 と ESf は止まった。ただし、標準の散逸はすべて ln ρ のフィルタ（filter_lnrho = T）付きで走らせたので、H の崩れとフィルタとは切り分けていない（5.4 節）。
- M_s = 0.5: 64³ と 128³ のすべての方式が完走した。(64, 128) の自己収束による参考の判定も「差が決まらない」だが、4 組すべてで H(1/4) の κ（上限で打ち切った 0.984 以上）が ES（0.69–0.72）より大きい。
- E（収支）: ES の恒等式の残差は 64³ と 128³ で 3.5e-14 以下（TOL_RES = 1e-10）で、本番の方式の回帰はない。

事前に決めた次の手の表では、「差が決まらない」ときは主張を頑健さと収支が閉じることに絞り、誌と構成を相談する。
次の段階として、H を filter_lnrho = F で走らせる対照と、時刻をそろえた σ による判定を提案する（12.2 節）。

## 2. 方法

### 2.1 依頼と問題の設定

論文化の相談で、方法論文を目指すなら ES-SVV に利点があるかを 3D で先に確かめるよう勧めた。
ユーザーの答えは「はい。おすすめの進め方で。」で、計画（比べる方式、量、判定の規則、止める規則、費用）を承認した。
判定の規則と細則は、ジョブを投げる前、数値を見る前に `tasks/todo.md` の Stage 15 の節に書いて固定した。

問題は Stage 6 の 3D 減衰乱流で、初期条件の生成器と seed も Stage 6 と同じである。
B0 = 1、c_s = 1 とし、turb1 は速度と磁場の揺らぎの rms を (1, 1) にとる（M_s = 1）。
新しく足した turb05 は、turb1 の m と δB を 0.5 倍したもの（M_s = 0.5）である。
共通の設定は、C_shock = 2、C_η = 0、reset_method = 'track'、t_end = 2τ0（τ0 = π/M_s）、out3d は 0.125τ0 ごと、budget あり、強制なしである。

### 2.2 比べる方式と散逸の強さ r

| 記号 | 設定 | 役割 |
|---|---|---|
| ES | svv_eps0 = 0.5（既定）、filter_lnrho = F | 本番の方式 |
| ESf | ES に filter_lnrho = T を足す | ln ρ のフィルタの効果を切り分ける対照 |
| ES25 | svv_eps0 = 0.25 | 係数の感度（64³ だけ） |
| R0 | SVV なし、ν = η = 0、filter_lnrho = T | SVV が要るかの対照 |
| L(r) | SVV なし、filter_lnrho = T、nu = eta、lmd = 0 | m と B のラプラシアン（運動量の拡散） |
| H(r) | SVV なし、filter_lnrho = T、nu_h = eta_h = lmd_h、指数 4（k⁸） | 標準の超粘性。ln ρ にも掛ける |

L と H の係数は、1 つの量 r でそろえた。
k_c = N/3 での減衰率を γ_c = r ε_ref^{1/3} k_c^{2/3} とおき、r は k_c での減衰率をその波数の渦の速さで割った値である。
積分因子の減衰率は nu k²/k2_max + nu_h (k²/k2_max)⁴ で（k2_max = 3(N/2)²）、k_c²/k2_max = 4/27 なので、L は nu = eta = (27/4)γ_c、H は nu_h = eta_h = lmd_h = (27/4)⁴γ_c になる。
ε_ref は 64³ の ES のエネルギー散逸率の最大で、M_s = 1 で 0.1424333（0.7555τ0）、M_s = 0.5 で 0.01471188（0.8487τ0）である。

L と H の散逸は、すべてを粘性に任せる計算（DNS）の物理粘性ではない。
L は m = ρu の拡散で、u の粘性応力とは違う。
H は ln ρ にも超拡散を掛けるので、質量が保存しない。
r を上げた L と H は、ES と比べるための参照であり、本番の方式（ES）を安定にするための粘性ではない。

## 3. 事前に固定した基準

判定に使う量は 3 つである（細則は `tasks/todo.md` の Stage 15 の節）。

- C（完走）: t ≥ t_end − dt/2 に exit 0 で達したら完走とする。失敗は、非有限値、abort、費用の規則による停止（`stopped_cost`）のどれかである。費用の規則は、2τ0 までの見込みが 1 本の上限（64³ 16、128³ 96、256³ 450 core-h）を超えたら止めるものである。設定を変えた再実行はしない。
- K（使える波数の範囲）: M_s = 1、128³ の窓平均のスペクトル E_B、E_m（m = ρu）を 256³ の参照と比べる。比 T(n) = E_128(n)/E_ref(n) の |ln T| が初めて ln 1.25 を超える殻を k_× とし、κ = k_×/k_c(128) とする。窓は W1 = [0.75, 1.25]τ0 と W2 = [1.5, 2.0]τ0、参照は ES-256 と H-256 の 2 本で、組は 8 つ（2 成分 × 2 窓 × 2 参照）である。B* は、完走した標準の散逸のうち 8 組の κ の平均が最大のものである。ES が優るのは、κ_ES − κ_B* > δ が 6 組以上、< −δ が 0 組、かつ [3, 32] での |ln T| の平均 D が 6 組以上で ES のほうが小さいときである。逆の条件で ES が劣る。それ以外は差が決まらない。δ は max(2/k_c, 2σ, Δ_rerun) で、σ は窓の記録ごとの κ のばらつき、Δ_rerun は ES-128 を Stage 8 と Stage 15 で 2 回走らせた κ の差である。
- E（収支と保存）: ES の恒等式の残差 R が TOL_RES = 1e-10 以下であること（本番の方式の回帰の確認）。標準の散逸については報告だけにする。

H-256 が完走しなかったときは、参照を ES-256 だけにし、組の数 n に対して「6 組以上」を「⌊3n/4⌋ 組以上」に読み替え、判定に印を付けると細則で決めていた（4 組なら 3 組以上）。
M_s = 0.5 は 256³ の参照がないので、同じ方式、同じ r の (64, 128) の自己収束で参考の判定をする（4 組で、6/8 を 3/4 に読み替える）。
費用対効果は、2τ0 までの core-h を c として、c_ES/c_B* < (k̄_ES/k̄_B*)⁴ のときにあるとする（k̄ は 8 組の k_× の幾何平均）。
指数 4 は、解像度を 2 倍にすると格子が 8 倍、step が 2 倍になることから来る。

### 4.2 完走に要る最小の散逸 r*

M_s = 0.5 では、64³ と 128³ のすべての方式が完走した。
SVV も物理的な散逸も持たない R0 も完走したので、この M_s では完走は方式を区別しない。

M_s = 1 では、完走が方式で分かれた。

| N | ES | R0 | r*_L | r*_H |
|---|---|---|---|---|
| 64 | 完走 | 0.512τ0 で中止 | ≤ 1/4（梯子の最下段） | 2 |
| 128 | 完走 | 走らせていない | ≤ 1（梯子の最下段） | 8 |
| 256 | 完走（Stage 6） | 走らせていない | 走らせていない | > 32（8 は 0.614τ0、32 は 0.665τ0 で中止） |

ES は、同じ係数（svv_eps0 = 0.5）のまま 3 つの解像度で 2τ0 まで完走した。
H が完走に要る r は、64³ の 2 から 128³ の 8 へ 4 倍になり、256³ では 32 を超えた。
r は k_c での減衰率を渦の速さで割った値なので、解像度を上げるほど、H は格子の波数での相対的な散逸を強めないと走らなかったことになる。
L は梯子の最下段から完走したので、r*_L の下限は分からない。

ESf は、M_s = 1 では 64³（0.954τ0）と 128³（0.653τ0）の両方で dt が 1e-11 程度まで落ちて止まった。
ES との違いは filter_lnrho だけである。

## 5. 失敗の原因

### 5.1 ρ_min と dt の時間変化

M_s = 1 で止まった 10 本（中止 8 本と、費用で停止した ESf 2 本）は、どれも ρ_min が 1e-3 を下回った後に止まった。
比べる基準として、完走した ES の ρ_min を先に示す。
ES の ρ_min は初期から下がり、初めて 0.1 を下回ったのは 64³ で 0.643τ0、128³ で 0.708τ0、256³ で 0.555τ0（Stage 6 の実行）である。
最小は 64³ で 0.085（0.875τ0）、128³ で 0.057（0.957τ0）、256³ で 0.009（0.902τ0）で、解像度を上げるほど小さい。

| 実行 | 止まった時刻 | ρ_min ≥ 0.1 の最後の時刻 | 止まった時刻の ES の ρ_min | dt を決めた制約 |
|---|---|---|---|---|
| R0、64³ | 0.512 | 0.464 | 0.179 | 移流 |
| H(1/4)、64³ | 0.568 | 0.544 | 0.152 | 移流と粘性 |
| H(1/2)、64³ | 0.554 | 0.533 | 0.159 | 移流 |
| H(1)、64³ | 0.860 | 0.813 | 0.088 | 移流と粘性 |
| ESf、64³ | 0.954 | 0.944 | 0.105 | 粘性 |
| H(2)、128³ | 0.550 | 0.521 | 0.166 | 移流と粘性 |
| H(4)、128³ | 0.597 | 0.545 | 0.141 | 移流 |
| ESf、128³ | 0.653 | 0.647 | 0.115 | 粘性 |
| H(8)、256³ | 0.614 | 0.545 | 0.081 | 移流 |
| H(32)、256³ | 0.665 | 0.639 | 0.082 | 移流と粘性 |

時刻の単位は τ0 で、ES の ρ_min は同じ N の ES の値である。
dt を決めた制約は、ρ_min が 3e-2 から 1e-4 に下がる間に、移流の CFL（速さは |u| + c_f）と粘性の制約（衝撃波の粘性と λ_svv）のどちらが dt を決めたかを示す。
95% 以上の step で一方が決めたときはその名を書き、そうでないときは両方を書いた。
L と H の散逸は積分因子で掛けるので、dt の制約には入らない。

64³ と 128³ の H と R0 は、H(1)-64 を除いて、同じ時刻の ES の ρ_min が 0.14–0.18 だったときに止まった。
止まる時点のこれらの実行の ρ_min は 1e-3 未満で、ES より 2 桁以上小さい。
256³ では、ES の ρ_min も 0.555τ0 に 0.1 を下回り、H(8) が止まった 0.614τ0 には 0.081、H(32) が止まった 0.665τ0 には 0.082 だった。
H(32) の ρ_min は、0.55τ0 では ES より低かった（0.078 と ES の 0.108）が、0.60–0.64τ0 では ES より高かった（0.093–0.108 と ES の 0.067–0.086）。
その後、0.65τ0 で 0.051、0.66τ0 で 0.029 と下がり、0.665τ0 で止まった。
ES の ρ_min は、その後 0.009 まで下がったが、ES は 2τ0 まで完走した。

中止した 8 本では、ρ_min が最後に 0.1 以上だった時刻から止まるまでが 0.020–0.070τ0 で、ESf の 2 本では 0.006–0.010τ0 だった。
どの実行でも、止まる前の 1.4e-4τ0 以内に dt が 1e-6 を下回った。

dt が移流の CFL で決まった 4 本のうち、R0-64、H(4)-128、H(8)-256 では、ρ_min が 3e-2 から 1e-4 に下がる間の dt ∝ ρ_min^p の p が 0.37–0.59 だった。
c_f はアルフベン速度 |B|/√ρ を含むので、密度の極小で |B| が有限なら p = 1/2 になる。
p はこの読みと合うが、極小での |B| は確かめていない。
H(1/2)-64 の p は 1.17 で、この読みと合わない（当てはめに使えた step は 40 で、ほかの 3 本の 141–550 より少ない）。
dt が粘性の制約で決まった ESf の p は、128³ で 1.53、64³ で 2.35 だった。

最後の out3d の高波数のスペクトルで、k_c の手前の積み上がりを調べた。
指標は、殻 ⌊k_c⌋ のエネルギーを [k_c/2, k_c] での最小で割った比である（1 なら殻 ⌊k_c⌋ がその範囲の最小で、1 を超えると k_c の手前でスペクトルが上がっている）。
E_B と E_m の比は、R0-64 で 1.07 と 1.02、ほかの実行ではどれも 1.00 だった。
ただし、中止した 8 本の最後の out3d は止まる 0.012–0.114τ0 前の記録で、R0 以外の 7 本では ρ_min が最後に 0.1 以上だった時刻より前である。
これらの実行では、ρ_min が 0 に近づく間のスペクトルは記録されていない。
ESf の 2 本には止めた時刻の out3d があり、ρ_min が 1e-4 を下回った後でも比は 1.00 だった。
したがって、少なくとも ESf では、dt の崩落は k_c の手前の積み上がりを伴わず、ρ_min が 0 に近づくのと同時に起きた。

### 5.2 崩れた場所

中止の診断（check_state）では、各ランクが担当する領域を、場、ix、iz、iy の順に調べる（iy が最も内側）。
最初に見つけた不正な格子点の (iy, iz, ix) と値を 1 行書き、MPI_Abort を呼ぶ。
したがって、報告は 1 ランクにつき 1 点で、報告しなかったランクに不正な点がなかったとは限らない。
実空間の分割は iz と ix で、各ランクは iy の全体を持つ。

| 実行 | 検出した step、stage | 報告した場 | 報告したランク | 報告した点 (iy, iz, ix) |
|---|---|---|---|---|
| R0、64³ | 699、3 | ln ρ | 55/64 | すべて領域の最初の点 |
| H(1/4)、64³ | 843、3 | m_x（NaN） | 43/64 | すべて領域の最初の点 |
| H(1/2)、64³ | 642、3 | ln ρ | 50/64 | すべて領域の最初の点 |
| H(1)、64³ | 1174、3 | ln ρ | 41/64 | すべて領域の最初の点 |
| H(2)、128³ | 1523、2 | m_x（NaN） | 105/128 | すべて領域の最初の点 |
| H(4)、128³ | 1698、1 | ln ρ（112、257） | 2/128 | (32, 32, 83)、(32, 33, 83) |
| H(8)、256³ | 3602、3 | ln ρ（−190 から 184） | 27/256 | iy = 60 の面の 2 本の線（本文） |
| H(32)、256³ | 3663、1 | ln ρ（−105） | 1/256 | (201, 185, 110) |

R0 から H(2) までの 5 本では、報告したランクのすべてが、領域の最初の点（iy = 1 で、iz と ix がその領域の最小の値）を報告した。
検査の時点で、崩れは 64³ で 41–55 ランク、128³ で 105 ランクの領域の最初の点にまで及んでいたので、最初に崩れた場所は分からない。

H(4)-128 では、stage 1 の検査で、隣り合うランク 81 と 82 が、iz 方向に隣り合う 2 点を報告した（ln ρ = 112、257）。
上に書いた制約はあるが、報告はこの 2 点だけなので、崩れはこの付近で始まったと読める。

H(8)-256 では、stage 3 の検査で 27 ランクが報告した。
点は iy = 60 の面に並び（1 点だけ 59）、iz = 46–51 を通る x 方向の線と、ix = 161–172 を通る z 方向の線をなす。
2 本の線は (iy, iz, ix) = (60, 51, 172) の付近で交わる。
2/3 則の打ち切りは各方向に別々に掛かるので、1 点の大きな値を打ち切ると、その点を通る x、y、z の 3 本の格子線の上では値が距離に反比例してしか減らず、線から外れた点ではより速く減る。
y の線は 1 つのランクの領域に収まるので、1 ランク 1 点の報告には現れない。
報告の並びは、交点の付近の 1 か所での崩れが x と z の線に広がったとすれば説明できる。
これは報告の並びからの推定で、場を出力して確かめてはいない。

H(32)-256 では、stage 1 の検査で 1 ランク（107）だけが報告した（ln ρ = −105、ρ ≈ 2e-46）。
256³ の各ランクの領域は、iy の全体と、iz、ix の 16 × 16 の範囲である。
報告したランクが 1 つなので、崩れはこのランクの領域の中で始まったと読める。
その場所は、H(8)-256 の 2 本の線の交点 (60, 51, 172) とは違う。

### 5.3 ESf の崩れ

ESf は、ES に filter_lnrho = T を足しただけの対照である。
0.5τ0 までは、ESf の ρ_min は ES と 5% 以内で一致した（最大の差は 64³ で 4.2%、128³ で 2.6%）。
その後は差が広がり、64³ の 0.75τ0 では ESf のほうが高かった（0.108 と ES の 0.101）。
止まる前には ESf のほうが低かった（64³ の 0.95τ0 で 0.082 と ES の 0.104、128³ の 0.645τ0 で 0.101 と ES の 0.118）。
ESf の ρ_min は、その後 64³ で 3.5e-5、128³ で 1.3e-5 まで下がり、dt は 3.5e-11 と 7.7e-12 まで落ちた。
設定の違いは filter_lnrho だけなので、この実験では、ESf の ρ_min と dt の崩落は ln ρ の打ち切りを足したことで起きた。

filter_lnrho = T は、ln ρ とその右辺（SVV の項を含む）から、どれかの方向で |k_d| ≥ k_c の成分を落とす。
このとき、ES-SVV の dE/dt ≤ 0 は保証されない（advance.F90:510–513 の警告）。
128³ の p = 1.53 は、Stage 13 で SVV の質量の流束を切った（svv_mass = F）ときの dt ∝ ρ^1.5 に近いが、64³ の 2.35 は合わない。
どの項を通じて dt が崩れたかは切り分けていない。

### 5.4 H が解像度とともに大きな r を要した理由

H が解像度とともに大きな r を要した理由は、この実験では特定できない。
5.3 節のとおり、ln ρ の打ち切りは ES-SVV の dt を崩した。
標準の散逸もすべて filter_lnrho = T で走らせたので、同じ打ち切りが H と R0 の崩れに関わっている可能性がある。
切り分けるには、H を filter_lnrho = F で走らせる対照が要る（12 章の提案）。

## 6. 使える波数の範囲（K）

### 6.1 M_s = 1（参照は ES-256 だけ）

判定は、2 回目の相談の後に `judge` で 1 回だけ求めた。
H-256 がないので、細則どおり参照を ES-256 だけにし、組は 4 つ（E_B、E_m × W1、W2）、閾値の組の数は 3 とした。
参照どうしの一致の範囲 k_ref,W は求められないので、k_× の上限は 42、D の範囲は [3, 32] である。
`judge.json` には、H-256 がなく ES-256 だけで判定したことを示す印が付いている。

B* の候補は、完走した 128³ の標準の散逸 H(8)、L(1)、L(2) で、4 組の κ の平均はそれぞれ 0.516、0.126、0.083 だった。
B* は H(8) である。

| 成分、窓 | κ_ES | κ_B* | κ_ES − κ_B* | δ | D_ES | D_B* |
|---|---|---|---|---|---|---|
| E_B、W1 | 0.713 | 0.477 | +0.236 | 0.825 | 0.045 | 0.148 |
| E_B、W2 | 0.743 | 0.534 | +0.209 | 0.818 | 0.039 | 0.134 |
| E_m、W1 | 0.744 | 0.496 | +0.248 | 0.848 | 0.029 | 0.137 |
| E_m、W2 | 0.436 | 0.557 | −0.121 | 0.647 | 0.119 | 0.171 |

κ に k_c(128) = 42.7 を掛けると、k_× は ES で 30.4、31.7、31.8、18.6、H(8) で 20.3、22.8、21.2、23.8 である（表の順）。
判定は「差が決まらない」である。
|κ_ES − κ_B*| が δ を超えた組は、どちらの側にもない。
D は 4 組すべてで ES のほうが小さい。

δ は 4 組とも 2σ で決まった（2/k_c = 0.047、Δ_rerun = 0.0020）。
σ が大きいのは、窓の端の記録の κ が小さいためである。
W1 の両端（0.75τ0、1.25τ0）と W2 の始め（1.5τ0）の記録では、ES と H(8) の 12 個の κ がすべて 0.070–0.105（k_× = 3.0–4.5）だった。
記録ごとの κ は、各記録のスペクトルを参照の窓平均と比べて求める。
端の記録のスペクトルは、n = 3–5 のいずれかの殻で参照の窓平均から |ln| = 0.23–0.34 ずれ、ln 1.25 = 0.223 を超える。
窓の始めの記録は窓平均より上に、終わりの記録は下にずれる。
n = 3–5 での ln T の ES と H(8) の差は 0.03 以内なので、このずれは方式の違いでなく、窓の中でスペクトルが減衰したことによる。
つまり、事前に決めた σ は、κ の統計的な揺らぎでなく、窓の中の時間変化を測った。
σ を決めたとき、この時間変化は見込んでいなかった。
なお、H(8)-128 の W2 には 1.9998τ0 と 2.0002τ0 の 2 つの記録があり、後者の窓平均での重みは 1e-5 未満だが、σ には前者と同じ重みで入っている。

σ の項を除いた δ' = max(2/k_c, Δ_rerun) = 0.047 で数え直すと、ES が大きい組が 3、B* が大きい組が 1（E_m、W2）になる。
「優る」には B* が大きい組が 0 であることが要るので、判定は「差が決まらない」のまま変わらない。
この数え直しは判定を差し替えるものではなく、判定が σ の欠陥に左右されていないことの確認である。

k_× を決めたのは、H(8) の 4 組と ES の 3 組では、高波数でスペクトルが参照より下がることである（[3, 32] での ln T の最小は、H(8) で −1.33 から −1.57、ES で −0.25 から −0.42）。
ES が劣った E_m、W2 では逆に、ES-128 の E_m が ES-256 を上回り、ln T は n = 18.6 で ln 1.25 を超え、n = 27 で最大 +0.33 になる。
n = 27 付近の超過は E_B、W2（+0.13）と E_m、W1（+0.11）にもあるが、25% には届かない。
n ≤ 10 では、|ln T| は ES で 0.11 以下、H(8) で 0.17 以下である。

参照が ES-256 だけなので、ES-128 と ES-256 に共通し H(8) にはない性質（ln ρ のフィルタを掛けないことと SVV）による偏りは、一致として数えられる。
この偏りの大きさは、H-256 がないので測れない。

費用対効果: 128³ の 2τ0 までの費用は、ES が 45.75 core-h、H(8) が 15.21 core-h で、比は 3.01 である。
k̄（4 組の k_× の幾何平均）は ES で 27.5、H(8) で 22.0 で、(k̄_ES/k̄_B*)⁴ = 2.44 である。
3.01 > 2.44 なので、事前の規則では費用対効果はない。
この規則は、B* を高い解像度でも同じ κ で走らせられることを仮定している。
H(8) は 256³ で完走しなかったので（5 章）、B* = H(8) ではこの仮定が成り立たなかった。
256³ の 2τ0 までの費用は ES が 1,539 core-h で、H-256 は止まったので比べられない。

## 7. 収支と保存（E）

ES の恒等式の残差 R（R_ζ、R_svv/A_svv。C_η = 0 なので R_η はない）は、64³ で 6.5e-15 以下、128³ で 3.5e-14 以下で、TOL_RES = 1e-10 を満たした。
ES の質量の相対変化は 128³ で 2.1e-7 以下である。
本番の方式の回帰はない。

ESf の R_ζ は 3.4e-15–1.1e-14 で閉じたが、R_svv は M_s = 0.5 の 64³ で 1.4e-2、止まった M_s = 1 の 2 本で 0.98–1.0 になり閉じない。
filter_lnrho = T では、eps_svv はフィルタの後の ln ρ の項で、D_svv はフィルタの前の二次形式なので、R_svv = eps_svv + D_svv は 0 にならない。
事前の細則どおり、ESf には R_svv の基準を課していない。

標準の散逸の結果は報告だけにする。

- 質量: H は ln ρ にも超拡散を掛けるので、ΔM/M0 は M_s = 1 で −6.0e-2 から −6.4e-2、M_s = 0.5 で −9.7e-3 から −1.24e-2 になった。完走した L、R0 の |ΔM/M0| は 6.5e-5 以下である（filter_lnrho = T の射影が質量を変える）。
- eps_nu > 0: m の拡散はエネルギーに対して符号が定まらないが、eps_nu > 0 になった step はどの L、H にもなかった。
- 散逸の割合（M_s = 1、128³、2τ0 までの積分）:

|---|---|---|---|---|---|---|---|
| ES | 0.299 | 0.420 | 0.284 | — | — | — | −0.003 |
| H(8) | 0.254 | — | — | 0.313 | 0.378 | 0.073 | −0.017 |
| L(1) | 0.141 | — | — | 0.426 | 0.436 | — | −0.003 |
| L(2) | 0.098 | — | — | 0.450 | 0.453 | — | −0.000 |

割合は、各項を時間で積分した値の、収支の各項の和の積分に対する比で、和は 1 になる。
理想項は、離散化した理想 MHD の項がエネルギーに与えた寄与で、連続極限では 0 である。
負の値は、理想項がエネルギーを足したことを示す。
M_s = 0.5、128³ の R0 では理想項の割合が −0.162、衝撃波の粘性が 1.162 だった。
R0 では、理想項が足したエネルギーを衝撃波の粘性が取り除いている。
理想項がエネルギーを足す機構は調べていない。

## 9. 事前の規則からの変更

事前の規則では、256³ の H は r_C = 8（128³ で完走した最小の段）で 1 本だけ走らせることにしていた。
H(8)-256 は 0.614τ0 で止まった（5 章）。
規則（細則）では、H-256 が完走しなければ参照を ES-256 だけにし、判定に印を付けて相談することになっていた。
しかし、参照が ES と同じ方式 1 本だけになると、ES に有利な偏りを除けない。
そこで、判定を走らせる前に、2 本目の参照をどうするかをユーザーに相談した。

ユーザーは H(32) の 256³ を選んだ（2026-11-11）。
r*_H が 64³ から 128³ で 4 倍になった傾向から選んだ段で、事前に決めた規則（r_C）からの変更である。
選ばなかった案は、H(16)（2 倍刻みの次の段。ρ_min が下がる 0.6τ0 前後か 0.9τ0 前後で止まる見込みが高いと判断した）と、ES-256 だけで判定する案（追加の計算はないが、参照が ES と同じ方式になる）である。
H(32) は、128³ の k_c = 42.7 でも散逸が無視できない。
H の減衰率をその波数の渦の速さで割った値は r (k/k_c)^{22/3} で、k_c(256) = 85.3 に対して k = 42.7 で約 0.20、k = 32 で 0.024 である。
この影響は、参照どうしの一致の範囲 k_ref,W で測る予定だった。

H(32)-256 も 0.665τ0 で止まった（5 章）。
2 回目の相談で、ユーザーは 2 本目の参照を足さず、ES-256 だけで判定する案を選んだ（2026-11-11）。
これは事前の細則どおりの扱い（3 章）で、追加の計算はない。
選ばなかった案は、L(1) の 256³（約 200 core-h）と、H(32) を filter_lnrho = F で走らせる 256³（約 250 core-h）である。
L の減衰率を渦の速さで割った値は r (k/k_c)^{4/3} で、L(1)-256 では k = 32 で 0.27 になる。L(1)-256 は 128³ の k_c 以下の波数を減衰させるので、参照として弱い。
filter_lnrho = F の H は崩れの原因の切り分けにはなるが、事前の規則からの 2 回目の変更になり、完走する保証もない。
これは次の段階の提案とした（12 章）。

判定（`judge`）は、2 回目の相談の後に初めて走らせた。
したがって、参照の選び方は判定の結果を見ずに決めている。

実装では、`runs/stage15/c.json` に r_256 = [H, 32] と理由を書き、`gen_stage15.r_256` が c.json を優先して読むようにした（c.json がなければ b.json の r_C）。
`judge` も同じ関数で H-256 を探す。
生成した calliope.in は、H(8) のものと nu_h、eta_h、lmd_h（672431.44 = 4 × 168107.86）だけが違い、ic/ は Stage 6 の turb1_N256 と同じである。

## 10. 物理的な妥当性

K の比べ方の物理的な前提は次のとおりである。
ES-256 の SVV は |k_d| ≤ 0.5k_c(256) = 42.7 で 0 なので、比べた n ≤ 42 で ES-256 に直接掛かる散逸は衝撃波の粘性だけである。
エネルギーを持つ n ≤ 10 では、128³ の ES と H(8) の窓平均スペクトルは ES-256 と 11%（ES）、19%（H(8)）未満の差で一致する。大きなスケールでの解像度と方式による差は、K の閾値の 25% より小さい。
ES-128 の E_m が W2 の n ≈ 27 で ES-256 を 40% 上回ること（6.1 節）は、SVV が掛かり始める 0.5k_c(128) = 21.3 より上で起きている。
その原因は調べていない。

安定化のための density floor、圧力の floor、一様な粘性は足していない。
r を上げた L、H は参照として走らせたもので、ES の係数は Stage 6 以来の既定値（svv_eps0 = 0.5、C_shock = 2）のままである。
止まった実行は係数を上げて通さず、5 章で原因を調べた。

## 11. 限界

- 実現は 1 つ（seed は 1 つ）で、減衰乱流だけを扱った。強制乱流での結論は出せない。
- 判定は C_shock = 2 での結論である。
- 標準の散逸はすべて filter_lnrho = T で走らせた。H の r* が N とともに上がることと ln ρ のフィルタとの関係は切り分けていない。
- 標準の散逸は m の拡散で、u の物理的な粘性応力ではない。
- ES の係数は事前に調整していない。感度を示すのは ES25（64³）だけである。
- M_s = 0.5 の判定は (64, 128) の自己収束による参考にとどまる。
- 256³ の参照は ES-256 の 1 本だけである。H-256 は H(8)、H(32) とも止まった（9 章）。参照が ES と同じ方式なので、K の判定は ES に有利な側にずれうる。
- 費用対効果の規則は、κ が N によらないという仮定に立つ。H(8) は 256³ で完走しなかったので、B* = H(8) ではこの仮定が成り立たなかった。
- 事前に固定した σ は窓の中の減衰を含み、δ を各組の差の 3.4 倍以上にした（6.1 節）。判定は σ の項を除いても変わらないが、σ の定義は判定の規則として不適切だった。
