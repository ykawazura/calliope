Stage 10 では、128³ の対照で ρ が最も低い K セルの質量収支を求め、SVV の項 T_svv が穴を下げる側に働いたことを示した（判定 (A)）。

- H1: T_svv が eps0 に比例しない。
- H2: T_svv は比例するが、移流の項が補償する。

この Stage では次の問いを調べた。

> Stage 8 の 3 ケースの既存レコードで、K = 64 の I_svv は svv_eps0 に比例するか。

ES-SVV の係数は eps_d = eps0 dl_d max(|u_d| + c_f,d) で、同じ場なら T_svv は eps0 に厳密に比例する（`selftest` で、eps0 を 2 倍にすると T_svv が丸め誤差の範囲で 2 倍になり、移流の項は変わらないことを確かめた）。

## 4. 事前に固定した基準

基準は e1.0、e0.25 の K = 64 の値を計算する前に `tasks/todo.md` に書き、変えていない。

### 4.1 収支と誤差の見積り

収支は Stage 10 と同じである。m_K は ρ の低い順に K 個のセルの ρ の和、I_T = ∫ S_T/m_K dt（5 レコードの台形則）で、Δ ln m_K = I_adv + I_svv が成り立つ。閉じの誤差を ε = |Δ ln m_K − I_adv − I_svv| とする。

5 レコードの誤差は、Stage 10 の密な再実行（0.01τ0 ごと）で見積もった。
5 レコードの開始を 0.60τ0 から 0.01τ0 ずつ 6 通りにずらし、同じ窓の密な積分と比べた I_svv の誤差の絶対値の最大は、K = 64 で 0.187、K = 8 で 1.480、K = 512 で 0.156 である。
I_adv の誤差の絶対値の最大は K = 64 で 0.405 である。
`selftest` はこれらの値を `runs/stage10/budget.json` から再計算して一致を確かめる。

### 4.2 関門

どれか 1 つでも落ちたら、ラベルを出さずに止まって報告すると定めた。

### 4.3 判定の式とラベル

K = 64 で、ケース e ごとに I_e（I_svv）と ε_e を求め、δ_e = max(0.187, ε_e) とする。

```
F = (I_1.0 − I_0.25)/(1.5 I_0.5)        比例なら 1、eps0 によらなければ 0
u = sqrt(δ_1.0² + δ_0.25²)/|1.5 I_0.5| + |F| δ_0.5/|I_0.5|
```

区間 [F − u, F + u] に次のラベルを付ける。

| ラベル | 条件 | 計画の解釈 |
|---|---|---|
| 比例と合う | 1 を含み、0 を含まない | H2 の可能性が高くなる |
| 一定と合う | 0 を含み、1 を含まない | H1 の可能性が高くなる |
| 中間 | どちらも含まず、0 < F < 1 | H1 と H2 は分けられない |
| 範囲の外 | どちらも含まず、F ≥ 1 か F ≤ 0 | 結果をそのまま報告する |
| 決められない | 両方を含む | 5 レコードでは分からない |

u は統計的な信頼区間ではなく、対照の 6 通りの誤差の最大と各ケースの ε から作った幅である。

## 8. 判定の弱い箇所

### 8.1 F が負であること

ラベルの区分は 0 と 1 を分けるために設計したので、「一定と合う」は区間が 0 を含むことしか意味しない。
点推定の F = −0.425 は、eps0 を上げると |I_svv| が減る向きを示す。区間の下端は −1.079 なので、この逆向きの依存は区間の中にある。
基準は、F ≤ 0 で区間が 0 を含む場合を「一定と合う」に入れていた。私は基準を作るときに、点推定が 0 より下に出る場合を考えていなかった。

### 8.2 判定を支えるケース

片側の比を報告だけの量として求めた。f_hi = (I_1.0 − I_0.5)/I_0.5、f_lo = (I_0.25 − I_0.5)/(−0.5 I_0.5) で、どちらも比例なら 1、一定なら 0 である。

| 比 | 値 | 幅 | 区間 |
|---|---|---|---|
| f_hi（e1.0 と対照） | −0.444 | 0.577 | [−1.021, +0.133] |
| f_lo（e0.25 と対照） | −0.387 | 2.070 | [−2.458, +1.683] |

f_hi の区間は 0 を含み 1 を含まないが、f_lo の区間は両方を含む。
e0.25 では比例と一定の I_svv の差が 0.398 しかなく、ε が 0.536 と大きいので、e0.25 と対照だけでは 0 と 1 を分けられない。
したがって、比例を否定する根拠は主に e1.0 の I_svv（−0.442）にある。

### 8.3 δ への依存

δ は対照の 1 ケースの 6 通りから求めた値で、e1.0、e0.25 の流れでの誤差は対照と違う可能性がある。
e0.25 の ε = 0.536 は、対照の 6 通りの ε の範囲（0.017–0.563）の上端に近い。

u は δ に比例するので、すべての δ を同じ倍率 s で変えたときのラベルは次のように決まる。これは事後の感度で、基準は変えていない。

- s ≥ 2.18 なら区間が 1 に届き、「決められない」になる（(1 − F)/u = 2.18）。
- s < 0.650 なら区間から 0 が外れ、F < 0 なので「範囲の外」になる（|F|/u = 0.650）。

「1 を含まない」ことには 2 倍余りの余裕があるが、「0 を含む」ことの余裕は 35% である。

### 8.4 計画の数値例の前提

計画は、合成値（I_0.5 = −0.8）で u の大きさを次のように示していた。
「δ がすべて 0.187 なら F = 0 で u = 0.22、F = 1 で u = 0.45」「ε が対照の最大 0.563 の場合でも F = 0 で u = 0.49、F = 1 で u = 0.73 で区別できる」。
後者は、e1.0 と e0.25 の一方だけの ε が 0.563 で、ほかの δ が 0.187 の場合の値である（`selftest` で 0.4944、0.7281 を確かめた）。
3 ケースすべての ε が 0.563 なら、F = 0 で u = 0.664、F = 1 で u = 1.367 で、F = 1 の区間は 0 も含むので「決められない」になる。
計画にはこの前提が書かれていなかった。今回の判定はこの数値例を使っていないので、ラベルには影響しない。

R_64 は行から求めた R（ρ_min の 1 点の量）と同じ符号で、大きさは約半分である。窓の始めですでに差があるのは、eps0 が t = 0 から違うためである。

## 10. Stage 10 の 11 章との関係

Stage 10 は、T_svv が eps0 に比例し、ほかが変わらないと仮定すると、eps0 を 2 倍にしたときの ln m_K のずれは I_svv の累積になると考えた。その予想は R(1.0) の約 8 倍から 13 倍で、仮定のどこかが成り立たないと結論した。

この Stage の K = 64 では、仮定の最初の段階が成り立たない。
e1.0 の I_svv は −0.442 で、比例の値 −1.591 から遠く、D_svv = +0.353 は比例の予想 −0.795 と符号が違う。
T_svv が比例しないなら Stage 10 の予想の前提が成り立たないので、R が I_svv の累積よりずっと小さいことと矛盾しない。
ただし、e1.0 の D_svv（+0.353）は R_64（−0.0480）と逆の向きで、D_adv（−0.263）と打ち消し合っている。どちらも誤差を超えないので、R の符号はこの 2 つからは説明できない（D_svv の誤差は δ_1.0 と δ_0.5 の二乗和の平方根で 0.404、D_adv の誤差は I_adv の誤差 0.405 とした）。
D_svv は 0 とは誤差の範囲で合い、比例の予想 −0.795 からは 1.149 離れている。
移流の補償（H2）は誤差を超える大きさでは見えないが、H2 が働いていないことも示していない。

T_svv の場の因子が eps0 にほぼ反比例する理由は調べていない。
候補の機構は次のとおりである。格子の尺度に届く揺らぎの量が大きな尺度の流れで決まるなら、係数が大きいほど揺らぎの振幅が小さくなり、T_svv の大きさはあまり変わらない。
これは乱流の散逸率が粘性によらない性質と同じ型であるが、この Stage では確かめていない。
