## 1. 結論

Stage 4 では、M_s = 4 の 3D 減衰乱流（`turb4`、`turb4b`）で ρ が格子 1 点の幅の穴で 0 に向かい、ES-SVV の剛性 F_svv が 1/ρ_min に比例して増えて、dt が 2e-8 以下に縮んだ（Stage 4 の 8.3 節）。
Stage 5 では、ES-SVV を Python に移して穴での F_svv の機構を静的に調べ、現行の方式のまま 2 本を 128³ で走らせて、穴が解像不足によるものかを確かめた。
F_svv は λ_svv をその状態の線形の上限 λ_lin（一様な状態の λ_svv、cfl.dat の 13 列目を 14 列目で割った値）で割った値で、一様な状態で 1 になる。

- 穴の点の剛性（4 章）
  - 実際の 2 つの穴（`turb4_N64_a` と `turb4b_N64` の最後の restart）では、F_svv は、穴の点の (ρ, m) の 4 成分の摂動に対する凍結した SVV の Rayleigh 商 Q4 と 1–2.5% で一致する。調べた 9 種の係数の変種のすべてで成り立つ。
  - Q4 は、核（SVV の作用素が 1 点の摂動を広げる範囲）の上の係数の和を穴の ρ_h で割った値 Q に、核の上の速度と穴の点の速度の差による 13–34 倍の増幅がかかったものである。差の rms は c_s の 3.9–6.3 倍である。
  - 静止した合成の穴（32³）では F_svv ∝ ρ_h^−1.09 で、ε_d を局所の波速で決めても F_svv ∝ ρ_h^−0.59（λ_svv ∝ ρ_h^−1.09）が残る。ρ の重みを 3 点の局所最小に替えても、冪は変わらず前の係数が下がるだけである。
- 変種を Fortran に入れなかった理由（5 章）
  - `turb4_N64_a` の穴の点では、−div_N m = −23.47 を SVV が +23.19 埋め戻し、正味の dρ/dt は −0.28 である。
  - F_svv を 1/50 以下にする変種は、埋め戻しも +0.38 以下か負にする。凍結した状態では、穴の ρ はおよそ 1.4e-5 の時間で 0 に達する。
  - この結果を受けて、ユーザーの判断で変種の Fortran への実装（計画の Phase B）と 64³ の試験（Phase C）を取りやめた。変種で t = 0 から走らせた試験はしていない。
- 128³ の解像度試験（6 章）
  - 2 本とも、128³ でも穴は格子 1 点の厚さで深まった。薄い軸（`turb4` は x、`turb4b` は z）の幅は ρ_min ≈ 7e-3 で 0.90 と 1.14 格子点で、物理の幅は 64³ の約半分である。
  - 128³ の深い段階では F_svv ρ_min が一定（`turb4` で 0.81、`turb4b` で 0.22–0.27）で、dt は 4e-8 と 4e-7 まで縮んだ。同じ ρ_min での dt は 64³ の 1/5–1/10 である。
  - 事前に決めた基準では「格子の尺度での崩壊」に当たり、穴は解像不足の有限の幅の構造ではない。解像度を上げるだけでは M_s ≈ 4 の t_end に届かない見込みである。

  - 最後の restart の穴の点では、`turb4` は 64³ と同じく移流が穴を掘り、現行の SVV が埋め戻す。`turb4b` では 64³ と向きが逆で、移流が穴を埋め、現行の SVV が掘る。この状態では local/rho の変種が F_svv を 1/13 にしながら穴を埋めるので、5 章の「F_svv を下げる変種は埋め戻しも下げる」はすべての状態には当てはまらない。

## 3. ES-SVV の 3D の写しと検証

### 3.1 写した範囲と変種

svv3d.py は、状態 (s, m, B) から ES-SVV の質量と運動量の時間変化 (dρ/dt, dm/dt) と散逸 D_svv を、コードと同じ波数格子、2/3 マスク、σ_d で計算する。
エントロピー変数は w = (w_ρ, u)、w_ρ = c_s² s − |u|²/2 で、係数は a_d = ε_d W/c_s²、b_d = ε_d W、κ_d = ε_d/(c_s² + max|u|²) である。
コードでは W = ρ、ε_d = svv_eps0 Δ_d max(|u_d| + c_f,d)（箱全体の最大）である。
λ_svv は G = ((dρ/dt)/ρ, dm/dt) の (s, m) に対するヤコビアンの最大の |固有値| で、コードはこれを差分の Jv と冪乗法（`svv_power`）で求める。

変種は次のとおりである。

- ε_d: `global`（コード）、`local`（ε_d(x) = svv_eps0 Δ_d (|u_d| + c_f,d)(x)）
- W: `rho`（コード）、`min<n>`（y, z, x の順に 3 点の最小をとる操作を n 回くり返した ρ）、`const<r>`（定数 r。静的な試験だけ）

W ≥ 0 と ε_d ≥ 0 であれば、各点の K = ε (W/ρ) ∂U/∂w は半正定値なので、どの変種でも Σ(w_ρ dρ/dt + u·dm/dt) = −D_svv ≤ 0 と、Σ dρ/dt = Σ dm/dt = 0 が成り立つ。

### 3.2 恒等式と λ の求め方

一様な 16³ の状態では F_svv − 1 = −1.36e-7（min2 で −2.36e-7）である。
16³ と 24³ のなめらかな状態では、全変種で (Σ w·G + D_svv)/Σ|w·G| が 3.5e-17 以下、max|ΣG|/Σ|G| が 3e-18 以下、2/3 マスクの外の dm/dt が 1.4e-16 以下である。

λ_svv は ARPACK（scipy の `eigs`、絶対値の大きい 3 つ）で求めた。
16³ のなめらかな状態では、ARPACK は Jv 65 回で 109.125495 を返し、冪乗法は 3000 回で 109.125511 で、400 回では収束しなかった。
大きい 3 つの固有値は −109.125, −106.665, −104.780 で、上位 2 つの比が 0.977 と 1 に近いので、冪乗法の収束は遅い。
コードの `svv_power` は前の step のベクトルから始めるので、step を重ねるうちに収束する。

## 4. 穴の点の剛性 F_svv の機構

### 4.1 速度の分布だけによる F_svv

まず、密度が一様なときに速度の分布だけで F_svv がどこまで上がるかを調べた（`svv3d.py synth`）。
32³、ρ = 1、B = B0 ẑ（v_A = c_s）とし、x の関数 f で u_c = U f(x) を与えた（c = x は圧縮、c = y はずれ）。
f は sin x（なめらか）と tanh(sin(x)/Δ)（約 1 格子点の跳び）である。

| f, 成分 | U/c_s = 0 | 0.25 | 0.5 | 1 | 2 | 4 | 8 |
|---|---|---|---|---|---|---|---|
| sin, u_x | 1.000 | 0.975 | 0.937 | 0.893 | 0.856 | 2.067 | 6.800 |
| sin, u_y | 1.000 | 0.975 | 0.945 | 0.923 | 0.918 | 2.023 | 6.628 |
| 跳び, u_x | 1.000 | 0.991 | 0.977 | 0.955 | 1.392 | 2.690 | 11.165 |
| 跳び, u_y | 1.000 | 0.992 | 0.979 | 0.964 | 1.342 | 3.707 | 13.109 |

U/c_s ≤ 1 では F_svv ≤ 1 で、U/c_s ≥ 2（跳び）または 4（sin）で 1 を超えて増える。
U = 8 での隣り合う格子点の u の差の最大は、sin で 1.56、跳びで 5.84 である。
F_svv が 1 を超えるには、核の上で速度が c_s 程度以上違う必要がある（4.4 節の Q4/Q の下限と同じ形）。
Stage 4 の 11.1 節は、M_s ≈ 4 の初期の F_svv = 7.0–7.9 の原因をエントロピー変数のヤコビアンの |u|²/c_s² の項と推定した。
この表はその推定と矛盾しないが、3D の乱流の初期値そのものでは調べていない。

λ_svv で見ると、箱全体の ε_d（穴の中の v_A ∝ ρ_h^(−1/2) で決まる）が ρ_h^(−1/2) を、残りが ρ_h^(−1.09) を担う。
W を定数にしても冪は −1.10 で、W を局所最小にしても −1.08 から −1.09 である。
したがって、1/ρ_h の因子は W から来るのではない。

### 4.3 核の広がり

W を穴の近くだけ下げても冪が変わらないのは、SVV の作用素が 1 点の摂動を広い範囲に広げるからである。
δ 関数に A_d = σ_d M（2/3 マスクの内側、L）と σ_d (1 − M)（外側、H）をかけ、Σ_d (A_d δ)² の和に占める割合を、中心からの距離（各軸の差の最大、格子点の単位）ごとに求めた（`svv3d.py kernel`）。

| 格子、部分 | 6 つの隣 | r ≤ 1 | r ≤ 2 | r ≤ 3 | r ≤ 4 | r ≤ 8 |
|---|---|---|---|---|---|---|
| 32³、L | 0.146 | 0.273 | 0.365 | 0.518 | 0.682 | 0.897 |
| 32³、H | 0.250 | 0.263 | 0.627 | 0.786 | 0.835 | 0.920 |
| 64³、L | 0.162 | 0.286 | 0.404 | 0.535 | 0.714 | 0.878 |
| 64³、H | 0.247 | 0.247 | 0.604 | 0.766 | 0.822 | 0.896 |

格子点の単位での核の形は N にほとんどよらない。
3 × 3 × 3 の範囲（r ≤ 1）は核の約 27% しか占めず、r ≤ 3 でも L は約 53% である。
min1–3 の重みが ρ_h まで下がるのは r ≤ 1–3 の範囲なので、それより外の核（W ≈ 1）の寄与が残る。

### 4.4 凍結した作用素の下限と埋め戻し

F_svv の大きさを分解するため、係数（ε_d, W）を固定した SVV、dU/dt = −A* K A H dU（U = (ρ, m)、H = ∂w/∂U）の最大の |固有値| の下限を求めた（`svv3d.py bound`）。
−A* K A H は対称な −H^½ A* K A H^½ と相似なので、dw = H dU についての Rayleigh 商 Σ dw·K dw / (dU·H dU) が下限を与える。
穴の点 x0 の δ 関数 e と、P_d = A_L,d e、P_H,d = A_H,d e を使うと、次の 2 つが得られる。

- Q: dw = (e, 0) の Rayleigh 商。Q = c_s² S/ρ(x0)、S = Σ_d Σ_y [a_d P_d² + κ_d W P_H,d²](y)。
- Q4: dw = c e（c は 4 成分）の Rayleigh–Ritz。x0 の (ρ, m) の 4 つの摂動に対する最大値である。

b_d = c_s² a_d なので、κ の部分を除くと Q4/Q は行列 [[1, dᵀ], [d, I + E]] の最大固有値になる。
d = ⟨u − u(x0)⟩/c_s、E = ⟨(u − u(x0))(u − u(x0))ᵀ⟩/c_s² で、⟨·⟩ は重み Σ_d a_d P_d² による核の上の平均である。
そのため 1 + λ_max(E) ≤ Q4/Q ≤ 2 + M_rel²（M_rel = tr(E)^½）で、Q4 が Q を大きく超えるには、核の上の速度が穴の点の速度と c_s 以上違う必要がある。

ヤコビアン G の (s, s) の対角には、凍結した作用素の分に加えて −R/ρ(x0) が入る（R = (dρ/dt)_svv(x0) は SVV による穴の埋め戻し）。
R は S と同じ核と係数の和で、μ = R/(c_s² S) は核の上の w の差を S の重みで平均したものになる。

静止した合成の穴では M_rel = 0 なので Q4 = Q で、F_svv はほぼ |J_ss| = Q + R/ρ_h = (1 + μ)Q である（λ_lin で割った値。global/rho）。

| ρ_h | Q | R/ρ_h | μ | Q + R/ρ_h | F_svv |
|---|---|---|---|---|---|
| 1e-2 | 23.47 | 67.26 | 2.866 | 90.73 | 90.81 |
| 1e-4 | 2171 | 12446 | 5.732 | 14617 | 14620 |

この穴では埋め戻しの項が F_svv の 3/4 以上を占める。
ln ρ の形を相似に保っているので、穴と核の上の w_ρ = c_s² s の差は ln(1/ρ_h) に比例し、μ = 0.622 ln(1/ρ_h) になる。
F_svv ∝ (1 + μ)/ρ_h の ρ_h = 1e-3 と 1e-4 の間の冪は −1.10 で、4.2 節の −1.09 とほぼ合う。

全変種で Q4/F_svv = 0.976–0.994 で、λ_svv は穴の点の 4 成分の摂動でほぼ決まる。
差分のヤコビアンを穴の点の 4 × 4 に制限した最大の |固有値|（係数の微分と −R/ρ を含む）も、Q4 と 0.4% 以内で一致した。
R/ρ_h の項は F_svv の 0.6% 以下で、合成の穴と違って埋め戻しの項は剛性にほとんど寄与しない。
剛性を決めるのは Q（F_svv の 3–8%）と、核の上の速度の差による増幅 Q4/Q = 13–34 である（M_rel は `turb4` で 4.8–6.3、`turb4b` で 3.9–6.2）。
穴は流れが外に開く点（−div_N m < 0）にあり、穴と周りの気体の速度の差は c_s の数倍になる。
対称な等温の Riemann 問題の見積もり ρ_h = ρ0 exp(−U/c_s) では、ρ_h = 3.4e-4 と 1.2e-4 は U ≈ 8 c_s と 9 c_s に当たり、M_rel と同じ程度である。

穴のない `turb1_N64`（M_s = 1、t = 3τ0、ρ_min = 0.399）では、Q4/F_svv = 0.29–0.38、ρ の最小の点のまわり 27 点に制限した最大の |固有値| も F_svv の 0.46–0.62 で、λ_svv は ρ の最小の点に局在しない。
Q4/Q は 1.17（M_rel 0.52–0.58）である。

したがって、穴の点の F_svv は、核の上の係数の和を ρ_h で割った Q = c_s² S/ρ_h に、穴と周りの速度の差による増幅 Q4/Q をかけたものである。
1/ρ_h の因子は、Rayleigh 商の分母の ∂U/∂w の (w_ρ, w_ρ) 成分 ρ/c_s² が穴の点で小さいことから来るので、ε_d と W のどちらを変えても残る。
W の変種は前の係数だけを変え、ε_d の局所化は箱全体の ε_d による ρ_h^(−1/2) を除く（4.2 節）。

## 5. 変種 (a) と (b1) を Fortran に入れなかった理由

計画では、F_svv を下げる 2 つの変種、(a) ε_d の局所化（`svv_eps_local`）と (b1) ρ の重みの局所最小（`svv_rho_nmin`）を既定オフで Fortran に入れ、64³ で試す予定だった。
4.5 節の表で、F_svv を下げる変種は、SVV による穴の埋め戻し R も下げる。
R と F_svv は、同じ核と同じ係数 a_d、κ_d の和で決まるからである（4.4 節）。

`turb4_N64_a` の穴の点では、現行の SVV の R = +23.19 が −div_N m = −23.47 をほぼ打ち消し、正味の dρ/dt は −0.28 である。
F_svv を 1/28 以下にする変種（local/rho、global/min3、local/min1–3）では R は +0.38 以下か負になり、正味の dρ/dt は −23.1 から −27.7 になる。
この速さが続けば、ρ_min = 3.37e-4 は 1.2e-5–1.5e-5 の時間で 0 に達し、s = ln ρ は −∞ になる。
`turb4b_N64` でも、local/rho と local/min1–3 で R は +0.075 以下か負で、正味の dρ/dt ≈ −0.74 から −1.01 のもとで ρ_min = 1.18e-4 は 1.2e-4–1.6e-4 の時間で 0 に達する。

Stage 4 の 8.3 節の推定どおり、2/3 マスクで帯域の限られた m は 1 格子点の穴に追従できず、穴の点の −div_N m は ρ_h → 0 でも 0 に向かわない。
現行の SVV は、その流出を埋め戻して ρ_h を正に保つ代わりに、1/ρ_h に比例する剛性を持つ。
調べた変種は剛性と埋め戻しを一緒に下げるので、dt は縮まなくなる見込みだが、穴の ρ が有限の時間で 0 に達する見込みになる。

この結果をユーザーに示し、ユーザーは変種の実装を取りやめ、報告と 128³ の解像度試験に進むことを選んだ。
ただし、この見積もりは 1 時刻の状態を凍結したものである。
変種で t = 0 から走らせると穴のでき方そのものが変わりうるが、その試験はしていない。
あとで求めた `turb4b` の 128³ の最後の restart では、local/rho が F_svv を下げながら穴を埋め、この章の結論は成り立たない（6.2 節）。

同じ合わせ方の傾きは、最後の 3e-3 の幅では −151 で、穴の深まりは遅くなっている。
μ = R/(c_s² S) は −0.001 で、64³ の +0.0016 と同じく 0 に近く、符号だけが入れ替わった。

この状態では、5 章の結論は成り立たない。
local/rho は F_svv を 1/13 にしながら R = +0.556 で穴を埋め、正味の dρ/dt は +0.85 になる。
ρ の重みを局所最小にする 6 変種（global/min1–3、local/min1–3）は R = −0.57 から −20 で、現行より速く穴を掘る。
μ は核の上の w の差に S の重みをつけた平均なので（4.4 節）、ε_d と W の変え方で符号が変わりうる。
64³ の 2 つの restart でも、この 6 変種のうち `turb4_N64_a` で 4 つ、`turb4b_N64` で 6 つすべての μ が負である。
64³ の 2 つの restart と `turb4` の 128³ で R が F_svv とともに下がったことは、それらの状態についての結果で、どの状態でも成り立つ性質ではない。
変種で走らせたときに穴が止まるかどうかは、1 時刻の凍結した状態からは決まらない（11 章）。

### 6.3 判定

判定の基準は、結果を見る前に次の 2 つに固定した。

- 解像された構造: ρ_min = 1e-2 の時点で、128³ の穴の幅が格子 2 点以上あり（物理の幅が 64³ と同程度）、かつ 64³ が崩れ始めるまでは ρ_min(t) が 64³ と合う。
- 格子の尺度での崩壊: 128³ でも穴が 1 格子点の厚さで深まり（物理の幅は半分）、F_svv ρ_min が O(1) で一定になる。

計画では幅を B0 の方向で測るとしていたが、`turb4` の穴が薄いのは x 方向だったので（4.5 節）、各ケースの薄い軸で判定した。
B0 の方向で測っても、`turb4` の z の幅は ρ_min = 7.2e-3 で 1.33 格子点で、判定は変わらない。

2 本とも「格子の尺度での崩壊」に当たる。
薄い軸の幅は ρ_min = 7e-3 で 0.90 と 1.14 格子点、最後まで 0.9–1.1 格子点で、物理の幅は 64³ の約半分になった。
128³ の深い段階の F_svv ρ_min は 0.81（`turb4`）と 0.22–0.27（`turb4b`）で、F_svv が 2.5 倍以上になる間ほぼ一定である。
「解像された構造」には当たらない。
ρ_min = 1e-2 での幅が 2 格子点に届かず、ρ_min(t) も 64³ が崩れ始める前（ρ_min ≈ 0.3–0.5）から 64³ と 10% 以上ずれる。
崩れ始める時刻は `turb4` で早まり、`turb4b` で遅れたので、N に対して一定の向きには動かない。

したがって、穴は 64³ で解像しきれていない有限の幅の構造ではない。
N を 2 倍にすると薄い軸の物理の幅も半分になり、F_svv の 1/ρ_min に比例する増え方と dt の縮みは 128³ でも同じように起きる。
同じ ρ_min での dt は 128³ のほうが小さいので、解像度を上げるだけでは M_s ≈ 4 の t_end に届かない見込みである。

## 7. Stage 4 の報告の訂正

- 11.1 節の「ρ の重みのついた SVV の剛性 F_svv ∝ 1/ρ_min」は、ρ の重みが原因という書き方になっている。
  4.2 節のとおり W を定数にしても F_svv ∝ ρ_h^−1.10 で、1/ρ_min の因子は H = ∂w/∂U から来る。
  λ_svv ∝ ρ_min^(−3/2) の冪の分け方（ε_d の ρ_min^(−1/2) と残りの ρ_min^(−1)）は、合成の穴の −1.59 と合う。
- 11.1 節の「推定した機構は 2 つの要素からなる」のうち、帯域の限られた m が −div_N m を O(1) に残すという要素は、4.5 節の収支（−23.47）で確かめた。
  ただし、64³ の 2 つの restart と `turb4` の 128³ では、穴の深まりを遅くしているのは現行の SVV の埋め戻しで、ε_d と W を変えるとその埋め戻しも消える（5 章、6.2 節）。
  `turb4b` の 128³ の最後の restart では、移流が穴を埋め、現行の SVV が掘る（6.2 節）。
- 8.3 節の `turb4` の穴は、隣の ρ が x 方向で 0.617 と 2.17、y と z 方向で 0.06–0.14 なので、1 格子点の厚さなのは x 方向（B0 に垂直）である。
  B0 の方向に 1 格子点の厚さなのは `turb4b` だけである。
  「B0 に沿った流れは磁場に妨げられないので、この種の希薄化は B0 の方向に起こりやすい」という説明は、`turb4` の穴には当てはまらない。

## 8. 実装した範囲と未実装の範囲

### 8.1 実装し、実行したもの

- ES-SVV の 3D の写しと、係数の変種 3 種（ε_d の局所化、ρ の重みの局所最小、定数の重み）。
  恒等式、一様な状態の F_svv = 1、コードの F_svv との一致（2e-4 以内）を確かめた（3 章）。
- 静的解析: 速度の分布による F_svv、静止した合成の穴での冪、核の広がり、凍結した作用素の下限 Q と Q4、埋め戻し R、穴の点の 4 × 4 のヤコビアン（4 章）。
  対象は合成の状態（32³）と、`turb4_N64_a`、`turb4b_N64`、`turb1_N64` の最後の restart である。

### 8.2 実装しなかったもの、走らせなかったもの

- 変種 (a) と (b1) の Fortran への実装と、64³ での試験（計画の Phase B と C）。5 章の結果を受けたユーザーの判断で取りやめた。

- 128³ の 2 本を t_end まで走らせること。dt が 4e-8 と 4e-7 まで縮んだ時点で、計画どおり 2 本目のジョブで打ち切った。
- 256³ の試験。

## 9. 未解決の問題

- 穴を格子 1 点の厚さまで薄くする流れを特定していない。
  128³ でも穴は 64³ と同じ場所にできるので、場所は初期の場の大きな尺度の流れで決まっていると見られる。
  しかし、薄くなる軸が `turb4` では B0 に垂直な x、`turb4b` では B0 の z である理由と、薄くする機構は調べていない。
- 128³ の深い段階は短い。ρ_min < 3e-3 の範囲は、t の幅で `turb4` が 5.5e-4、`turb4b` が 4.9e-3 で、F_svv ρ_min が一定であることは F_svv の 2.5–2.8 倍の範囲でしか確かめていない。
- M_s ≈ 4 で t_end まで走らせる方法がない。
  現行の方式では dt が ρ_min とともに縮む。F_svv を 1/10 以下にする変種は、凍結した状態の見積もりでは、64³ の 2 つと `turb4` の 128³ の restart で穴の ρ を有限の時間で 0 にする（5 章、6.2 節）。
  `turb4b` の 128³ では local/rho が穴を埋める。どちらも 1 時刻の凍結した状態の見積もりで、変種で t = 0 から走らせた試験はしていない。
- 穴の点の収支は最後の restart でしか求めていない。`turb4b` の 128³ で移流と SVV の向きがいつ、なぜ入れ替わったかは調べていない。
- 64³ と 128³ の ρ_min(t) は ρ_min ≈ 0.3–0.5 より下で解像度について収束しておらず、穴のできる時刻も N に対して一定の向きに動かない。

## 11. 次の段階

6 章の結果から、M_s ≈ 4 の穴は、現行の方式のまま解像度を上げても扱えない見込みである。
F_svv を 1/10 以下にする 5 章の変種は、凍結した状態の見積もりでは、4 つの restart のうち 3 つで穴の ρ を 1.2e-5–1.6e-4 の時間で 0 にする。
残る `turb4b` の 128³ では、local/rho が穴を埋め、ρ の重みを局所最小にする変種は穴を掘る（6.2 節）。
現行の方式で `turb4` の 128³ を続けると、dt = 4e-8 のまま残りの t ≈ 2.25 に約 5.6e7 step かかり、0.2 s/step では 1 ケース 64 コアで約 130 日になる。
dt はさらに縮むので、これは下限である。
次の段階の候補と、その代償は次のとおりである。

| 候補 | 得られるもの | 代償 |
|---|---|---|
| 対象を M_s ≲ 1–2 に限る | コードを変えずに使える。M_s ≈ 1 の `turb1` は Stage 4 で t_end に達した | M_s ≈ 4 は扱えない。M_s ≈ 2 は試していないので、上限は試験で決める必要がある |
| 穴での質量流束を制限する（FCT 型の正値性の制限子など） | ρ を正に保ちつつ、SVV の埋め戻しに頼らずに穴の流出を止められる可能性がある | 方式の大きな変更で、穴でだけ働く点で密度の床に近い。元の指示により、入れる前にユーザーの承認が要る |
| 変種（local/rho、min<n>）を Fortran に入れ、64³ で t = 0 から走らせる | 5 章の凍結した状態の見積もりを、穴のでき方の変化を含めて確かめられる | 64³ の 2 つと `turb4` の 128³ の見積もりどおりなら、穴の ρ が有限の時間で 0 になって止まる（`turb4b` の 128³ では local/rho が穴を埋めた）。Fortran の変更（既定オフ）と A_dev の 64³ のジョブ数本 |
| 256³ で走らせる | 薄い軸の幅がさらに半分になるかを確かめられる | 6 章の結果からは dt の縮みは止まらないと予想する。費用は 128³ の約 16 倍（格子点 8 倍、dt 1/2）で、元の合意（3D は 256³ まで）の上限に当たる |
