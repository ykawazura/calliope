計画は (A) の次の手として ES-SVV の見直しと 3b の相談を挙げていた。この結果を踏まえて、私はその前に係数ごとの I_svv を測ることを勧める（12 章）。この Stage ではどれも実行していない。

## 4. 事前に固定した基準

基準はジョブの前に `tasks/todo.md` に書き、変えていない。

### 4.1 最も低い K セルの質量

m_K(t) を、ρ の低い順に K 個のセルの ρ の和とする。
S_T を同じ K 個のセルでの項 T の和とし、I_T = ∫ S_T/m_K dt（台形則）と定義する。単位は e-fold である。
組が一意な時刻では dm_K/dt = S_adv + S_svv が成り立つので、Δ ln m_K = I_adv + I_svv となる。
組が入れ替わるのは値が等しいときなので、境界の項は出ない。

判定には K = 8、64 を使い、K = 1、512 は報告だけとした。

### 4.2 時間窓と検査

K ごとに、t_* を 0.60–1.05τ0 での m_K の最小の時刻とする。

- W_p = [0.60τ0, t_*]、W_s = [0.75τ0, t_*] にラベルを付ける。
- W_a = [0.75τ0, 1.05τ0] は上昇の期間を含むので、I_T だけを報告する。
- 閉じの検査: ε = |Δ ln m_K − I_adv − I_svv| ≤ 0.5 max(|I_svv|, 0.1)
- 安定性の検査: 1 個おきのレコードの I_svv との差 ≤ 0.5 max(|I_svv|, 0.1)

### 4.3 ラベルと判定

- 決められない: 閉じか安定性に落ちた場合、または Δ ln m_K > −0.1 の場合
- 掘る: I_svv ≤ −0.1 かつ I_svv/|Δ ln m_K| ≤ −0.5
- 埋める: I_svv ≥ +0.1
- 中間: それ以外

K = 8、64 の W_p、W_s の 4 つがすべて「掘る」なら (A)、すべて「埋める」なら (B)、それ以外は (C) とする。

### 4.4 関門

どれか 1 つでも落ちたら、ラベルを出さずに止まって報告すると定めた。

- 関門 R: 0–1.05τ0 の全行で、対照の行との |Δ ln ρ_min| の最大が 0.01 以下である。
- 関門 1a: 0.60–1.05τ0 の全レコードで、レコードの ρ_min と conservation.dat の行の相対差が 1e-10 以下である。
- 関門 1b: 同じ全レコードで、res = |g_c − g_c,f|/A ≤ 0.05 である。A = max(a(x_min), a(p_b), a(p_f))、a = (|div m| + |T_svv|)/ρ で、p_b、p_f は前後の行に対して予測した最小のセルである。除外するレコードはない。

## 8. 判定の弱い箇所

### 8.1 閉じの検査の分母

閉じの限度は 0.5 max(|I_svv|, 0.1) で、分母は I_svv の大きさである。
残差が降下そのものより大きくても、I_svv が大きければ検査に通る。
そこで、残差を Δ ln m_K と比べた値を表にした。これは事後の感度で、基準は変えていない。

| K | 窓 | ε | ε/\|Δ\| | 0.5\|Δ\| | ε ≤ 0.5\|Δ\| | 残差を全部 I_svv に足した値 | その値/\|Δ\| |
|---|---|---|---|---|---|---|---|
| 8 | W_p | 0.299 | 0.389 | 0.384 | 合格 | −1.376 | −1.79 |
| 8 | W_s | 0.212 | 0.658 | 0.161 | 不合格 | −0.850 | −2.63 |
| 64 | W_p | 0.091 | 0.163 | 0.279 | 合格 | −0.930 | −1.67 |
| 64 | W_s | 0.042 | 0.198 | 0.107 | 合格 | −0.532 | −2.48 |

分母が |Δ ln m_K| の基準だったなら、K = 8 の W_s が落ちて判定は (C) になる。
一方で、残差の全部を I_svv を弱める向きに割り当てても、4 つとも「掘る」の条件を満たす。
したがって、「SVV の項が負である」ことは残差より確かで、K = 8 の W_s で「降下の収支が閉じている」とまでは言えない。

### 8.2 間引きへの依存

判定の安定性の検査は 1 個おきだけを見る。
0.05τ0 に間引くと、K = 8 の W_s の I_svv は −1.713 で、−1.063 との差 0.650 は限度 0.531 を超える。
K = 8、64 の間引きの値はすべて負である（9.1 節）が、K = 8 の大きさはレコードの間隔に左右される。

### 8.3 レコードの間隔と ε の関係

K = 8 の W_p の ε は 0.01、0.02、0.05、0.1τ0 の順に 0.299、0.017、0.370、0.727 で、K = 64 の W_p は 0.091、0.009、0.286、0.306 である。
0.01τ0 の ε が 0.02τ0 より大きいので、台形則の誤差だけなら間隔とともに単調に減るという見方には合わない。
原因は調べていない。

## 11. Stage 8 の R との関係

Stage 8 の R は svv_eps0 を変えたときの L（0.6–1.2τ0 の ln ρ_min の時間平均）の応答で、R(1.0) = −0.0830、R(0.25) = +0.0218（0.6–1.0τ0 では −0.0864、+0.0500）だった。
この Stage の I_svv は、同じ流れの中で SVV の項がどれだけ寄与したかを測る量である。
2 つは別の量で、窓も K も違うので、論理的な矛盾はない。しかし比べられる形にすると大きさが合わない。

T_svv が eps0 に比例し、ほかが変わらないと仮定すると、eps0 を 2 倍にしたときの ln m_K のずれは I_svv の累積の値になる。
0.60–1.05τ0 での累積の時間平均は次のとおりである。

| K | I_svv の累積の時間平均 | \|R(1.0)\| = 0.083 との比 |
|---|---|---|
| 1 | −1.265（安定性に不合格） | 15.2 |
| 8 | −1.073 | 12.9 |
| 64 | −0.643 | 7.7 |
| 512 | −0.250 | 3.0 |

向きは合うが、K = 8、64 で約 8 倍から 13 倍の開きがある。eps0 を半分にしたときも同様で、0.5 × 0.643 と 0.5 × 1.073 は R(0.25) = +0.0218 の約 15 倍と約 25 倍である。

したがって、仮定のどこかが成り立たない。候補は次の 2 つで、どちらも検証していない。

- T_svv の大きさが eps0 に比例しない。高波数の振幅が eps0 とともに下がるなら、積はあまり変わらない。
- 移流の項が補償する。10.2 節の負の相関はこの可能性と合う。

どちらの場合も、「SVV の項の寄与」を「係数に比例する寄与」と読むことはできない。(A) は eps0 を下げれば穴が浅くなることを意味しない。
