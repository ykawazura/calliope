## 2. 問い

Stage 12 では、ES-SVV の質量の式の項 T_svv を 4 つに分けた。4 項はそれぞれほぼ eps0 に比例して大きくなり、和は打ち消しの残りとして決まっていた。
正味の値は eps0 では直接調整できないので、Stage 12 の 12 章では、質量の項をまとめて外し、128³ の 1 ケースで穴の深さを対照と比べる試験を提案した。
Stage 10 の判定 (A)（K = 8、64 で SVV の項が穴を掘る側に働いた）が穴の深さを決めているかを、eps0 を介さずに確かめるためである。

この Stage の問いは、`svv_mass = F` にすると、ρ_min の窓の平均 L が対照より上がるか下がるか、である。

外し方は次の V2 とした（`shock_viscosity.F90` の `svv_es_core`）。
既定（`svv_mass = T`）の流束は f_ρ = a(g_ρ + u·g_m)、f_m = u f_ρ + b g_m、f_h = κρ g_h である（`REPORT_stage1.md` の 3.3 節）。
`svv_mass = F` では f_ρ = f_h = 0、f_m = b g_m とする。

- 保つもの: dE/dt|svv = −D_svv、D_svv = Σ_d Σ_j b|g_m|² dV ≥ 0。質量と運動量の保存。
- 失うもの: KH = ε_d I の性質と、s の SVV。衝撃粘性は s の式に項を持たないので、s の式には人工の散逸がなくなる。

ρ̇ だけを外して f_ρ を運動量の流束に残す形（V1）は採らなかった。そのときは Σ u·ṁ = −Σ[a t (u·g_m) + b|g_m|²] の第 1 項の符号が決まらず、散逸が保証されないからである。

## 6. 物理的な妥当性の確認

保存と散逸は、N でも崩れの最後まで保たれた。

| 量 | N | C |
|---|---|---|
| 質量の相対誤差の最大 | 1.129e-7 | 5.252e-8 |
| E が増えた step の数 | 0 | 0 |
| min D_svv | 7.559e-21 | 7.687e-21 |
| max D_svv | 4205 | 17.10 |
| max R_svv | 7.4e-17 | 9.8e-17 |
| RK で合成した R_zeta の最大 | 3.0e-15 | 1.2e-14 |

質量の相対誤差は、RK 法が Σ e^s を厳密には保存しないことによる時間積分の誤差である（`REPORT_stage1.md` の 3 章「完全離散の質量誤差は O(dt³) の時間積分誤差として残る」）。N は C の 2.150 倍で、崩れの間も 1e-7 の桁に収まった。
半離散の質量と運動量の変化率は、N で dMdt_raw 2.9e-17、dP 5.6e-17 だった。
err_t は、実測の (E_n+1 − E_n)/dt と各段の寄与の重み付き和の差である（`REPORT_stage1.md` の 3 章）。N の最大 0.5367 は崩れの中の 13473 行（0.466099τ0）に出たもので、そこでの |dE/dt| は 8150 なので、比は 6.59e-5 である。dt が DT_REF の 0.1 倍を下回る前の N の最大は 2.23e-4 で、C の最大の 3.05 倍である。

安定化のための density floor、圧力の floor、一様な粘性は足していない。N の崩れの後も、係数や設定を変えて走らせ直していない。

一方、崩れの中の N の解は、等温 MHD の解の近似として妥当ではない。理由は次の 2 つである。

- 最小のセルの ρ̇ の符号が、連続の式と逆である。そのセルの ∇·u（スペクトル法の微分）は −2.503 で、圧縮している。連続の式なら、ρ の最小点では ∇ρ = 0 なので ρ̇ = −ρ∇·u = +5.69e-8 となり、ρ は増える。計算の ρ̇ は −11.574 だった。
- 構造は 1 セルの幅で、格子で解像されていない（7.3 節）。そのセルの Alfvén 速度は |B|/√ρ = 1.485e4 で、M_s ≤ 1 を前提にしたこのモデルの対象の外にある。

### 7.4 計算を止める条件が働かなかった理由

1436 行から最後の行までの両対数の傾きは、dt で 1.4996、λ_svv で −1.4999、max(|u_d| + c_f,d) で −0.4999（いずれも ln ρ_min に対して）だった。
それぞれ次のように説明できる。

- max(|u_d| + c_f,d) は最小のセルの Alfvén 速度で決まる。最後の行の値 1.485e4 は、そのセルの |B|/√ρ = 1.485e4 と一致する。したがって ρ^−0.5 に比例する。
- SVV の係数 ε_d = svv_eps0 dl_d max(|u_d| + c_f,d) も ρ^−0.5 に比例する。最後の行の ε/max(|u_d| + c_f,d) は 0.0245437 で、svv_eps0 × 2π/128 = 0.5 × 2π/128 と一致する。
- λ_svv ρ_min/ε は、1436 行、5140 行、最後の行で 371.69、371.70、371.71 とほぼ一定で、λ_svv は ε/ρ_min に比例した。V2 のヤコビアン J_mm は m を ρ で割ってから A_L を掛ける形（A_L(v_m/ρ)）なので、最小の ρ のセルで重み 1/ρ が最大になり、λ_svv が ε/ρ_min に比例すると考えられる。したがって λ_svv は ρ^−1.5 に比例する。
- dt は dt_visc = 2/λ_svv で決まるので ρ^1.5 に比例する。'track' の dt は、dt_cfl を超えたときに 0.8 dt_cfl を 3 桁に切り捨てた値に下げるので、dt·λ_svv は 1.6 のすぐ下から 2 の手前までを行き来する（1436 行以降は 1.5855–1.99986）。最大は 1.99986（4128 行）で、rk3_lim = 2.51 に届かない。

1 step の s の変化は Δs = ρ̇ dt/ρ = −c ρ^0.5 である。ここで c = 11.574 K、K = dt/ρ^1.5 は最後の行で 0.08116 で、c = 0.9393、最後の行の Δs は −1.416e-4 である。
c を一定とすると、ds/dn = −c e^{s/2} を解いて、n step の後の ρ は ρ^−0.5 = ρ_0^−0.5 + c n/2 となる。
この式で 1436 行から最後の行までの step 数を求めると 13940 で、実際の 12960 より 7.6% 多い。1436 行より後の dt·λ_svv の平均は 1.783 で、K を決めた最後の行の 1.658 より大きいので、実際の 1 step の Δs はこの見積りより大きい。
s が s_abort = −100 に届くまでの step 数は、同じ式で 1.10e22 である。

時間で見ると、ρ̇ = −11.574 のまま減れば、最後の行の ρ は 1.963e-9（コードの単位、6.25e-10τ0）で 0 になる。
dt が ρ^1.5 に比例して縮むので、step 数はこの短い時間の間に増え続ける。値は有限のまま、|s| は s_abort に届かず、dt·λ_svv は rk3_lim を超えない。dt には下限がないので、「dt を下げられない」という停止も起きない。
その結果、計算は止まらずに進み、BUDGET が止めた。全 14397 行のうち 13124 行（91.2%）は、dt が初めて DT_REF の半分を下回った 1273 行以降の行である。

E は N でも C でも単調に減った（増えた step は 0）。1436 行から最後の行までの N の E の減りは 0.002763 で、全体の減り 18.51 のうちわずかである。E が減っても、ρ の下限は保たれない。
