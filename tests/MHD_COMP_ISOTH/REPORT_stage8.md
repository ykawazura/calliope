# MHD_COMP_ISOTH Stage 8 報告: 密度の穴の散逸係数への依存（128³）

- 日付: 2026-11-07
- branch: `feature/isoth-logrho-shock`（Stage 7 の a6b0d05 の上。ソースは変えていない）
- 対象: turb1（M_s = 1）の 128³ で、svv_eps0 と C_shock を 2 倍と 1/2 に変えた 4 ケースと対照
- 計算機: ps1 のジョブ 484820（A_dev、512 コア、25 分 56 秒、約 221 core-h）。解析はログインノード

## 1. 結論

- 事前に固定した基準（5 章）での判定は、svv_eps0 の軸も C_shock の軸も「鈍い」である。基準の対応に従い、3b（256³ の restart）を省いて、ES-SVV の質量の項が局所最小で ρ を下げるかをスナップショットの上で調べることを提案する。提案なので、この Stage では実行していない。
- 「鈍い」は閾値の近くでの判定である。応答 R の絶対値は最大 0.083 で、閾値 δ = 0.1 の 0.83 倍だった。R の符号は 4 ケースとも、仮説 N（ES-SVV の質量の項が穴を深くする）と衝撃粘性の対照から予想した向きと同じだった。δ を 0.083 以下に取れば svv_eps0 の軸は「深まる」に変わる。基準は変えていないが、この結果は仮説 N を退ける根拠にならない。
- L（0.6–1.2τ0 での ln ρ_min の時間平均）の変化は、係数を 2 倍変えたときが最大 0.083 で、N を 2 倍にしたときの −0.211（64³ → 128³）と −0.598（128³ → 256³）より小さい。128³ の応答で見る限り、係数の大きさだけでは ρ_min の解像度への依存を説明できない。256³ の応答は測っていない。
- 5 ケースとも 1.2τ0 まで進み、非有限値はなく、全 step で dt ≤ dt_cfl だった。svv_eps0 = 1.0 も、C_shock = 1 も不安定にならなかった。

## 2. 問い

Stage 7 の判定は「中間」で、次の 2 つの仮説が残った。

- 仮説 P: 穴は物理的な構造で、散逸のスケールまで細くなる。散逸を強めると穴は浅くなる。
- 仮説 N: ES-SVV の質量の式の項が最小値原理を満たさず、局所最小で ρ を下げる。svv_eps0 を上げると穴は深くなりうる。

衝撃粘性 ζ = C_shock Δ² S[max(0, −D)] は運動量の式だけに入り、圧縮でだけ働く。
質量の式に入らない散逸なので、C_shock の軸は svv_eps0 の軸の対照になる。
svv_eps0 を上げて穴が深くなり、C_shock を上げて浅くなれば、仮説 N を強く支持する。

## 5. 事前に固定した判定の基準

### 5.1 ジョブの前に固定した基準

次の基準はジョブの前に `tasks/todo.md` に記録した。

ケース c ごとの量は次のとおりである。

- L_c: 0.6τ0 ≤ t ≤ 1.2τ0 での ln ρ_min(t) の時間平均（conservation.dat の毎 step の値）。主な量とする。
- m_c: 0 ≤ t ≤ 1.2τ0 での ρ_min(t) の最小値
- H_c: out3d の t = 0.6, 0.7, …, 1.2τ0 で数えた、ρ < 0.1 の局所最小の数の和
- V_c: 同じ時刻の F_V(ρ < 0.2) の平均
- 応答 R_c = L_c − L_対照

閾値は δ = 0.1（ρ_min で約 10%）とした。
対照と基準の |L の差| が δ/10 を超えた場合は、判定を「決められない」とする。

各軸の判定は次のとおりである。

- 深まる: 係数を 2 倍にしたケースで R ≤ −δ
- 埋まる: 係数を 2 倍にしたケースで R ≥ +δ、かつ 1/2 にしたケースで R ≤ −δ
- 鈍い: 両方とも |R| < δ
- どれにも当たらなければ「単調でない」とする。

次の手の対応は次のとおりである（報告で提案するだけで、この Stage では実行しない）。

- SVV の軸が「深まる」で、C_shock の軸が「埋まる」か「鈍い」: 仮説 N を強く支持する。ES-SVV の最小値原理の見直しを相談し、3b を e1.0 で回す。
- 両方の軸が「埋まる」: 仮説 P と矛盾しない。3b を e1.0 で回し、手順 4（DNS 参照）を相談する。
- SVV の軸が「鈍い」: 係数からはどちらの仮説も支持できない。3b を省き、ES-SVV の質量の項が局所最小で ρ を下げるかをスナップショットの上で調べる。
- それ以外: 結果をそのまま報告して相談する。

ln(m/m_対照)、H/H_対照、V/V_対照、SVV の項の符号、数値由来の疑いの割合は補助の量で、判定には使わない。

### 5.2 ジョブの後に変えた「到達」の定義

ジョブの後で 1 か所を変えた。
変えた時点で見ていたのは exit_status と最後の step の時刻だけで、L、R、m は見ていなかった。

- 変更前: 実行は t_final ≥ t − 1e-6τ0 のとき時刻 t に達したとする。
- 変更後: 最後の step の dt を使い、t_final ≥ t − dt/2 のとき達したとする。
- 理由: コードは t ≥ t_end − dt/2 で止まる（`src/time.F90` の t_end_reached）。t_end の手前で規則どおり止まる実行が 3 本あり、対照もその 1 本である（t_end の 0.36 dt 手前で止まった）。変更前の定義では対照が未到達になり、全ケースが 0.6–1.0τ0 で比べられることになる。

変更の前後で判定は変わらない（6.3 節）。

次の表は、結果を見た後で選んだ見方で、判定には使わない。

0.8τ0 の穴全体でも 22 個のうち 17 個で SVV の項が ρ を下げ、−div m が ρ を下げるのは 6 個だけである。

一方、対照の ρ_min は 0.9τ0 の 0.070 から 0.957τ0 の 0.057 へもう一度下がる。

つまり、SVV の項が ρ を下げる時刻は、ρ_min が下がる時刻の全体とは一致しない。

Stage 7 の 256³ の最小点でも、SVV の項の符号は同じ順に変わる。
0.5–0.818τ0 では負で、0.893–0.921τ0 では正で、その後は 0.965τ0 で負、1.0τ0 で正である。

この表から「SVV の項が穴を掘っている」とは結論できない。
5 ケースは同じ流れの変形なので、穴は独立な標本ではない。
また 0.1τ0 ごとの瞬間の値で、その間の時間積分は分からない。
それでも、Q = 1 の拡散なら局所最小で ρ を下げる符号は現れない。
その符号が 0.8τ0 の穴の多くに現れることは、スナップショットでの直接の検査を提案する根拠になる。

### 7.2 次の手の提案

3b を省き、ジョブの要らない次の解析を先に行うことを提案する。
解析はログインノードで済み、使うのは 128³ の 5 ケースの 8 時刻と、256³ の 9 時刻の既存の out3d である。

1. 穴の領域の質量収支: ρ < θ の領域で、SVV の項と −div m を体積積分する。点の値と違って、SVV が穴の領域から質量を運び出しているかを、1 点の符号によらずに見られる。
2. A_L の流束の分解: t = Q∂w + u·Q∂u を c_s²Q∂s と、Q∂(u²/2) と u·Q∂u の差に分ける。Stage 7 の 7.2 節の 4 で立てた機構（Q をかけると拡散の形にならない）で、局所最小の負の値を説明できるかを確かめる。
3. 判定の基準は、解析の前に決めて `tasks/todo.md` に記録する。

3b と比べた費用は次のとおりである。

| 選択肢 | 計算の費用 | 分かること | 分からないこと |
|---|---|---|---|
| スナップショットの解析 | ジョブなし | SVV の項が穴の質量をどれだけ動かすか、負になる原因 | 係数を変えたときの解の応答（256³） |
| 3b（`e1.0_C2` 相当、256³、0.578 → 1.0τ0） | 約 1,430 core-h（30 分のジョブ約 13 本。基準の係数の 770 core-h と 7 本に、128³ の step 数の比 1.86 を掛けた見込み） | 256³ でも L の応答が小さいか | 応答の原因 |

3b の費用は高く、128³ の応答からは 256³ でも大きな応答を見込む根拠がない。
ただし、256³ の m は 128³ の約 1/6 である（0.0090 と 0.0566）。128³ で応答が小さいことは、256³ で小さいことを保証しない。
そのため 3b は取り消さず、解析の結果を見て改めて決めることを提案する。

3b を回す場合は、`stage6q/ana/c256_t1817`（t = 0.578τ0）から svv_eps0 = 1.0 の 1 ケースを続け、`stage6q/turb/turb1_N256` と比べることを提案する。
L の窓は 0.6–1.0τ0 で（既存の実行の値は −2.9817）、閾値は δ = 0.1 のままとする。
0.578τ0 までは既定の係数で進んだ場なので、この比較で分かるのは 0.578τ0 以降の応答だけである。

ES-SVV の最小値原理の見直しは設計の変更なので、解析の結果とあわせてユーザーと相談する。
