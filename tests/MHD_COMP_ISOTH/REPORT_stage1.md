## 1. 結論

Stage 1 の合格基準（6 節）は、既定設定（ES-SVV、C_shock = 2）ですべて満たした。
U4（ρ = 1, u = ±4、c_s = 1 の衝突流）の衝撃波は、ユーザーの決定により N ≥ 1024 で判定した。
結果は次のとおりである。

- 正値性: 既定設定の衝撃波試験 20 本が、非有限値も CFL 停止もなく t_end に達した。
- 保存: 半離散の質量の時間微分は |dM/dt_raw| / dM/dt_abs ≤ 5.5e-15、運動量は max|ΔP| / √(2 M0 E_kin,max) ≤ 5.1e-15 である。
  完全離散の質量誤差は時間刻みに対して O(dt³) で縮む（観測次数 3.03–3.13）。
- 人工粘性の散逸性: shock viscosity ζ の恒等式の残差は max|R_ζ| / Σρζ D² ≤ 7.9e-14 である。
  ES-SVV は、散逸 D_svv ≥ 0 が構成から成り立ち、エネルギー寄与 ε_svv = −D_svv の残差は max|R_svv| / A_svv ≤ 8.3e-16 である。
  ES-SVV の全実行で ε_svv > 0 になったステップは、滑らかな単純波の 4 ステップだけで、どれも丸め誤差の大きさである（7.3 節）。
- 滑らかな解: 音波の振幅・位相誤差は 1.3e-6、8.8e-7 である。破砕前の単純波は C_shock = 0 でスペクトル収束し、C_shock = 2 では観測次数 1.87–1.99 で収束する。
- 衝撃波: U1・U2・Sod（N ≥ 512）と U4（N ≥ 1024）の中間状態・衝撃波速度・位置・overshoot が基準を満たし、L1(ρ) の観測次数は 0.921–0.985 である。
  U4 の膨張側の中間状態 ρ* の誤差は N = 1024, 2048, 4096 で 6.5e-3, 9.7e-4, 1.5e-4、overshoot は 4.1%, 3.4%, 3.7% である。
- 分割非依存: x, y, z 方向 × 1, 2, 4 rank の ρ, u の差は ≤ 2.9e-14 である。dt を固定して restart で継いだ実行の解は、継がない実行とビット一致する（7.5 節）。
- 異常検出: NaN を注入すると終了コード 1 で止まる。dt λ_svv が安定限界 2.51 を超えても終了コード 1 で止まる。
- 回帰: MHD_INCOMP の出力がバイト一致する。

U4 の N = 512 は参考として載せた（7.1 節）。ρ* の誤差 2.7%、衝撃波速度の誤差 5.3%、overshoot 5.5% で、いずれも基準を超える。
N = 512 では膨張波の星領域の立ち上がりの過渡が t_end = 0.4 までに収まらない（6 節）。

初版の SVV（`svv_form = 'linear'`）は U4 の N = 1024 で ρ* の誤差 3.0e-2、overshoot 5.3% になり、基準を満たさない。この値は初版の報告と一致する。
ES-SVV ではこの二つが 6.5e-3 と 4.1% に下がった。
ただし、ES-SVV と `linear` では dt が 6.6 倍違うので、改善が SVV の形だけによるとは限らない（7.1 節）。

ES-SVV の費用は次のとおりである。

- 硬さの比 F = λ_svv / Σ_d ε_d Λ_d^s（`linear` では 1）は Sod で 7.0–8.2、U1 で 2.0–2.3、U2 で 3.5–4.6、U4 で 15.4（N = 256）から 25.5（N = 4096）である。
- dt の上限が F に応じて小さくなり、N = 1024 のステップ数は `linear` の 1.7 倍（U2）から 6.6 倍（U4）になる。
- 右辺 1 回あたりの 3D FFT は `linear` の 2.2 倍で、16³ の 3D 計算の 1 ステップは 2.4 倍の時間がかかる。

`linear` での U4 の誤差の診断は 8 節に、未解決の問題は 12 節にまとめた。

## 3. 離散化

### 3.1 状態変数と方程式

状態は Fourier 係数 ŝ = F[ln ρ]、m̂ = F[ρu]、B̂ である。
格子点 x_j では ρ_j = exp(s_j) > 0 なので、正値性は構成的に保証される。
長さは grid.F90 の規約に従い L = 2π lx、波数は k_n = n/lx である（Stage 1 の試験は lx = 1）。

微分は ∂_N,d = F⁻¹ i k_d M F とする。k_d は Nyquist 波数で 0 にし、M は 2/3 フィルタである。
2/3 フィルタは各方向で |k_d| ≥ (2/3) k_Nyq,d の成分を 0 にするので、残る最大波数は k_c = N/3（lx = 1）である。
各 RK 段の後に m と B にフィルタを掛け、s には掛けない（既定 `filter_lnrho = F`）。

方程式（定式化 C）は次のとおりである。

- 質量: ṡ_j = −(∇_N·m)_j / ρ_j。
  s にフィルタを掛けず `pruned = F` なら、Σ_j ρ_j ṡ_j = −Σ_j (∇_N·m)_j = 0 が丸め誤差の範囲で成り立つ（微分の k = 0 成分は 0）。
  RK 法は非線形量 Σ e^s を厳密には保存しないので、完全離散の質量誤差は O(dt³) の時間積分誤差として残る。
- 運動量: ṁ = −∇_N·[ρuu + (c_s²ρ + B²/2 − q) I − BB]。流束を格子上で作ってから FFT する。
  右辺の k = 0 成分は 0 なので、全運動量は丸め誤差の範囲で保存する。
- 誘導: 旧コードの −∇_N×(B×u) をそのまま使う。η 一定の拡散は積分因子で扱い、`div_free` も旧コードのものを使う。

### 3.2 shock viscosity

- D = ∇_N·u とする。微分には運動量と同じ ∂_N（同じ M）を使う。
- ζ = C_shock Δ² S[max(0, −D)]。S は各有効方向（nl > 2）に、半幅 1 の局所 max を `shock_nmax` 回、
  正の重み [1, 2, 1]/4 の平滑化を `shock_nsmooth` 回、方向ごとに順に掛ける。
  ζ ≥ 0 であり、圧縮のない所では ζ = 0 になる。Δ は有効方向の dl_d の最小値である（`shock_dl > 0` で上書き）。
- 局所 max と平滑化はランク境界をまたぐ。隣接ランクを `grid.F90` の `idx2procid` で求め、`MPI_Sendrecv` で 1 層ずつ halo を交換する。
  各格子点の演算順は分割に依らないので、ζ は分割に対してビット一致する。
- 粘性応力 q_j = ρ_j ζ_j D_j を格子上で作り、圧力に −q として入れてから FFT する。FFT 空間の Gaussian は使わない。
- エネルギーへの寄与は Σ_j u_j·(∇_N q)_j である。∂_N が反自己共役（M が自己共役な射影）なら
  Σ u·∇_N q = −Σ q ∇_N·u = −Σ ρζD² ≤ 0 が成り立つ。
  `budget.dat` には残差 R_ζ = Σ u·∇_N q + Σ ρζD² を毎段出す。

### 3.3 spectral vanishing viscosity

SVV（Tadmor 1989; Maday, Ould Kaber & Tadmor 1993）は、切断波数の近くだけに掛かる 2 階の粘性である。
減衰率は λ(k) = Σ_d ε_d k_d² Q(|k_d|) とし、核 Q は a = |k_d| について次のように決める。

- a ≤ m_N（= `svv_mN`·k_c）: Q = 0
- m_N < a < k_c: Q = exp(−r²)、r = (k_c − a)/(a − m_N)
- a ≥ k_c: Q = 1（`svv_above_kc = T`, 既定）または 0（F）

a ≥ k_c の成分を持つのは、フィルタを掛けない s だけである。

係数は ε_d = `svv_eps0`·dl_d·max(|u_d| + c_f,d) で、各ステップの第 1 段で決めてそのステップ中は固定する。

B には線形の減衰 Ḃ̂ += −λ(k) B̂、λ(k) = Σ_d ε_d k_d² Q(|k_d|) を掛ける。
B²/2 は B の二次形式で λ ≥ 0 なので、この項のエネルギー寄与は −Σ_k λ|B̂|² ≤ 0 である。

ρ と m には、既定（`svv_form = 'entropy'`）でエントロピー変数の流束形（以下 ES-SVV）を掛ける。
エントロピー変数は w = ∂E/∂(ρ, m) = (w_ρ, u)、w_ρ = c_s² s − u²/2 である。
方向 d ごとに、m のフィルタ M の内側と外側に分けた演算子

- A_L,d = F⁻¹ σ_d M F、A_H,d = F⁻¹ σ_d (1 − M) F
- σ_d = i k_d √Q(|k_d|)（Nyquist 成分では |k_d| √Q とし、実の場を実の場に写す）

を定め、次の流束を格子上で作る。

- g_ρ = A_L,d w_ρ、g_m = A_L,d u、g_h = A_H,d w_ρ
- f_ρ = a (g_ρ + u·g_m)、f_m = u f_ρ + b g_m、f_h = κ ρ g_h
- a = ε_d ρ / c_s²、b = ε_d ρ、κ = ε_d / (c_s² + max_x |u|²)

右辺への寄与は ρ̇ = −Σ_d (A_L,d* f_ρ + A_H,d* f_h)、ṁ = −Σ_d A_L,d* f_m で、s には ṡ = ρ̇/ρ として入れる。
A_H は帯域外の成分を持つ s だけに掛かる（m の帯域外は各段のフィルタで 0 になる）。
この形には次の性質がある。

- σ_d(0) = 0 なので Σ_j ρ̇_j = Σ_j ṁ_j = 0 が丸め誤差の範囲で成り立つ。全質量と全運動量は変わらない。
- エネルギーへの寄与は Σ (w_ρ ρ̇ + u·ṁ) dV = −D_svv で、
  D_svv = Σ_d Σ_j [a t² + b |g_m|² + κ ρ g_h²] dV、t = g_ρ + u·g_m である。
  導出には A* の定義 Σ φ A*ψ = Σ (Aφ) ψ だけを使う。
  a, b, κ ≥ 0 なので、D_svv ≥ 0 は状態によらず成り立つ。
  ただし s の時間微分にフィルタを掛けない（`filter_lnrho = F`）場合に限る。
  M は 0 か 1 の値をとる射影なので、各段の後で m に掛けるフィルタは ṁ = −A_L* f_m を変えない。
- 流束を f = K A_L w と書くと、保存変数 U = (ρ, m) に対する Hessian H = ∂w/∂U との積は各点で KH = ε_d I になる。
  したがって、U の摂動に対する作用は凍結係数で −ε_d A_L* (·) A_L と同じ形になり、Galilei 変換で硬さが変わらない。
  帯域外の部分は κ(c_s² + |u|²) ≤ ε_d を満たす。
- `budget.dat` には残差 R_svv = dE/dt|svv + D_svv と、丸め誤差の尺度 A_svv = Σ |∂E/∂U · U̇_svv| dV を毎段出す。

`svv_form = 'linear'` では、旧版の形 ṁ̂ += −λ m̂、ṡ += (1/ρ) F⁻¹(−λ F ρ) を掛ける。
この形のエネルギー寄与は Σ_ij c_ij (w_i − w_j)·(U_i − U_j)/2（c_ij = −Λ_ij、Λ は −λ(k) の格子上の行列）である。
符号が定まるのは c_ij ≥ 0（正の拡散ステンシル）の場合に限られ、SVV の核ではこれが成り立たない（10.2 節）。

FFT の回数は、ES-SVV の右辺 1 回あたり 3D で 53 回で、`linear` の 24 回の 2.2 倍である。
内訳は、w_ρ の順変換 1 回、勾配の逆変換 15 回、流束の順変換 15 回の追加である（û は ∇·u の計算のものを使う）。

### 3.4 時間積分と CFL

時間積分は既存の eSSPIFRK3 だけに対応する（gear3 と RK4 は停止する）。
展開すると有効重みは b = (1/4, 3/16, 9/16)、段の時刻は c = (0, 2/3, 2/3) である。

dt は dt ≤ min(dt_adv, dt_visc) で決める。

- dt_adv = `cfl` / Σ_d max(|u_d| + c_f,d)/dl_d。和は有効方向だけにとる。c_f,d は方向 d の fast 波の速さで、
  c_f,d² = [c_s² + v_A² + √((c_s² + v_A²)² − 4 c_s² v_A,d²)]/2 である。
- ES-SVV（既定）: 1/dt_visc = max(ζ_max Σ_d k_d,max² / `cfl_visc` + λ_svv / `cfl_svv`, Σ_d ε_d Λ_d^B / `cfl_visc`)。
  Λ_d^B は B に残る波数での k_d² Q の最大値である。
- `linear`: dt_visc = `cfl_visc` / max(ζ_max Σ_d k_d,max² + Σ_d ε_d Λ_d^m, Σ_d ε_d Λ_d^s, Σ_d ε_d Λ_d^B)。

λ_svv は、凍結係数の ES-SVV の Jacobian J（(s, m) について）の固有値の絶対値の最大値の推定である。
`linear` では各 Fourier 成分の減衰率がそのまま固有値になるが、ES-SVV では K が空間で変わるので固有値が k_d² Q から決まらない。
そこで冪乗法で求める。

- J v は有限差分 [G(U + h v) − G(U)]/h（h = 1e-7、G は ES-SVV の (ṡ, ṁ)、ε_d は固定）で作る。
- 最初の呼び出しで `svv_pi_init` = 50 回反復し、以後は前のステップのベクトルから毎ステップ 1 回反復する。
- 初期ベクトルは s の成分だけを持つ (−1)^Σ_d(i_d−1) (1 + 0.3 Σ_d cos(2π(i_d − 1)/nl_d + 1)) で、和は有効方向だけにとる。
  大域格子番号の関数なので分割に依らない。
- `svv_pi_check` = 100 ステップごとに、相対変化 < 1e-3 まで（最大 200 回）反復する。
  そこで dt λ_svv が eSSPIFRK3 の負の実軸上の安定限界 2.51 を超えていたら、値を出力して停止する。dt を黙って直すことはしない。
- `cfl_svv` = 2.0 は 2.51 に対して 25% の余裕である。
- 停止を決めた検査の行は `cfl.dat` に書かない。そのときの dt λ_svv は停止時のメッセージにだけ出る。
- 冪乗法のベクトルは restart ファイルに書かない。restart の直後は `svv_pi_init` 回の反復からやり直すので、dt を固定した実行でも `cfl.dat` の λ_svv が継がない実行から最大 1.6% ずれる（7.5 節）。

硬さの比 F = λ_svv / Σ_d ε_d Λ_d^s は `linear` では 1 だが、ES-SVV では Fortran の実行で Sod が 7.0–8.2、U1 が 2.0–2.3、U2 が 3.5–4.6、U4 が 15.4（N = 256）から 25.5（N = 4096）になる（7.4 節）。
F は構造が何格子にわたるか（c t / dl）にほぼ依存し、t と N が大きいほど増えるので、毎ステップ測る必要がある。
近傍 3 格子の密度比では F を上から抑えられない（F / 密度比 = 1.5–2.9）。

冪乗法の初期ベクトルの符号を全方向（nl = 2 の方向を含む）でとると、1D 試験（nly = nlz = 2）でベクトルが y, z の Nyquist 部分空間に入る。
そこでは M = 0 なので A_H だけが働き、λ が一様部分空間の 0.483 倍になる（試作、U2, N = 512 の初期状態で 1.19e3 対 2.47e3）。
J は x だけに依る係数を持つのでこの二つの部分空間を結合せず、有限差分の O(h) の非線形性を通してしか一様部分空間に移らない。
一方、物理的な場は nl = 2 の方向で一様に保たれ、Nyquist 部分空間の成分を持たない。
初回の Fortran 実行はこの誤りのため dt_visc が試作から最大 6.8% ずれたので、符号と変調を有効方向だけでとるよう直した（7.5 節）。
一様部分空間でも、50 回の反復では λ が 3.4% 小さい（2.385e3 対 2000 回の 2.470e3）。この差は `cfl_svv` の余裕に収まる。

いずれの量も第 1 段の状態から求める。dt の変更には既存の `reset_dt` を使う。
試験はすべて dt を固定し、`reset_method = 'stop'` にした。dt が上限を超えたら、dt を黙って変えずに停止する。

`cfl` の意味は旧モデルから変わった。旧モデルは dt = cfl·min_d (dl_d / max_vel_d) で、新しい式は方向の和をとるので、
3 方向が同等な 3D では同じ cfl で dt が最大 1/3 になる。1D では両者は一致する。

### 3.5 異常検出と質量補正

- 非有限値は浮動小数点数の指数部のビットで判定する（`transfer` を使い、`-O3` の最適化で判定が消えないようにした）。
  |s| > `s_abort`（既定 100、exp の桁あふれを防ぐため 700 以下を強制）も同じく検出する。
  検出したらランク・位置・値を出力して `MPI_Abort` で止める（終了コード 1）。
- 密度の床上げはしない。旧コードの `check_floor` は呼ばない。namelist の `rho_min` は読むが使わない。
- 一様な質量補正 `mass_correction`（既定 F）は、各ステップの初めに ŝ(k = 0) += ln(M0/M) とする。
  これは全域の ρ に同じ比 M0/M を掛けることに当たる。補正量はステップごとと累計を `conservation.dat` に残す。
  全質量は戻るが、局所的な質量保存は回復しない（失われていない場所にも質量を足す）。
- 基準の M0 は各実行の最初のステップでとる。restart すると M0 は restart 時点の値になる。

### 3.6 出力

| ファイル | 内容 |
|---|---|
| `conservation.dat` | t, dt, M, (M − M0)/M0, P_x,y,z, E の内訳と和, min/max ρ, max ζ, min D, Σρζ D² dV, 質量補正量（ステップごとと累計） |
| `budget.dat`（`budget = T`） | dM/dt（実測・raw・射影後・規模 Σ\|∇_N·m\|）、dE/dt（実測・各段の重み付き和）、時間積分誤差 err_t、ε_ideal, ε_shock, −Σρζ D², R_ζ, max\|R_ζ\|/Σρζ D², ε_force, ε_res, ε_nu, ε_lmd, E_n, E_n+1, ε_svv（全体）, ε_svv,B, −D_svv, R_svv, 3 段のうちでの \|R_svv\|/D_svv と \|R_svv\|/A_svv の最大値（26 列）。率の列は各段の値を b で重み付けした和 |
| `cfl.dat` | t, dt, dt_adv, dt_visc, 方向ごとの max(\|u_d\| + c_f,d), ζ_max, 粘性の重み付き平均, ε_d, λ_svv, F_svv, dt λ_svv, 冪乗法の反復数（16 列） |
| `out1d/line_NNNNN.dat` | 第 1 の有効方向に沿った線上の ρ, u, B, ζ, D（ASCII） |
| `shock_selftest.dat`（`shock_selftest = T`） | 解析的な D から作った ζ の全格子点の値（分割非依存の検査用） |

エネルギーは E = Σ_j [m_j²/(2ρ_j) + c_s² ρ_j (s_j − 1) + B_j²/2] dV である。
∂E/∂m = u、∂E/∂s = ρ(c_s² s − u²/2) である。そこで dE/dt = Σ u·ṁ + Σ (c_s² s − u²/2) ρ ṡ（+ B の項）として、各項の寄与を分ける。
ε_ideal は、右辺の陽的項の寄与から ε_shock, ε_force, ε_svv を引いた残りである。
err_t は、実測の (E_n+1 − E_n)/dt と各段の寄与の重み付き和の差である。

## 5. 旧モデルの破綻の原因と SVV の採用

旧設定（ρ を状態にし、床上げあり）に近い組合せとして、ln ρ を状態にしたうえで C_shock = 1、SVV なし、`filter_lnrho = T` で
U2（N = 512）を走らせると、t = 0.0158 で CFL の検査により停止した。それまでに質量誤差は 1.1e-2、ρ_min は 1.4e-3 になった。

Python の試作で原因を調べた結果は次のとおりである。

- `filter_lnrho = T`・SVV なしでは、N ≥ 1024 かつ C_shock ≤ 4 で非有限値になって止まる。
  C_shock = 8 でも N = 2048 では t = 0.25、N = 4096 では t = 0.031 で止まる。必要な C_shock は N とともに増える。
- 見立ては次のとおりである。解像されない衝撃波と鋭い初期条件が k_c 付近の成分を作り、大域的な射影（sinc の裾）がそれを全領域に広げる。
  それが膨張波の音速点付近（u ± c がパターン速度に近い所）で共鳴的に成長する。
  Ray et al. (2011, PRE 84, 016301) が報告した "tyger" と同種の現象とみている。
- 否定した仮説は次のとおりである。
  - エイリアシング: pad = 2, 4 の過剰積分でも破綻する。
  - 時間積分: 破綻は dt にも cfl_visc にも依らない。
  - 一様流の局所的な不安定、滑らかな膨張波そのものの不安定: 膨張波だけ、衝撃波だけの問題はどちらも安定である。

これを受けて SVV を試し、`filter_lnrho = F` と組み合わせると U1・U2・U4・Sod が N = 512–4096 で安定になった。
退けた組合せは次のとおりである。

| 組合せ | 結果 |
|---|---|
| SVV を m だけに掛ける | 破綻する |
| `filter_lnrho = F` で SVV なし | 8 ステップで破綻する |
| SVV と `filter_lnrho = T` | U4 で t = 0.4 までに質量が 92% 増える |
| 既存の lmd_h（ln ρ の超拡散）と nu_h | 質量誤差が 1e-2 になる（lmd は ln ρ に掛かるので質量を保存しない） |
| べき型の核 (k/k_c)⁸ | L1 は約 15% 小さいが、全波数を減衰させる |

SVV を既定で有効にすることと、Q(k ≥ k_c) の扱いは、設計変更なのでユーザーに確認して決めた。
5 節の試作は、すべて初版の `linear` の SVV で行った。

## 6. 判定基準

Fortran の一括試験の前に、次の基準を数値で固定した。「見た目がきれい」は合格にしない。

| 項目 | 量 | 基準 |
|---|---|---|
| 正値性 | 既定設定の全衝撃波試験 | 非有限値・CFL 停止なしで t_end に到達 |
| 半離散の質量保存 | max\|dM/dt_raw\| / dM/dt_abs（`filter_lnrho = F`, `pruned = F`） | ≤ 1e-12 |
| 完全離散の質量誤差 | max\|ΔM/M0\| の dt 依存 | 観測次数 ≥ 2.7 |
| 運動量保存 | max\|ΔP\| / √(2 M0 E_kin,max) | ≤ 1e-11 |
| 粘性の恒等式 | max\|R_ζ\| / Σρζ D² | ≤ 1e-10 |
| SVV の散逸性（ES-SVV） | max\|R_svv\| / A_svv、各ステップの D_svv（3 段の重み付き和） | ≤ 1e-10、D_svv ≥ 0 |
| 音波（C_shock = 0, N = 32, 64, 1 周期） | 振幅誤差・位相誤差 | ≤ 1e-5 |
| 単純波（破砕前, t = t_b/2）, C_shock = 0 | Linf(u) | N を倍にするごとに 1 桁以上減る（丸め・時間誤差の床まで） |
| 単純波, C_shock = 2 | Linf(u) の観測次数（N ≥ 64 → 2N） | ≥ 1.8 |
| 衝撃波（既定, U1・U2・Sod は N ≥ 512、U4 は N ≥ 1024） | 中間状態 ρ* の相対誤差 | ≤ 1% |
| | 衝撃波速度の相対誤差 | ≤ 1% |
| | 衝撃波位置のずれ | 2 格子以内 |
| | over/undershoot（跳びに対する比） | ≤ 5% |
| | L1(ρ) の観測次数（N = 512 → 4096 の当てはめ） | ≥ 0.8 |
| 分割非依存 | x, y, z 方向 × 1, 2, 4 rank の ρ, u の最大差 | ≤ 1e-10（ζ の自己検査はビット一致） |
| CFL | 全ステップで dt ≤ min(dt_adv, dt_visc) | `reset_method = 'stop'` で保証 |
| 異常検出 | NaN の注入 | 非 0 の終了コードで停止 |

初版から変えた基準は次の 3 点である。

- SVV の散逸性を加えた。初版の SVV（`linear`）はエネルギー寄与の符号が保証されないので合否に使わなかったが、
  ES-SVV では D_svv ≥ 0 が恒等的に成り立つので、R_svv を丸め誤差と比べる。
  規格化は A_svv（各点の寄与の絶対値の和）とする。滑らかな波では D_svv が丸め誤差の大きさまで小さくなり（音波 N = 64 の全段で 8.7e-33–6.6e-20）、
  |R_svv| / D_svv が意味を持たないからである。|R_svv| / D_svv も併せて報告する。
- U4 の衝撃波の基準を N ≥ 1024 に限った（ユーザーの決定）。
  N = 512 では、膨張波の星領域の立ち上がりの過渡が t_end = 0.4 までに収まらない。
  誤差はほぼ c t / dl で決まり、試作の ES-SVV（C = 3）では N = 512 の t = 0.24, 0.32, 0.40 で 0.29, 0.088, 0.028、
  c t / dl が同じ N = 1024, t = 0.20 で 0.026 である。
  t_end は二つの界面から出る扇が出会う前に限られるので、N = 512 では星領域が 33 格子しかない。
  N = 512 の値は 7.1 節に載せる。
- 単純波（C_shock = 2）の観測次数の基準を、N ≥ 64 から 2N への次数に当てるよう判定スクリプトに入れた。
  初版の判定スクリプト（c5d971d）はこの基準を当てておらず、初版の報告では手で判定した。
  N ≥ 64 という範囲は、初版の結果を見た後に決めたものである。

## 7. 結果

試験は ps1 の PBS `A_dev` で走らせた。判定と後処理も ps1 で行い、判定表と各ケースの要約（`post.tgz`、数 MB）だけを手元に持ち帰った。
1D 試験は横方向を nl = 2（`pruned = F`）にして代用した。横方向は一様で、2/3 フィルタで k = 0 だけが残る。
c_s = 1（beta0 = 2）、lx = 1（L = 2π）とし、Riemann 問題は R 状態を (L/4, 3L/4) に置いた周期問題である（界面は 2 枚）。
初期の界面は幅 1 格子の tanh にした。
dt は、試作 `proto1d.py` を既定設定で走らせて min(dt_adv, dt_visc) の全ステップの最小値を問題と N ごとに求め、それに 0.7 を掛けて固定した。
ES-SVV では硬さの比 F が N とともに増えるので、dt は 1/N に比例せず、N ごとに測る必要がある。
既定設定の全実行で、dt / min(dt_adv, dt_visc) の全ステップの最大値は 0.699–0.701 である。

表の列の定義は次のとおりである。

- ρ_min: 全ステップを通した最小値（`conservation.dat`）
- L1(ρ): t_end での ∫\|ρ − ρ_exact\| dx
- ρ* 誤差: 中間状態の中央半分での平均の相対誤差（2 つの界面のうち大きい方）
- 速度誤差: 衝撃波位置の時系列に直線を当てはめた速度の相対誤差
- 位置: t_end での衝撃波位置のずれ（格子数）。位置は (ρ − ρ_up)/(ρ_dn − ρ_up) の積分から求める
- over/under: 衝撃波の両側 24 格子の窓での over/undershoot の大きい方（跳びに対する比）
- dM/dt_raw, ΔP, R_ζ: 6 節の規格化での最大値
- R_svv: 各段の max\|R_svv\| / A_svv の最大値。
  `linear` と SVV なしのほか、`filter_lnrho = T` のケース（fs, fs_mc, fs_nt6, pruned）も「-」とした。
  `filter_lnrho = T` では ṡ に射影が掛かるので ε_svv = −D_svv が恒等式にならず、|R_svv| / A_svv が 2e-3–1e-2 になる。
- min D_svv: 各ステップの D_svv（3 段の重み付き和）の最小値。`linear` と SVV なしは「-」
- ∫ε_svv: SVV のエネルギー寄与の時間積分（横方向の面積 (2π)² を含む体積積分）

- NaN の注入（2 rank、ステップ 5）: ランク・位置・値を出して `MPI_Abort` し、終了コード 1 で止まる。
- 試作との照合（ES-SVV, U2, N = 512, 1000 ステップ）: Fortran と `proto1d.py` の相対差は、

## 8. `linear` での U4 の誤差の診断

この節は、初版（`svv_form = 'linear'`、C_shock = 2）で U4 が基準を満たさなかった原因を、試作で調べた記録である。
この節の「既定」は初版の既定設定を指す。ES-SVV の既定設定では、U4 は N ≥ 1024 で基準を満たした（7.1 節）。
ES-SVV のもとでの雑音の出どころと伝わり方は調べていない。

診断は `tests/MHD_COMP_ISOTH/diag_u4.py` で行った（試作 `proto1d.py` を `svv_form = 'linear'` に固定して使う。dt は初版の shock の一括試験と同じ 0.7 × 2.982e-4 × 512/N）。
star の格子スケールの雑音は、局所的な high-pass hp（4 階差分、k = k_c で利得 1）の標準偏差で測る。
スペクトルの帯域で測ると衝撃波の sinc の裾が混ざるからである。

雑音の出どころは衝突側の衝撃波である。根拠は次の 2 つである。

- 衝突を滑らかにすると（tanh 幅を x で 1 にし、t ≈ 0.25 まで衝撃波ができない初期条件）、t = 0.2 の star の hp(m) が
  既定の 1.0e-2 から 6.0e-7 に下がる（N = 512。N = 1024 では 2.5e-3 → 4.6e-7、N = 2048 では 2.3e-3 → 2.2e-7）。
  コマンドは `python3 diag_u4.py cause 512`。
- 滑らかな衝突で雑音が立つ時刻は衝撃波ができる時刻と一致する（`diag_u4.py onset 1024`）。
  N = 1024 の star の hp(u) は t = 0.300 で 5.2e-4、t = 0.325 で 4.9e-2 であり、
  同じ間に衝突側の ζ_max が 5.4e-3 → 9.9e-3 に増える。N = 2048 でも t = 0.300 で 9.2e-4、t = 0.325 で 2.1e-2 である。

衝突側から star への伝わり方は、流れによるものではない。star の上流は超音速なので、局所的な流れでは雑音は届かない。
届くのは、ik と SVV の乗数が k_c で鋭く切れているために微分が非局所になるからである。
(ρ, u, q) を固定すると、m の右辺は m と流束について線形なので、star の周り（|x − 3L/4| < a）の外側の寄与だけを分けて計算できる。
その hp を λ(k_c) で割った量（外側の寄与で決まる準定常の雑音）は、実測の hp(m) と桁が合う
（`diag_u4.py remote 512 1024 2048`、t = 0.3）。

| N | 外側の寄与 / λ(k_c)（a = 1, 2, 2.8） | 実測の hp(m) | λ(k_c) |
|---|---|---|---|
| 512 | 1.39e-3–4.68e-3 | 3.33e-3 | 998 |
| 1024 | 1.58e-3–3.60e-3 | 3.33e-3 | 1940 |
| 2048 | 5.5e-4–1.19e-3 | 2.23e-3 | 3839 |

star では ρ* = e⁻⁴ = 0.018 なので、m の雑音は u = m/ρ で 55 倍になる。
N = 512、t = 0.2 の star では hp(m) = 1.0e-2、hp(u) = 0.48 である。
この雑音は ∇·u < 0 の点を作り、star の中で ζ を起動する。
t = 0.2 の star での ζ の平均は、N = 512 で 1.5e-2、N = 1024 で 2.5e-3、N = 2048 で 1.2e-3 である（`diag_u4.py cause N default`）。

ρ* の誤差が衝突側の始め方で決まることは、衝突を滑らかにした計算から分かる（`diag_u4.py onset N`）。
t = 0.4 の ρ/ρ* − 1 は、滑らかな衝突では N = 1024 で +2.6e-3、N = 2048 で +1.4e-3 であり、既定の −3.0e-2 と −1.6e-2 より 1 桁小さい。
膨張側の界面は両者で同じ幅 1 格子の tanh である。
滑らかな衝突では衝突側の tanh の裾が膨張側の状態をわずかに変え、厳密な ρ* を e⁻⁴ から約 +1.6e-3 ずらす（特性曲線に沿った見積り）。
測った +2.6e-3 と +1.4e-3 はこのずれと同程度である。
衝突側から star へは物理的な信号が届かないので、既定との差はスペクトル演算（ik と SVV）の非局所性を通じて届いたものである。
なお、この初期条件は tanh を周期化していないので、x = 0 に Δu = 0.33 の弱い跳びが残る。
その波は超音速の流れで衝突側へ運ばれ、t = 0.2 の star の hp(m) は 6e-7 以下にとどまる。

雑音がどう ρ* の誤差になるのかは特定していない。
滑らかな衝突でも、衝撃波ができた後の t ≥ 0.325 では既定と同じ大きさの雑音が star に届く（t = 0.4 の hp(u) は N = 1024 で 0.19、既定では 0.12）。
それでも誤差は小さいので、ある時刻の雑音の大きさだけでは誤差は決まらない。
雑音にさらされた時間の差（既定では t ≈ 0 から、滑らかな衝突では t ≈ 0.3 から）が誤差の差を生んでいる可能性はあるが、確かめていない。
既定の誤差は t について単調でもない。N = 1024 では t = 0.2 の −5.4e-3 から t = 0.4 の −3.0e-2 に増え、N = 2048 では −3.2e-2 から −1.6e-2 に減る。

ζ を膨張側の半分で切る対策は取れない。切ると N = 512 で t = 0.108、N = 1024 で t = 0.141、N = 2048 で t = 0.049 に非有限値になる
（`diag_u4.py cause N zmask`）。

試した対策と、未検証の候補は次のとおりである。

- ik と m の SVV に、0.8 k_c から k_c にかけて raised cosine の taper を掛ける（`diag_u4.py taper N taper default`）。
  t = 0.4 の ρ/ρ* − 1 は次のとおりで、N によって良くも悪くもなる。taper では t = 0.025 から star に雑音が立つ（hp(u) = 0.42, N = 1024）。
  このため未検証扱いとする。

  | N | taper | 既定 |
  |---|---|---|
  | 512 | +2.62e-2 | +4.92e-3 |
  | 1024 | −3.45e-2 | −3.02e-2 |
  | 2048 | −5.47e-3 | −1.64e-2 |

- C_shock = 4（初版の走査）: ρ* 誤差 1.5%、overshoot 2.7% に下がったが基準に届かず、他の問題の L1 と dt が悪くなった。
- ユーザーの決定で SVV を ES-SVV に切り替えると、N ≥ 1024 で基準を満たした（7.1 節）。
  Hou–Li 型の指数フィルタ、svv_eps0 の増加、ζ の起動条件の変更（低密度での雑音の扱い）は試していない。

| | ρ* 誤差 | 3.9e-5 | 8.7e-5 | 3.6e-5 |
| | max\|ΔM/M0\| | 4.3e-5 | 1.6e-4 | 6.0e-8 |

`fs_nt6` と横方向 2 点の `fs` は、L1・ρ*・速度・位置・overshoot が表の桁まで一致し、質量誤差も相対 1e-12 まで一致した。横方向の点数は結果に影響しない。

`filter_lnrho = T` の質量誤差は、`linear` の SVV と組み合わせた初版より小さい。
U2 の `fs_nt6` では、初版の 3.8e-3 に対して ES-SVV では 1.6e-4 で、約 24 倍小さい。
次の段落の機構は初版の `linear` について試作で調べたもので、ES-SVV のもとでの機構は調べていない。

初版では、`filter_lnrho = T` の質量誤差の主な原因は、s の SVV 項の高波数成分が射影で消えることだった。
SVV 項 (1/ρ) F⁻¹(−λ F ρ) の Σ ρ ṡ = 0 は射影前の ṡ について成り立つので、射影で ṡ の k ≥ k_c 成分を消すと崩れる。
Q(k ≥ k_c) = 1 では λ ∝ k² が ρ の k ≥ k_c 成分に掛かるので、消える成分が大きい。試作（`linear`、U2、N = 1024、t = 0.4、`filter_lnrho = T`）で
Q = 1 なら max|ΔM/M0| = 1.95e-3、Q = 0 なら 6.2e-6 になる（`diag_u4.py fsmass Q1`, `Q0`）。
3/2 則の質量誤差が小さいのは、k ≥ k_c の成分を持たないからであり、この結果と整合する。
このため `filter_lnrho = T` で使うときは `svv_above_kc = F` を勧めるが、ES-SVV でも Fortran でも試していない。

一様な質量補正（`mc`, `fs_mc`）は全質量を戻す。`fs_mc` の質量誤差は Sod で 8.6e-7、U2 で 2.0e-7 である。
しかし `fs_mc` の U2 では ρ* 誤差が 8.7e-5 → 2.5e-4 に悪化した（Sod では 1.9e-4 → 1.6e-4）。
射影で失われた質量を全域に一様に戻すので、局所的な誤差は直らない。
`filter_lnrho = F` の `mc` は、既定と表の桁まで一致する（補正量が O(dt³) の質量誤差の大きさにとどまる）。

## 10. エネルギー収支

### 10.1 ε_ideal が 0 にならない理由

定式化 C の理想項は、積の微分則と連鎖律が格子上で成り立つことを前提にしないと、エネルギーを保存しない。
1D、B = 0 で ṁ = −∂_N(ρu² + c_s²ρ)、ρṡ = −∂_N m を 3.6 節の dE/dt に入れ、∂_N の反自己共役性 Σ f ∂_N g = −Σ g ∂_N f を使うと、

ε_ideal = Σ m [u ∂_N u − ∂_N(u²/2)] + c_s² Σ [ρ ∂_N u + m ∂_N s − ∂_N m]

になる（最後の項の和は 0 なので加えてよい）。
連続系では u ∂u = ∂(u²/2)、ρ ∂u + ρu ∂ ln ρ = ∂(ρu) なので両方の括弧が 0 になるが、∂_N ではどちらも成り立たない。
値は格子スケールの成分が多いほど大きい。

既定設定（ES-SVV）での値は次のとおりである。

| ケース | ∫ε_ideal | ∫ε_shock |
|---|---|---|
| Sod N1024 | 1.18e-2 | −20.43 |
| Sod N4096 | 8.52e-3 | −20.51 |
| U1 N1024 | 8.2e-3 | −15.93 |
| U2 N1024 | 0.437 | −161.6 |
| U4 N1024 | 11.8 | −789.7 |
| U4 N4096 | 9.43 | −783.3 |
| Sod N1024, C_shock = 0 | 1.55 | 0 |
| U2 N1024, C_shock = 0 | 16.6 | 0 |

∫ε_ideal / |∫ε_shock| は U4 で 1.5%、U2 で 0.27%、Sod と U1 で 0.06% 以下である。
初版（`linear`）の ∫ε_ideal は Sod で 3.1e-3、U1 で 3.2e-3、U2 で −1.1e-3、U4 で 17.7（N = 4096 で 15.0）、C_shock = 0 の Sod で 2.87、U2 で 2.32 だった。
ES-SVV では U2 の値が 2 桁以上大きくなり、U4 では N を 4 倍にしても 11.8 から 9.43 にしか減らない。どちらも原因は調べていない（12 節）。
エネルギーの時間積分誤差 ∫err_t dt / |E0| は Sod N1024 で −1.5e-7 であり、budget の各項の和は実測の dE/dt と整合する。

### 10.2 SVV のエネルギー寄与の符号

ES-SVV のすべての実行の全ステップで D_svv ≥ 0 が成り立ち、`filter_lnrho = F` では ε_svv = −D_svv の残差が丸め誤差の大きさである（7 節）。
既定設定の衝撃波試験 20 本の ∫ε_svv はすべて負である。

| 問題（N = 1024） | ∫ε_svv | ∫ε_shock | ∫ε_svv / \|∫ε_shock\| |
|---|---|---|---|
| Sod | −0.266 | −20.43 | 0.013 |
| U1 | −0.202 | −15.93 | 0.013 |
| U2 | −2.74 | −161.6 | 0.017 |
| U4 | −40.6 | −789.7 | 0.051 |

初版の `linear` では、ε_svv > 0 のステップが Sod で 1526 中 1513、U2 で 4035 中 4020、U4 で 3833 中 3724 を占め、
∫ε_svv は +0.184、+5.00、+78.7 だった（7.2 節の `linear` のケースで再現した）。
初版の報告では、このときも ε_shock + ε_svv < 0 は全ステップで成り立っていた。

初版の `linear` について、試作で ε_svv を m の項 Σ u·F⁻¹(−λ F m) と ln ρ の項（運動エネルギー部分 −u²/2 と内部エネルギー部分 c_s² s）に分けた
（`diag_u4.py svvsplit`、N = 1024、横方向の面積あたり。Fortran の値はこの (2π)² 倍）。

| 問題 | t | ε_svv | m の項 | ln ρ の項（運動） | ln ρ の項（内部） |
|---|---|---|---|---|---|
| U4 | 0.05 | +1.493 | +2.093 | −0.710 | +0.110 |
| U4 | 0.2 | +7.332 | +4.825 | +2.354 | +0.153 |
| U4 | 0.4 | +4.325 | +2.715 | +1.465 | +0.145 |
| U2 | 0.05 | +0.1873 | +0.0891 | +0.1072 | −0.0089 |
| Sod | 0.05 | +9.33e-3 | +7.79e-3 | +4.61e-3 | −3.07e-3 |

正の寄与の大部分は m の項から来る（ε_svv に占める割合は U4 で 140%, 66%, 63%、U2 で 48–58%、Sod で 83–85%）。
`linear` の SVV は保存変数 (ρ, m) に掛かり、エネルギーのエントロピー変数 (c_s² ln ρ − u²/2, u) には掛かっていない。
連続系で保存変数 U = (ρ, m) に同じ局所的な 2 階の拡散 ∂(ε ∂U) を掛けるなら、寄与は −∫ ε ∂U·H ∂U ≤ 0 になる。
H はエネルギー密度の Hesse 行列で、行列式は c_s²/ρ² > 0、すなわち正定値である。
離散系では連鎖律が成り立たず、SVV の乗数も局所的でないので、この符号は保証されない。

ES-SVV は、エントロピー変数 (c_s² s − u²/2, u) の勾配に非負の重みを掛けた流束の形にしたので、離散系でも D_svv ≥ 0 が状態によらず成り立つ（3.3 節）。

- `exe`: `EXE` を上書きする（回帰ケースは `bin/calliope_incomp_branch_es` を使う）。
- `fftw_estimate`: `fftw_shim.c` から作った `bin/fftw_shim.so` を先に読み込ませ、p3dfft の `FFTW_MEASURE` を `FFTW_ESTIMATE` に置き換える。

- `terminate`: calliope は各ステップの終わりにこのファイルを探し、見つけるとファイルを消して restart を書き、止まる。
  ジョブスクリプトは、こうして止まった実行と経過時間の上限で止まった実行の出力を `chunk_<k>/` に移し、残りのステップを restart から走らせる。

`$SSH` は `ssh -o RemoteCommand=none -o RequestTTY=no -o BatchMode=yes` である。
1D の試験では `transverse()` が横方向の点数を rank 数に合わせる（`dim_decomp = 2` の実空間分割で nlz を dims(1) で割り切るため）。

## 12. 未実装の項目と未解決の問題

実装していないものは次のとおりである。

- 定式化 A/B（`formulation` は `'C'` 以外で停止する）
- 粘性の形 `'flux_smooth'`, `'expanded'`（`visc_form` は `'flux'` 以外で停止する）
- eSSPIFRK3 以外の時間積分（gear3, RK4 は停止する）
- shear と ζ または SVV の組合せ（停止する）
- `nonlinear = F`（停止する）
- Stage 3（1D MHD）と Stage 4（2D/3D）。B の経路はコンパイルと fast 波だけで確かめた。

未解決の問題と注意点は次のとおりである。

- ES-SVV の費用（1 節、7.4 節）: F は N とともに増え続け、dt の上限はそれに応じて小さくなる。強い衝撃波を含む多次元の計算での費用は測っていない。
- ES-SVV と `linear` の U4 の差を、同じ dt で比べていない（7.1 節）。
- N = 1024 の U4 の膨張側の star の振れ幅（0.113）は `linear`（0.047）より大きい。基準には入れていない量だが、原因は調べていない（7.1 節）。
- dt λ_svv の検査の f = 3.0 の実行（7.4 節）で、どの量が安定限界を超えたのかを確かめていない。
- dt 収束で ρ の差の次数が 2.4–2.5 で 3 に届かない理由は調べていない（7.4 節）。
- U4 の ∫ε_ideal（N = 1024 で 11.8、N = 4096 で 9.43）と U2 の 0.437 が初版より大きい理由は調べていない（10.1 節）。
- 冪乗法のベクトルは restart ファイルに入らない（3.4 節）。dt を上限から決める実行では、restart の前後で dt が変わりうる（未確認）。
- `budget.dat` は、実行を止めて restart で継ぐたびに 1 行欠ける（7.5 節）。
- SVV を切った経路（`svv_eps0 = 0`）が SVV の実装前とビット一致することは、ES-SVV を入れたビルドで確かめ直していない（7.5 節）。
- `filter_lnrho = T` で使うなら `svv_above_kc = F` を勧めるが、ES-SVV でも Fortran でも試していない（9 節）。
- `cfl` の意味が旧モデルから変わり、多次元では同じ値で dt が最大 1/3 になる。既存の入力を使う人には告知が要る。
- 入力例 `input_examples/MHD_COMP_ISOTH.in` の lmd, lmd_h は ln ρ に掛かり、質量を保存しない（0 でないと警告を出す）。
- restart ファイルは `lnrho.dat` になったので、旧モデルの restart（`rho.dat`）からは再開できない。`out3d/rho.dat` は従来どおり密度である。
- 質量誤差の基準 M0 は restart のたびにその時点の値になる。
- Sod の衝撃波位置の 0.41 格子のずれの原因は調べていない（7.1 節）。
