## 1. 結論

Stage 1 の合格基準（6 節）は、U4 の衝撃波の項目を除いてすべて満たした。
U4 は ρ = 1, u = ±4（c_s = 1）の衝突流である。
満たした項目は次のとおりである。

- 正値性: 既定設定の衝撃波試験 20 本が、非有限値も CFL 停止もなく t_end に達した。
- 保存と恒等式: 半離散の質量の時間微分は |dM/dt_raw| / dM/dt_abs ≤ 4.9e-15、運動量は max|ΔP| / √(2 M0 E_kin,max) ≤ 5.6e-16、
  粘性の恒等式は max|R_ζ| / Σρζ D² ≤ 1.3e-13 である。
- 完全離散の質量誤差: 時間刻みに対して O(dt³) で縮む（観測次数 3.02–3.08）。
- 滑らかな解: 音波の振幅・位相誤差と、破砕前の単純波の収束。
- 衝撃波: U1・U2・Sod（N = 256–4096）の中間状態・衝撃波速度・位置・overshoot・L1 誤差の収束。
- 分割非依存: x, y, z 方向 × 1, 2, 4 rank の ρ, u の差が ≤ 1.5e-14 である。
- 異常検出: NaN を注入すると終了コード 1 で止まる。
- 回帰: MHD_INCOMP の出力がバイト一致する。

U4 は N ≥ 512 で次の基準を満たさない。

- 膨張側の中間状態 ρ* の誤差が N = 1024 で 3.0%、N = 2048 で 1.6% である（基準 1%）。
- 衝撃波の overshoot が 4.8–5.3% である（基準 5%）。
- N = 512 では衝撃波速度の誤差 1.5% も基準 1% を超える。

U4 の誤差の機構は特定していないが、Python の試作（`proto1d.py`）で次のことが分かった（8 節）。
衝突側の衝撃波が切断波数 k_c 付近の成分を作り、それが Fourier 微分と SVV の非局所性によって超音速の上流を越え、
密度 ρ* = e⁻⁴ = 0.018 の膨張側の中間領域（以下 star）に届く。
star では m の雑音が u = m/ρ で 55 倍になり、star の中で shock viscosity ζ を起動する。
衝突を滑らかにして始めると t = 0.4 の ρ* の誤差は 1 桁小さくなるので、誤差の大部分は衝突側から非局所的に届いた影響である。
ただし、雑音がどう誤差になるのかは確かめていない。
対策はどれも離散化の設計変更になるので、承認を得てから Stage 2 で試す。

エネルギーについては、ζ の項だけが半離散で散逸的と保証される（R_ζ が丸め誤差の大きさ）。
既定で入れた spectral vanishing viscosity（SVV, 3.3 節）のエネルギー寄与は、既定の衝撃波試験の 97–100% のステップで正である。
その時間積分は ζ の散逸の 0.3–8.6% で、両者の和は全ステップで負である。
SVV の散逸性は保証されない（10 節）。

## 3. 離散化

### 3.1 状態変数と方程式

状態は Fourier 係数 ŝ = F[ln ρ]、m̂ = F[ρu]、B̂ である。
格子点 x_j では ρ_j = exp(s_j) > 0 なので、正値性は構成的に保証される。
長さは grid.F90 の規約に従い L = 2π lx、波数は k_n = n/lx である（Stage 1 の試験は lx = 1）。

微分は ∂_N,d = F⁻¹ i k_d M F とする。k_d は Nyquist 波数で 0 にし、M は 2/3 フィルタである。
2/3 フィルタは各方向で |k_d| ≥ (2/3) k_Nyq,d の成分を 0 にするので、残る最大波数は k_c = N/3（lx = 1）である。
各 RK 段の後に m と B にフィルタを掛け、s には掛けない（既定 `filter_lnrho = F`）。

方程式（定式化 C）は次のとおりである。

- 質量: ṡ_j = −(∇_N·m)_j / ρ_j。
  s にフィルタを掛けず `pruned = F` なら、Σ_j ρ_j ṡ_j = −Σ_j (∇_N·m)_j = 0 が丸め誤差の範囲で成り立つ（微分の k = 0 成分は 0）。
  RK 法は非線形量 Σ e^s を厳密には保存しないので、完全離散の質量誤差は O(dt³) の時間積分誤差として残る。
- 運動量: ṁ = −∇_N·[ρuu + (c_s²ρ + B²/2 − q) I − BB]。流束を格子上で作ってから FFT する。
  右辺の k = 0 成分は 0 なので、全運動量は丸め誤差の範囲で保存する。
- 誘導: 旧コードの −∇_N×(B×u) をそのまま使う。η 一定の拡散は積分因子で扱い、`div_free` も旧コードのものを使う。

### 3.2 shock viscosity

- D = ∇_N·u とする。微分には運動量と同じ ∂_N（同じ M）を使う。
- ζ = C_shock Δ² S[max(0, −D)]。S は各有効方向（nl > 2）に、半幅 1 の局所 max を `shock_nmax` 回、
  正の重み [1, 2, 1]/4 の平滑化を `shock_nsmooth` 回、方向ごとに順に掛ける。
  ζ ≥ 0 であり、圧縮のない所では ζ = 0 になる。Δ は有効方向の dl_d の最小値である（`shock_dl > 0` で上書き）。
- 局所 max と平滑化はランク境界をまたぐ。隣接ランクを `grid.F90` の `idx2procid` で求め、`MPI_Sendrecv` で 1 層ずつ halo を交換する。
  各格子点の演算順は分割に依らないので、ζ は分割に対してビット一致する。
- 粘性応力 q_j = ρ_j ζ_j D_j を格子上で作り、圧力に −q として入れてから FFT する。FFT 空間の Gaussian は使わない。
- エネルギーへの寄与は Σ_j u_j·(∇_N q)_j である。∂_N が反自己共役（M が自己共役な射影）なら
  Σ u·∇_N q = −Σ q ∇_N·u = −Σ ρζD² ≤ 0 が成り立つ。
  `budget.dat` には残差 R_ζ = Σ u·∇_N q + Σ ρζD² を毎段出す。

### 3.3 spectral vanishing viscosity

SVV（Tadmor 1989; Maday, Ould Kaber & Tadmor 1993）は、切断波数の近くだけに掛かる 2 階の粘性である。
減衰率は λ(k) = Σ_d ε_d k_d² Q(|k_d|) とし、核 Q は a = |k_d| について次のように決める。

- a ≤ m_N（= `svv_mN`·k_c）: Q = 0
- m_N < a < k_c: Q = exp(−r²)、r = (k_c − a)/(a − m_N)
- a ≥ k_c: Q = 1（`svv_above_kc = T`, 既定）または 0（F）

a ≥ k_c の成分を持つのは、フィルタを掛けない s だけである。

各場への掛け方は次のとおりである。

- m と B: ṁ̂ += −λ m̂、Ḃ̂ += −λ B̂。λ(0) = 0 なので全運動量は変わらない。
- s: ṡ += (1/ρ) F⁻¹(−λ F ρ)。これは ρ̇ = F⁻¹(−λ F ρ) を s の式に書き直したもので、
  Σ_j ρ_j ṡ_j への追加分は −λ(0) ρ̂(0) = 0 である。正値性は s を状態にしているので保たれる。

係数は ε_d = `svv_eps0`·dl_d·max(|u_d| + c_f,d) で、各ステップの第 1 段で決めてそのステップ中は固定する。
s の項のために 1 段あたり FFT が 2 回増える。

### 3.4 時間積分と CFL

時間積分は既存の eSSPIFRK3 だけに対応する（gear3 と RK4 は停止する）。
展開すると有効重みは b = (1/4, 3/16, 9/16)、段の時刻は c = (0, 2/3, 2/3) である。

dt は dt ≤ min(dt_adv, dt_visc) で決める。

- dt_adv = `cfl` / Σ_d max(|u_d| + c_f,d)/dl_d。和は有効方向だけにとる。c_f,d は方向 d の fast 波の速さで、
  c_f,d² = [c_s² + v_A² + √((c_s² + v_A²)² − 4 c_s² v_A,d²)]/2 である。
- dt_visc = `cfl_visc` / max(ζ_max Σ_d k_d,max² + Σ_d ε_d Λ_d^m, Σ_d ε_d Λ_d^s, Σ_d ε_d Λ_d^B)。
  Λ_d は各場に残る波数での k_d² Q の最大値である。

両方とも第 1 段の状態から求める。dt の変更には既存の `reset_dt` を使う。
試験はすべて dt を固定し、`reset_method = 'stop'` にした。dt が上限を超えたら、dt を黙って変えずに停止する。

`cfl` の意味は旧モデルから変わった。旧モデルは dt = cfl·min_d (dl_d / max_vel_d) で、新しい式は方向の和をとるので、
3 方向が同等な 3D では同じ cfl で dt が最大 1/3 になる。1D では両者は一致する。

### 3.5 異常検出と質量補正

- 非有限値は浮動小数点数の指数部のビットで判定する（`transfer` を使い、`-O3` の最適化で判定が消えないようにした）。
  |s| > `s_abort`（既定 100、exp の桁あふれを防ぐため 700 以下を強制）も同じく検出する。
  検出したらランク・位置・値を出力して `MPI_Abort` で止める（終了コード 1）。
- 密度の床上げはしない。旧コードの `check_floor` は呼ばない。namelist の `rho_min` は読むが使わない。
- 一様な質量補正 `mass_correction`（既定 F）は、各ステップの初めに ŝ(k = 0) += ln(M0/M) とする。
  これは全域の ρ に同じ比 M0/M を掛けることに当たる。補正量はステップごとと累計を `conservation.dat` に残す。
  全質量は戻るが、局所的な質量保存は回復しない（失われていない場所にも質量を足す）。
- 基準の M0 は各実行の最初のステップでとる。restart すると M0 は restart 時点の値になる。

### 3.6 出力

| ファイル | 内容 |
|---|---|
| `conservation.dat` | t, dt, M, (M − M0)/M0, P_x,y,z, E の内訳と和, min/max ρ, max ζ, min D, Σρζ D² dV, 質量補正量（ステップごとと累計） |
| `budget.dat`（`budget = T`） | dM/dt（実測・raw・射影後・規模 Σ\|∇_N·m\|）、dE/dt（実測・各段の重み付き和）、時間積分誤差 err_t、ε_ideal, ε_shock, −Σρζ D², R_ζ, max\|R_ζ\|/Σρζ D², ε_force, ε_res, ε_nu, ε_lmd, E_n, E_n+1, ε_svv |
| `cfl.dat` | t, dt, dt_adv, dt_visc, 方向ごとの max(\|u_d\| + c_f,d), ζ_max, 粘性の重み付き平均, ε_d |
| `out1d/line_NNNNN.dat` | 第 1 の有効方向に沿った線上の ρ, u, B, ζ, D（ASCII） |
| `shock_selftest.dat`（`shock_selftest = T`） | 解析的な D から作った ζ の全格子点の値（分割非依存の検査用） |

エネルギーは E = Σ_j [m_j²/(2ρ_j) + c_s² ρ_j (s_j − 1) + B_j²/2] dV である。
∂E/∂m = u、∂E/∂s = ρ(c_s² s − u²/2) である。そこで dE/dt = Σ u·ṁ + Σ (c_s² s − u²/2) ρ ṡ（+ B の項）として、各項の寄与を分ける。
ε_ideal は、右辺の陽的項の寄与から ε_shock, ε_force, ε_svv を引いた残りである。
err_t は、実測の (E_n+1 − E_n)/dt と各段の寄与の重み付き和の差である。

## 5. 旧モデルの破綻の原因と SVV の採用

旧設定（ρ を状態にし、床上げあり）に近い組合せとして、ln ρ を状態にしたうえで C_shock = 1、SVV なし、`filter_lnrho = T` で
U2（N = 512）を走らせると、t = 0.0158 で CFL の検査により停止した。それまでに質量誤差は 1.1e-2、ρ_min は 1.4e-3 になった。

Python の試作で原因を調べた結果は次のとおりである。

- `filter_lnrho = T`・SVV なしでは、N ≥ 1024 かつ C_shock ≤ 4 で非有限値になって止まる。
  C_shock = 8 でも N = 2048 では t = 0.25、N = 4096 では t = 0.031 で止まる。必要な C_shock は N とともに増える。
- 見立ては次のとおりである。解像されない衝撃波と鋭い初期条件が k_c 付近の成分を作り、大域的な射影（sinc の裾）がそれを全領域に広げる。
  それが膨張波の音速点付近（u ± c がパターン速度に近い所）で共鳴的に成長する。
  Ray et al. (2011, PRE 84, 016301) が報告した "tyger" と同種の現象とみている。
- 否定した仮説は次のとおりである。
  - エイリアシング: pad = 2, 4 の過剰積分でも破綻する。
  - 時間積分: 破綻は dt にも cfl_visc にも依らない。
  - 一様流の局所的な不安定、滑らかな膨張波そのものの不安定: 膨張波だけ、衝撃波だけの問題はどちらも安定である。

これを受けて SVV を試し、`filter_lnrho = F` と組み合わせると U1・U2・U4・Sod が N = 512–4096 で安定になった。
退けた組合せは次のとおりである。

| 組合せ | 結果 |
|---|---|
| SVV を m だけに掛ける | 破綻する |
| `filter_lnrho = F` で SVV なし | 8 ステップで破綻する |
| SVV と `filter_lnrho = T` | U4 で t = 0.4 までに質量が 92% 増える |
| 既存の lmd_h（ln ρ の超拡散）と nu_h | 質量誤差が 1e-2 になる（lmd は ln ρ に掛かるので質量を保存しない） |
| べき型の核 (k/k_c)⁸ | L1 は約 15% 小さいが、全波数を減衰させる |

SVV を既定で有効にすることと、Q(k ≥ k_c) の扱いは、設計変更なのでユーザーに確認して決めた。

## 6. 判定基準

Fortran の一括試験の前に、次の基準を数値で固定した。「見た目がきれい」は合格にしない。

| 項目 | 量 | 基準 |
|---|---|---|
| 正値性 | 既定設定の全衝撃波試験 | 非有限値・CFL 停止なしで t_end に到達 |
| 半離散の質量保存 | max\|dM/dt_raw\| / dM/dt_abs（`filter_lnrho = F`, `pruned = F`） | ≤ 1e-12 |
| 完全離散の質量誤差 | max\|ΔM/M0\| の dt 依存 | 観測次数 ≥ 2.7 |
| 運動量保存 | max\|ΔP\| / √(2 M0 E_kin,max) | ≤ 1e-11 |
| 粘性の恒等式 | max\|R_ζ\| / Σρζ D² | ≤ 1e-10 |
| 音波（C_shock = 0, N = 32, 64, 1 周期） | 振幅誤差・位相誤差 | ≤ 1e-5 |
| 単純波（破砕前, t = t_b/2）, C_shock = 0 | Linf(u) | N を倍にするごとに 1 桁以上減る（丸め・時間誤差の床まで） |
| 単純波, C_shock = 2 | Linf(u) の観測次数 | ≥ 1.8 |

## 7. 結果

試験は ps1 の PBS `A_dev` で走らせ、ASCII の出力だけを手元に持ち帰って解析した。
1D 試験は横方向を nl = 2（`pruned = F`）にして代用した。横方向は一様で、2/3 フィルタで k = 0 だけが残る。
c_s = 1（beta0 = 2）、lx = 1（L = 2π）とし、Riemann 問題は R 状態を (L/4, 3L/4) に置いた周期問題である（界面は 2 枚）。
初期の界面は幅 1 格子の tanh にした。
dt は試作で求めた N = 512 での min(dt_adv, dt_visc) の最小値 DT512 に 0.7 と 512/N を掛けて固定した。

表の列の定義は次のとおりである。

- ρ_min: 全ステップを通した最小値（`conservation.dat`）
- L1(ρ): t_end での ∫\|ρ − ρ_exact\| dx
- ρ* 誤差: 中間状態の中央半分での平均の相対誤差（2 つの界面のうち大きい方）
- 速度誤差: 衝撃波位置の時系列に直線を当てはめた速度の相対誤差
- 位置: t_end での衝撃波位置のずれ（格子数）。位置は (ρ − ρ_up)/(ρ_dn − ρ_up) の積分から求める
- over/under: 衝撃波の両側 24 格子の窓での over/undershoot の大きい方（跳びに対する比）
- dM/dt_raw, ΔP, R_ζ: 6 節の規格化での最大値
- ∫ε_svv: SVV のエネルギー寄与の時間積分（横方向の面積 (2π)² を含む体積積分）

律速の欄は svvQ0 の結果から決めた。Sod では Q(k ≥ k_c) = 0 にすると dt_visc が 7.085e-4 に増えるので、s の SVV が律速している。
U2・U4 では svvQ0 でも dt_visc が変わらないので、m の項が律速している。U1 では svvQ0 を走らせていない。

SVV を入れると、許される dt（min(dt_adv, dt_visc)）は小さくなる。
Sod では 1.392e-3 → 5.622e-4（2.5 倍）、U2 では 4.035e-4 → 2.812e-4（1.4 倍）である（SVV なしの U2 は停止するまでの値）。

分割非依存（U2、N = 512、t = 0.2、x, y, z 方向 × 1, 2, 4 rank）: x 方向 1 rank との差は全 9 通りで
max|Δρ| ≤ 1.47e-14、max|Δu| ≤ 1.09e-14 である（基準 1e-10）。
ζ の自己検査（32×16×16、n_max = n_smooth = 2）は 1, 2, 4 rank で全格子点がビット一致した。

## 8. U4 が基準を満たさない原因

診断は `tests/MHD_COMP_ISOTH/diag_u4.py` で行った（試作 `proto1d.py` を使う。dt は Fortran の shock の一括試験と同じ）。
star の格子スケールの雑音は、局所的な high-pass hp（4 階差分、k = k_c で利得 1）の標準偏差で測る。
スペクトルの帯域で測ると衝撃波の sinc の裾が混ざるからである。

雑音の出どころは衝突側の衝撃波である。根拠は次の 2 つである。

- 衝突を滑らかにすると（tanh 幅を x で 1 にし、t ≈ 0.25 まで衝撃波ができない初期条件）、t = 0.2 の star の hp(m) が
  既定の 1.0e-2 から 6.0e-7 に下がる（N = 512。N = 1024 では 2.5e-3 → 4.6e-7、N = 2048 では 2.3e-3 → 2.2e-7）。
  コマンドは `python3 diag_u4.py cause 512`。
- 滑らかな衝突で雑音が立つ時刻は衝撃波ができる時刻と一致する（`diag_u4.py onset 1024`）。
  N = 1024 の star の hp(u) は t = 0.300 で 5.2e-4、t = 0.325 で 4.9e-2 であり、
  同じ間に衝突側の ζ_max が 5.4e-3 → 9.9e-3 に増える。N = 2048 でも t = 0.300 で 9.2e-4、t = 0.325 で 2.1e-2 である。

衝突側から star への伝わり方は、流れによるものではない。star の上流は超音速なので、局所的な流れでは雑音は届かない。
届くのは、ik と SVV の乗数が k_c で鋭く切れているために微分が非局所になるからである。
(ρ, u, q) を固定すると、m の右辺は m と流束について線形なので、star の周り（|x − 3L/4| < a）の外側の寄与だけを分けて計算できる。
その hp を λ(k_c) で割った量（外側の寄与で決まる準定常の雑音）は、実測の hp(m) と桁が合う
（`diag_u4.py remote 512 1024 2048`、t = 0.3）。

| N | 外側の寄与 / λ(k_c)（a = 1, 2, 2.8） | 実測の hp(m) | λ(k_c) |
|---|---|---|---|
| 512 | 1.39e-3–4.68e-3 | 3.33e-3 | 998 |
| 1024 | 1.58e-3–3.60e-3 | 3.33e-3 | 1940 |
| 2048 | 5.5e-4–1.19e-3 | 2.23e-3 | 3839 |

star では ρ* = e⁻⁴ = 0.018 なので、m の雑音は u = m/ρ で 55 倍になる。
N = 512、t = 0.2 の star では hp(m) = 1.0e-2、hp(u) = 0.48 である。
この雑音は ∇·u < 0 の点を作り、star の中で ζ を起動する。
t = 0.2 の star での ζ の平均は、N = 512 で 1.5e-2、N = 1024 で 2.5e-3、N = 2048 で 1.2e-3 である（`diag_u4.py cause N default`）。

ρ* の誤差が衝突側の始め方で決まることは、衝突を滑らかにした計算から分かる（`diag_u4.py onset N`）。
t = 0.4 の ρ/ρ* − 1 は、滑らかな衝突では N = 1024 で +2.6e-3、N = 2048 で +1.4e-3 であり、既定の −3.0e-2 と −1.6e-2 より 1 桁小さい。
膨張側の界面は両者で同じ幅 1 格子の tanh である。
滑らかな衝突では衝突側の tanh の裾が膨張側の状態をわずかに変え、厳密な ρ* を e⁻⁴ から約 +1.6e-3 ずらす（特性曲線に沿った見積り）。
測った +2.6e-3 と +1.4e-3 はこのずれと同程度である。
衝突側から star へは物理的な信号が届かないので、既定との差はスペクトル演算（ik と SVV）の非局所性を通じて届いたものである。
なお、この初期条件は tanh を周期化していないので、x = 0 に Δu = 0.33 の弱い跳びが残る。
その波は超音速の流れで衝突側へ運ばれ、t = 0.2 の star の hp(m) は 6e-7 以下にとどまる。

雑音がどう ρ* の誤差になるのかは特定していない。
滑らかな衝突でも、衝撃波ができた後の t ≥ 0.325 では既定と同じ大きさの雑音が star に届く（t = 0.4 の hp(u) は N = 1024 で 0.19、既定では 0.12）。
それでも誤差は小さいので、ある時刻の雑音の大きさだけでは誤差は決まらない。
雑音にさらされた時間の差（既定では t ≈ 0 から、滑らかな衝突では t ≈ 0.3 から）が誤差の差を生んでいる可能性はあるが、確かめていない。
既定の誤差は t について単調でもない。N = 1024 では t = 0.2 の −5.4e-3 から t = 0.4 の −3.0e-2 に増え、N = 2048 では −3.2e-2 から −1.6e-2 に減る。

ζ を膨張側の半分で切る対策は取れない。切ると N = 512 で t = 0.108、N = 1024 で t = 0.141、N = 2048 で t = 0.049 に非有限値になる
（`diag_u4.py cause N zmask`）。

試した対策と、未検証の候補は次のとおりである。

- ik と m の SVV に、0.8 k_c から k_c にかけて raised cosine の taper を掛ける（`diag_u4.py taper N taper default`）。
  t = 0.4 の ρ/ρ* − 1 は次のとおりで、N によって良くも悪くもなる。taper では t = 0.025 から star に雑音が立つ（hp(u) = 0.42, N = 1024）。
  このため未検証扱いとする。

  | N | taper | 既定 |
  |---|---|---|
  | 512 | +2.62e-2 | +4.92e-3 |
  | 1024 | −3.45e-2 | −3.02e-2 |
  | 2048 | −5.47e-3 | −1.64e-2 |

- C_shock = 4: ρ* 誤差 1.5%、overshoot 2.7% に下がるが基準に届かず、他の問題の L1 と dt が悪くなる（7.2 節）。
- 未着手: Hou–Li 型の指数フィルタ、svv_eps0 の増加、ζ の起動条件の変更（低密度での雑音の扱い）。
  どれも離散化の設計変更なので、承認を得てから Stage 2 で試す。

## 9. 2/3 則と 3/2 則、filter_lnrho と質量誤差

`pruned = T` は全場の変換を切断する 3/2 則（パディング）で、s にも射影が掛かるので `filter_lnrho = T` が必要になる。
同じ `filter_lnrho = T`・横方向 6 点の 2/3 則（`fs_nt6`）と比べた結果は次のとおりである（N = 1024）。

| 問題 | 量 | 3/2 則（pruned） | 2/3 則（fs_nt6） | 既定（2/3 則, filter_lnrho = F） |
|---|---|---|---|---|
| Sod | L1(ρ) | 0.0909 | 0.0911 | 0.0905 |
| | ρ* 誤差 | 6.4e-6 | 1.7e-4 | 3.4e-6 |
| | max\|ΔM/M0\| | 6.8e-6 | 3.5e-5 | 7.2e-7 |
| U2 | L1(ρ) | 0.0794 | 0.0740 | 0.0785 |
| | ρ* 誤差 | 6.8e-5 | 9.3e-4 | 7.7e-6 |
| | max\|ΔM/M0\| | 1.2e-5 | 3.8e-3 | 1.7e-8 |

`fs_nt6` と横方向 2 点の `fs` は、L1・ρ*・速度・位置・overshoot が表の桁まで一致し、質量誤差も相対 1e-10 まで一致した。横方向の点数は結果に影響しない。

`filter_lnrho = T` の質量誤差の主な原因は、s の SVV 項の高波数成分が射影で消えることである。
SVV 項 (1/ρ) F⁻¹(−λ F ρ) の Σ ρ ṡ = 0 は射影前の ṡ について成り立つので、射影で ṡ の k ≥ k_c 成分を消すと崩れる。
Q(k ≥ k_c) = 1 では λ ∝ k² が ρ の k ≥ k_c 成分に掛かるので、消える成分が大きい。試作（U2、N = 1024、t = 0.4、`filter_lnrho = T`）で
Q = 1 なら max|ΔM/M0| = 1.95e-3、Q = 0 なら 6.2e-6 になる（`diag_u4.py fsmass Q1`, `Q0`）。
3/2 則の質量誤差が小さいのは、k ≥ k_c の成分を持たないからであり、この結果と整合する。
したがって `filter_lnrho = T` で使うときは `svv_above_kc = F` を推奨する（Fortran では未試験）。

一様な質量補正（`mc`, `fs_mc`）は全質量を戻すが、`fs_mc` の U2 では ρ* 誤差が 9.3e-4 → 6.4e-3 に悪化した。
射影で失われた質量を全域に一様に戻すので、局所的な誤差は直らない。

## 10. エネルギー収支

### 10.1 ε_ideal が 0 にならない理由

定式化 C の理想項は、積の微分則と連鎖律が格子上で成り立つことを前提にしないと、エネルギーを保存しない。
1D、B = 0 で ṁ = −∂_N(ρu² + c_s²ρ)、ρṡ = −∂_N m を 3.6 節の dE/dt に入れ、∂_N の反自己共役性 Σ f ∂_N g = −Σ g ∂_N f を使うと、

ε_ideal = Σ m [u ∂_N u − ∂_N(u²/2)] + c_s² Σ [ρ ∂_N u + m ∂_N s − ∂_N m]

になる（最後の項の和は 0 なので加えてよい）。
連続系では u ∂u = ∂(u²/2)、ρ ∂u + ρu ∂ ln ρ = ∂(ρu) なので両方の括弧が 0 になるが、∂_N ではどちらも成り立たない。
値は格子スケールの成分が多いほど大きい。

| ケース | ∫ε_ideal | ∫ε_shock |
|---|---|---|
| Sod N1024 | 3.1e-3 | −20.9 |
| U1 N1024 | 3.2e-3 | −16.2 |
| U2 N1024 | −1.1e-3 | −168.9 |
| U4 N1024 | 17.7 | −914.9 |
| U4 N4096 | 15.0 | −905.1 |
| Sod N1024, C_shock = 0 | 2.87 | 0 |
| U2 N1024, C_shock = 0 | 2.32 | 0 |

U4 で N を上げても ∫ε_ideal が減らないのは、star の雑音が N によらず残るためとみている（未確認）。
エネルギーの時間積分誤差 ∫err_t dt / |E0| は Sod N1024 で −1.7e-6 であり、budget の各項の和は実測の dE/dt と整合する。

### 10.2 SVV のエネルギー寄与の符号

既定の衝撃波試験では、ε_svv > 0 のステップが 97–100% を占める。一方、ε_shock + ε_svv < 0 は全ステップで成り立つ。

| 問題（N = 1024） | ∫ε_svv | ∫ε_shock | ∫ε_svv / \|∫ε_shock\| |
|---|---|---|---|
| Sod | 0.184 | −20.9 | 0.009 |
| U1 | 0.0557 | −16.2 | 0.003 |
| U2 | 5.0 | −168.9 | 0.030 |
| U4 | 78.7 | −914.9 | 0.086 |

試作で ε_svv を m の項 Σ u·F⁻¹(−λ F m) と ln ρ の項（運動エネルギー部分 −u²/2 と内部エネルギー部分 c_s² s）に分けた
（`diag_u4.py svvsplit`、N = 1024、横方向の面積あたり。Fortran の値はこの (2π)² 倍）。

| 問題 | t | ε_svv | m の項 | ln ρ の項（運動） | ln ρ の項（内部） |
|---|---|---|---|---|---|
| U4 | 0.05 | +1.493 | +2.093 | −0.710 | +0.110 |
| U4 | 0.2 | +7.332 | +4.825 | +2.354 | +0.153 |
| U4 | 0.4 | +4.325 | +2.715 | +1.465 | +0.145 |
| U2 | 0.05 | +0.1873 | +0.0891 | +0.1072 | −0.0089 |
| Sod | 0.05 | +9.33e-3 | +7.79e-3 | +4.61e-3 | −3.07e-3 |

正の寄与の大部分は m の項から来る（ε_svv に占める割合は U4 で 140%, 66%, 63%、U2 で 48–58%、Sod で 83–85%）。
SVV は保存変数 (ρ, m) に掛かり、エネルギーのエントロピー変数 (c_s² ln ρ − u²/2, u) には掛かっていない。
連続系で保存変数 U = (ρ, m) に同じ局所的な 2 階の拡散 ∂(ε ∂U) を掛けるなら、寄与は −∫ ε ∂U·H ∂U ≤ 0 になる。
H はエネルギー密度の Hesse 行列で、行列式は c_s²/ρ² > 0、すなわち正定値である。
離散系では連鎖律が成り立たず、SVV の乗数も局所的でないので、この符号は保証されない。

- restart ファイルは `lnrho.dat` になったので、旧モデルの restart（`rho.dat`）からは再開できない。`out3d/rho.dat` は従来どおり密度である。
- 質量誤差の基準 M0 は restart のたびにその時点の値になる。
- Sod の衝撃波位置の 0.41 格子のずれの原因は調べていない（7.1 節）。
