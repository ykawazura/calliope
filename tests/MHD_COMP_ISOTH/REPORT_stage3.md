## 1. 結論

磁場を有効にした 1D 等温 MHD で、bulk の衝撃波粘性だけ（C_eta = 0）の定式化 C を試した。
B_t が構造の中で反転しない波は、bulk 粘性だけで正しい速度・跳び・収束性で解ける。
B_t が反転する構造は、bulk 粘性だけでは解けない。
局在抵抗 η_shock を Fortran と試作に実装し、係数 C_eta の既定値は 0 のままにした。

結果は次のとおりである（数値は試作。Fortran と試作の一致は 16 節）。

- bulk 粘性だけで解ける波
  - 正規の fast・slow 衝撃波（F1, F2, S1, S2）と垂直 MHD の衝撃波（P1a–c, P2, P3）
    - 衝撃波の速度の相対誤差は N = 2048 で 1.8e-4 以下である（P3 の fast 衝撃波だけ 1.1e-3）。
    - 平坦部の誤差は N = 256 → 2048 で 1.1–2.5 桁縮む（P1c だけ約 3 倍）。
    - 6 変数の L1 誤差は 1 次（観測次数 0.91–1.00）で縮む。
  - 幅のある回転不連続（RDh, RDp の幅 4 格子と 8 格子）。一周後の速度誤差は 1e-6 以下、|B_t| の変化は 7e-4 以下である。
  - 接線不連続（TDS, TDA）。速度の誤差は 2.2e-6 以下で、u_t = 0 は厳密に保たれる。ただし、法線速度 u_x に最大 1.4e-2 の偽の流れが生じる（12 節）。
  - 複合リーマン問題のうち B_t が反転しない C1 と C3。FV 参照解との L1 距離は 1 次（0.97, 1.00）で縮む。
  - 滑らかな解（線形 fast・slow 波、円偏光 Alfvén 波）。誤差は時間積分の誤差と、振幅と Δ² に比例する ζ の寄与だけである（8 節）。
- bulk 粘性だけで解けない構造（10 節）
  - 2→3 中間衝撃波 I1 と、鋭い 180° の共面回転不連続 RDpc である。
  - 機構: bulk 粘性だけでは、構造の中で接線成分を均す物理的な散逸がない。
    - 定常構造の式から B_y = K/(w − w_A) が従い、連続な構造は w = w_A を越えられない。
    - 共面の初期値では B_z = u_z = 0 が厳密に保たれるので、B_t は回転できない。
  - I1: 理想解との L1 距離の観測次数が 0.82 から 0.20 へ下がる。FV 参照解とは 1.2e-2 の距離から縮まない（Fortran の N = 8192 まで）。
  - RDpc: 速度誤差 −1.6e-2 と B_t の L1 誤差 0.30 が N によらない。
  - C2（B_t が反転する複合問題）は、6 変数の L1 で FV 参照解に観測次数 0.58 でしか近づかない（ρ だけの距離は N = 2048 で 2.1e-3 まで縮む）。
- η_shock（C_eta = 2）の効果（15 節）
  - 試作では、FV 参照解との距離の観測次数が I1 で 0.95、RDpc で 0.75、C2 で 0.90 になる（I1 は N = 2048、RDpc は 1024、C2 は 4096 まで。15.2 節）。
  - 構造の近くでは、FV と異なる値に近づく（10.6 節）。I1 の前方の ρ は、Fortran の N = 4096, 8192 で 0.9832, 0.9834 と、FV の 0.9814 から離れる。RDpc の RD から 0.01–0.15 の帯の距離は、N = 1024, 2048, 4096, 8192 で 2.0e-3, 1.8e-3, 1.8e-3, 1.8e-3 と縮まない。どちらも FV 自身の誤差（1.9e-5、4.5e-4）を上回る。構造から離れた領域の距離は縮む（RDpc では、その観測次数も N = 8192 で 0.48 に下がる）。
  - FV 参照解も η を足した解も、理想の単一の I1 と単一の RDpc にはならない。粘性と抵抗のある系の極限は散逸の形に依存しうる（Torrilhon 2003）ので、FV 参照解は 1 つの散逸の極限にすぎない。上の構造の近くの差も、η を足した系の極限が FV の極限と異なることを示唆するが、確かめてはいない。
  - 代償として、正規の衝撃波で次の変化が出る。
    - 垂直 MHD の P1b の壁の加熱（平坦部の誤差が 1/N で縮むだけになる）
    - 衝撃波の位置のずれの増加（F2 で −0.33Δ から −0.75Δ）
    - I1 の速度の偏り（−2e-3）
- C_eta の既定値は 0 とする。B_t が反転する問題では C_eta = 2 を推奨する。
- 保存と恒等式（7 節）
  - 質量・運動量・∫B の半離散の変化と、R_ζ、R_svv、R_η は丸め誤差の範囲にある。
  - 完全離散の質量の誤差は dt³ で縮む（最大 1.6e-5）。
  - E が増えたステップと ε_svv > 0 のステップはない。284 本の試作はどれも最初の dt で t_end に達した。
- Fortran
  - Fortran と試作の差は N = 256 の 8 問題で 1.13e-13 以下、C_eta = 2 の 4 問題で 5.7e-14 以下である。
  - MPI 分割と方向（x, y, z）による差は 1.15e-14 以下である。
  - MHD_INCOMP の回帰は 69 ファイルが一致した。
  - C_eta = 0 では、η_shock の追加の前後で、budget.dat の 1 列（1 ulp）を除いてビット一致する。
  - 試作の全ケース（bulk 粘性 131 本、C_eta = 2 の 51 本）を Fortran で走らせた。182 本すべてが t_end に達し、最終状態の試作との差は 4.4e-12 以下である。N = 512, 1024 の 4 問題では、全スナップショットの差が 1.52e-13 以下である（16.2 節）。

## 3. 離散化と局在抵抗 η_shock

### 3.1 1D での散逸

定式化と離散化は Stage 1・2 で決めたものである。
状態は (s = ln ρ, m = ρu, B)、Fourier 選点法で 2/3 則のマスクを掛け、時間積分は eSSPIFRK3 である。
フィルタは m と B に掛け、s には掛けない（filter_mom = T, filter_mag = T, filter_lnrho = F）。
衝撃波粘性は ζ = C_shock Δ² S[max(0, −∇·u)]（C_shock = 2）で、運動量の流束に q = ρζD（D = ∇_N·u）を足す。

1D では ζ は m_x にしか働かない。
m_y, m_z, B_y, B_z を均すのは、m の ES-SVV、B の線形 SVV、2/3 則のフィルタだけである（この Stage では定数の η と ν を 0 にした）。
これらはどれも格子の尺度の散逸で、N → ∞ で消える。

### 3.2 η_shock の定義と離散化

元の指示の 5 節の局在抵抗を次のように実装した。

- η_shock = C_eta Δ² S[max(0, −D)]。検出量 S[max(0, −D)] と Δ は ζ と同じものを使う（Δ は格子幅の最小値）。
  C_eta は ζ の C_shock と同じく拡散係数の無次元の係数で、既定は 0（無効）である。
- J = F⁻¹[ik × P B̂]（P は filter_mag のマスク）を格子上で作り、誘導方程式の流束に η J を足す。
  ∂_t B = −∇_N×(−u×B + η J) となる。逆 FFT が 3 本増え、順 FFT は増えない。
- エネルギーの変化は ε_η = Σ B·F⁻¹[P(−ik × F(ηJ))] ΔV である。
  ∇_N× は離散の内積について反対称で、P は対称なので、ε_η = −Σ (∇_N×B)·(ηJ) ΔV = −Σ η|J|² ΔV ≤ 0 が離散で成り立つ。
  budget.dat の 27–30 列に ε_η、−Σ η|J|² ΔV、R_η = ε_η + Σ η|J|² ΔV、max|R_η|/Σ η|J|² ΔV を書く。既存の列番号は変えていない。
  理想部の離散化誤差（10 列）からは ε_η を差し引く。
- 粘性の dt の B の項に η_max k_max² を足した（k_max は 2/3 則のマスクの最大波数）。cfl.dat の 17 列に η_max を書く。
- `shear = T` と C_eta > 0 の組は確かめていないので停止する。

試作 `proto_mhd1d.py` にも同じ定義と離散化を入れた。
接線粘性 ν_t（∂_t m_t に ∂(ρν_t ∂_N u_t) を足す。ν_t = C_nu Δ² S[max(0, −D)]）は、比較のために試作の補助 `stage3_aux.py` にだけ入れた（10.5 節）。

## 4. 試験の組と時間刻み

### 4.1 単位と初期値

c = 1（β0 = 2）、L = 1（lx = 1/(2π)）、格子は x_j = jL/N である。
W = (ρ, u_x, u_y, u_z, B_y, B_z) と書く。
不連続は、とくに断らなければ格子点の上に H = 1/2 で置く。

垂直 MHD と複合問題では、周期境界のために右の状態を (L/4, 3L/4) に置き、2 つの界面が出す波を重ね合わせる。
垂直 MHD の厳密解は、2 つの界面のリーマン解の重ね合わせが成り立つ点だけで比べる。

共面の単一衝撃波では、x_a = 0.125 に厳密な単一衝撃波を置く。
x_b の界面が出す波は厳密解を持たないので、特性速度の上下限で囲み、その範囲を比較から除く。
x_b は、t_end での上流と下流の有効な区間の長さが等しくなるように選んだ。
有効な区間が実際に x_b の波に乱されていないことは、FV 法の N = 4096 の解で確かめた（5.2 節）。

### 4.2 時間刻み

各ケースは固定の dt = t_end/nstep で走らせる。
dt は、同じ設定の適応 dt の予備実行での min(dt_adv, dt_visc) の最小値 DTMIN に対して dt ≤ SAFETY·DTMIN（SAFETY = 0.7）を満たし、nstep は NWRITE = 20 の倍数にする。
非有限値、CFL による停止、dt λ_svv > 2.51 のどれかが起きたら、dt/2、dt/4 で繰り返す。
284 本（bulk 粘性 131 本、C_eta = 0.5, 2, 8 の各 51 本）はどれも最初の dt で t_end に達した。
Fortran のケースは試作と同じ (nstep, dt) を `stage3_nstep.json` から読み、`reset_method = 'stop'` で走らせる。

収支は各段で評価する。
半離散の恒等式は各ステップの第 1 段の状態で測り、エネルギーの内訳には段の重みを掛けた変化率を使う。
時間積分の誤差は、エネルギーの実際の変化から変化率の和 Σ dt ε_N を引いたものである。

## 5. 参照解

### 5.1 厳密解とその自己検査

`mhd_exact.py` は次のものを持つ。

- 垂直 MHD の厳密リーマン解。B_x = 0 では b = B_y/ρ が流体とともに運ばれるので、圧力 P(ρ) = c²ρ + b²ρ²/2 の気体に帰着する。膨張波は閉じた形の積分を二分法で解く。
- 共面の RH 条件。上流 (ρ, u_x, u_y, B_y) = (1, 0, 0, 1)、B_x = 1、圧縮比 r に対し、X = (衝撃波の系での上流の速度)² が 3 次式
  (X − rc²)(X − ra²)² = (r b₁²/2) X((r + 1)X − 2ra²)
  を満たす（a² = B_x²/ρ₁、b₁ = B_y/√ρ₁）。根を fast・中間・slow に分類する。F1 では X = 4 + 2√2、B_y,2 = 1 + √2 が閉じた形で出る。
- 線形 fast・slow 固有モード、円偏光 Alfvén 波、RD、TD。

自己検査の結果は次のとおりである。

- RH の残差は 1.6e-15 以下である。
- b → 0 の垂直 MHD の解は、等温 Euler の `riemann_exact` と 1e-9 で一致する。
- B_x = B_y = 1、ρ = 1、k = 2π/L の線形モードの角振動数を ω/k で表すと、fast は 1.280776、slow は 0.780776 である。

### 5.2 有限体積法の参照解

`fv_mhd1d.py` は等温 HLLD（Mignone 2007）である。
扇の中で ρ と u_x を一定とし、接線成分は跳びの条件から、中央の状態は接線成分の線形リーマン問題から決める。
このため、孤立した RD は 1 次精度でも厳密に運ばれる。
空間 2 次は原始変数の MUSCL と MC リミタ、時間は SSP-RK2 である。
セルの中心 x_i = i dx はスペクトル法の格子点と一致する。

参照解として使う前に、次のことを確かめた。

- RD を 1e-13 で厳密に運ぶ。
- 単一衝撃波の厳密解との L1 距離が、N = 256 → 2048 で 1 次で縮む。
  F1 は 1.43e-2 → 1.42e-3、S1 は 6.12e-3 → 7.80e-4、S2 は 1.18e-2 → 1.32e-3、C3 の衝突側は 2.54e-2 → 3.75e-3 である。
  I1 だけは 6.03e-2 → 3.32e-2 で、観測次数は 0.47、0.24、0.15 と下がる。
- 共面の時間窓（4.1 節）: N = 4096 の FV の解の、有効な区間での厳密解との L1 距離は、F1 2.3e-3、F2 1.1e-2、S1 3.5e-4、S2 2.0e-3 である。I1 は 7.8e-2 で、10 節で扱う。
- 複合問題の自己収束: 隣り合う N の差は、C1 で 3.0e-4 → 1.5e-4、C3 で 5.0e-4 → 2.4e-4 と 1 次で縮む。
  C2 は一様に縮まず、観測次数は 0.16–0.30 である。
- 複合問題の参照解は N = 65536 で、比べる時刻 T_REF = 0.025, 0.05, 0.075, 0.1 に保存した。
  N/2 との差（6 変数の L1）は、t = 0.1 で C1 7.8e-5、C2 3.0e-3、C3 1.1e-4 である。
- I1 と RDpc の参照解は N = 16384 である。N/4 との ρ の L1 の差は I1 で 9.5e-4、RDpc で 1.5e-3 である。

FV 法は HLLD の数値散逸をすべての変数に持つ。
B_t が反転する問題では、粘性と抵抗のある系の解が散逸の形に依存しうる（Torrilhon 2003）ので、FV 参照解は散逸の 1 つの極限であり、唯一の正解とは限らない。
実際、FV 参照解自身も、理想の単一の I1 と単一の RDpc を再現しない（10 節）。

## 6. 測った量

- 保存
  - 質量 M、運動量 P = (P_x, P_y, P_z)、∫B_y, ∫B_z の完全離散の変化。ΔM/M0 と、運動量・磁場は max|ΔP|、max|Δ∫B| で示す。
  - 半離散の変化率（右辺の和）dM/dt, dP/dt, d∫B/dt。
- 半離散の恒等式（Stage 1 の定義に R_η を足した）
  - R_ζ（衝撃波粘性の散逸の恒等式の残差）、R_svv（ES-SVV の残差）、R_η を、それぞれの散逸で割って示す。
  - ε_svv,B（B の線形 SVV のエネルギー変化）が負であること。
- エネルギーの内訳（元の指示の 6 節）: 衝撃波粘性 ε_shock、抵抗 ε_η、その他の散逸（m と s の ES-SVV、B の SVV）、理想部の離散化誤差（ε_N から散逸の項を引いたもの）、時間積分の誤差。
- 衝撃波（単一衝撃波と垂直 MHD の各波）
  - 速度の誤差 (S_fit − S)/|S|。S_fit は ρ の跳びの中間値を横切る位置の、t ≥ t_end/4 での 1 次の当てはめである。
  - 平坦部の誤差: 各平坦部の平均の誤差の最大を、跳びの最大で割ったもの。平坦部は max(8Δ, 0.02) だけ削る。
  - RH 残差: S_fit と平坦部の平均で評価した跳びの条件の残差を、|ΔF| + |S||ΔU| で割ったものの、方程式についての最大。
  - ρ の overshoot: 波の前後の min(max(20Δ, 0.03), 窓の幅) の帯での、平坦部を超える量を ρ の跳びで割ったもの。
  - 位置のずれ: t_end での ρ の中間値を横切る位置と厳密解の差を Δ で割ったもの。
  - L1 誤差: 有効な点の上での 6 変数の L1 の和と、その観測次数。
- RD と TD（一周の間のスナップショットについての最大）
  - 位相のずれ: 1 次の Fourier モードの位相から出す位置のずれ（V t を引く）。速度誤差はその t_end での値を t で割ったもの。
  - RD: |ρ − 1|, |u_x|, ||B_t| − 1|, |D|, ζ, |u_t + B_t|（Alfvén の関係）, RDpc では |u_z|, |B_z|。L1 は B_t。
  - TD: |u_x − U|, |u_t|, |ρ + B_t²/2 − 2|（全圧の不釣り合い）, |D|, ζ。ρ の 10–90% の幅を Δ で割ったもの（初期値の表、起動時のフィルタの後、t_end）。L1 は ρ。
- 複合問題: FV 参照解との 6 変数の L1 距離と、その観測次数（細かい 3 解像度）。
- 正値性 ρ_min、dt/dt_lim（実際の dt と min(dt_adv, dt_visc) の比の最大）、dt λ_svv。

## 10. B_t が反転する構造

### 10.1 定常構造の式

衝撃波の系で、流れを +x 向き（上流を x = −∞）にとる。
w = u_x − S > 0、質量流束 j = ρw とおくと、共面の定常な式は D X' = F(X) に積分できる。
ここで X = (w, u_y, B_y)、D = diag(ρζ, ρν, η) で、

F = (j w + c² j/w + B_y²/2 − Π, j u_y − B_x B_y − T, w B_y − B_x u_y − E)

である（Π, T, E は上流の状態で決まる定数）。
固定点での F のヤコビ行列 J は対称なので、Sylvester の慣性法則から、不安定多様体の次元はすべての正の D について J の正の固有値の数 n+(J) に等しい。
連結 i → k の次元は一般に d = n+(i) − n+(k) である（d = 1 で孤立した軌道、d = 0 で一般には連結なし）。

ν = 0 では u_y が代数的に決まり、J は Schur 補行列 J2 = [[j(1 − c²/w²), B_y], [B_y, w − w_A]]（w_A = B_x²/j）に置き換わる。n+(J) = 1 + n+(J2) である。
bulk 粘性だけ（ν = η = 0）では B_y = K/(w − w_A)（K は定数）となり、連続な構造は w = w_A を越えられない。
非共面の成分 (u_z, B_z) は、ν があればブロック [[j, −B_x], [−B_x, w]] を、なければ w − w_A を足す。

`stage3_aux.py structure` で求めた n+ を次に示す（ランダムな D で慣性法則を確かめた）。

| 問題 | 固定点 | 共面 ζ+η | 共面 ζ+ν+η | 非共面 ζ+η | 非共面 ζ+ν+η |
|---|---|---|---|---|---|
| F1 | 上流（状態 1） | 2 | 3 | 3 | 5 |
| | 下流（状態 2） | 1 | 2 | 2 | 4 |
| S1 | 上流（状態 3） | 1 | 2 | 1 | 3 |
| | 下流（状態 4） | 0 | 1 | 0 | 2 |
| I1 | 上流（状態 2） | 1 | 2 | 2 | 4 |
| | 下流（状態 3） | 1 | 2 | 1 | 3 |

F1（1→2）と S1（3→4）では、どの散逸の組でも d = 1 で、構造が孤立した軌道として存在する。
I1（2→3）は共面で d = 0、非共面で d = 1 である。
ν を足しても d は変わらない。
したがって、ν_t を足しても 2→3 の構造が一意に決まるわけではない。
これは、共面の 2→3 中間衝撃波の構造が散逸の係数の特別な比でしか存在しないという結果（Wu 1987、Kennel, Blandford & Wu 1990）と整合する。

bulk 粘性だけの I1 では、上流 w > w_A、下流 w < w_A なので、連続な構造がない。
RDpc は D = 0 の線形退化の波で、ζ が働かない。
共面の初期値では B_z = u_z = 0 が厳密に保たれるので、|B_t| を一定に保つ 180° の回転はできず、B_y は 0 を通らなければならない。
どちらの場合も、構造を支えるのは格子の尺度の SVV とフィルタだけである。

衝撃波の前方に、上流と異なる状態が現れる。

### 10.4 RDpc: bulk 粘性だけの結果

bulk 粘性だけの RDpc では、跳びは 180° 回転せず、B_y が 0 を通る（||B_t| − 1| の最大は 1.0）。
圧縮成分への漏れが大きく、|ρ − 1| は 0.56–0.57、|u_x| は 0.36–0.37、|D| は 90（N = 256）から 720（N = 2048）まで N に比例して増える。

u_z = B_z = 0 は厳密に保たれる。
理想の RD に対する B_t の L1 誤差は 0.30、速度誤差は −1.7e-2 から −1.6e-2 で、どちらも N によらない。
位相のずれは 4.32Δ, 8.46Δ, 16.71Δ, 33.25Δ で、物理的には約 0.0165 で一定である。

### 10.5 接線粘性 ν_t の試験

ν_t は、試作の補助 `stage3_aux.py nut` でだけ試した。
∂_t m_t に ∂(ρν_t ∂_N u_t) を足し、ν_t = C_nu Δ² S[max(0, −D)] とする。エネルギーの変化は −Σ ρν_t (∂_N u_t)² ΔV である。
dt は、C_eta = 2 の試作（ない場合は bulk 粘性だけの試作）の刻み数の 2 倍で固定した。
10.3 節の結果から、I1 と RDpc の FV 参照解への収束について、ν_t は η と同等で、併用しても改善しない。
このため Fortran には η_shock だけを実装した。

B の SVV とフィルタは B_y を、ES-SVV は (ρ, m) を、それぞれ別の作用素で均すので、全圧 c²ρ + B_y²/2 の釣り合いが崩れると推定している（確かめてはいない）。
実際、全圧の不釣り合いの最大は `pre` でも 1.4e-2（N = 256）から 8.7e-3（N = 2048）ある。
t_end の幅は 3.2–3.6Δ で、N とともにわずかに増える（w0: 3.20 → 3.39、w1: 3.42 → 3.58）。初期の幅（w0 で 1.6Δ、w1 で 2.4Δ）からは約 2 倍と 1.5 倍である。
幅 4 格子の TD では、u_x は 2e-5 以下で、幅は変わらない。
ζ の最大は 1e-4 以下で、TD に衝撃波粘性はほとんど働かない。

RD と TD は D = 0 なので、η_shock はほとんど働かない。
RDh_w4 の N = 1024 の B_t の L1 は、C_eta = 0, 0.5, 2, 8 で 8.0e-5, 8.6e-5, 1.1e-4, 2.3e-4、速度誤差は −9.9e-8, −1.4e-7, −2.7e-7, −8.2e-7 である。
TDS_w1 の N = 512 の max|u_x| は 4.7e-3, 5.0e-3, 6.1e-3, 1.1e-2、t_end の幅は 3.49Δ, 3.57Δ, 3.77Δ, 4.43Δ である。
RD と TD の中の小さな D に η が働き、わずかに漏れが増える。

### 15.4 既定値

C_eta の既定値は 0 とする。
理由は次の 2 つである。

- 正規の衝撃波、RD、TD は bulk 粘性だけで正しく解け、η_shock を足すと P1b の壁の加熱、位置のずれ、RD・TD への漏れが増える。
- η_shock を足した解が近づくのは理想解ではない。FV 参照解（散逸の 1 つの極限）にも、構造の近くでは N = 8192 までの範囲で近づかなくなる（10.6 節）。

B_t が構造の中で反転する問題（中間衝撃波、共面の 180° の RD、Brio–Wu 型の複合問題）では、C_eta = 2 を推奨する。
C_eta = 0.5 では RDpc の収束が単調でなく、C_eta = 8 では FV 参照解との距離が大きく、RDpc の観測次数も下がる（0.75 → 0.62）ので、2 を選んだ。
この推奨の根拠は、FV 参照解との距離が bulk 粘性だけの場合より 1 桁小さくなることである（I1 の ρ で 1.16e-2 → 1.31e-3、N = 8192。RDpc で 5.52e-2 → 3.80e-3、N = 8192）。
FV 参照解への収束を保証するものではない。
この推奨は 1D の試験だけに基づく。多次元での値は Stage 4 で確かめる。

再開した実行は、最初のステップにも out1d の行を 1 本書く。

`analyze_stage3.py` は、試作のスナップショットのステップ（nstep/20 の倍数と nstep）の行だけを使う。

`stage3_table.py` の表を Fortran の出力から作り直し、試作の表とセルごとに比べた。
表示の桁で一致しないセルは次の 3 種類だけである。

- 丸め誤差の大きさの列。TD の t = 0 の全圧の不釣り合い（約 1e-15）、RD の B の SVV の散逸（約 1e-17）、TDS_w4pre の理想部の離散化誤差（−1.7e-12 と −1.6e-12）、R_ζ、R_svv、R_η、ΔP、dM/dt（どちらも 2e-12 以下）が該当する。
- ρ_min。Fortran の conservation.dat は t_end の状態を含み、試作の履歴は含まない。RDpc の N = 512 の Fortran の値 0.725394 は、試作の t_end のスナップショットの最小値と一致する（試作の履歴の値は 0.725928）。
- max ε_svv,B。Fortran の値は RK の段の重みつき平均、試作の値は第 1 段の値で、t = 0 では厳密に 0 になる。どちらも 0 以下である。

dP/dt と d∫B/dt の半離散の列は Fortran の budget.dat にないので、比べていない（17 節）。

conv（I1 と RDpc の N = 4096, 8192）の結果は 10.6 節に示した。
conv は FFTW_ESTIMATE で走らせ、ジョブ 479682 から 479913 まで `restart/` から続けた。

## 18. 未解決の問題

- η_shock を足した I1 と RDpc では、構造の近くの FV 参照解との距離が縮まなくなる（I1 の前方は N = 4096, 8192 で、RDpc の RD から 0.01–0.15 の帯は N = 1024–8192 で。10.6 節）。η を足した系の極限が FV の極限と異なるためか、前漸近的な振る舞いかを区別していない。RDpc の C_eta = 0.5 では距離が N について単調でない（15.2 節）。
- bulk 粘性だけの I1 は、理想解にも FV 参照解にも収束しない。どの極限に近づいているのかを特定していない（10.2 節）。
- 鋭い TD の偽の法線速度 u_x（最大 1.4e-2、N とともに約 N^(−1/3) で縮む）。B の SVV とフィルタが B_y を、ES-SVV が (ρ, m) を別々に均すためだという推定を確かめていない（12 節）。
- η_shock を足した I1 の速度の偏り（約 −2e-3）のうち、FV の極限の前方の波による分と η_shock 自体による分を分けていない（15.2 節）。
- P1a と P3 では E0 < 0 で、E0 で割った相対値が意味を持たない。|ΔE| で割って示した（14 節）。
- C2 の FV 参照解の自己収束が一様でない（観測次数 0.16–0.30）。t = 0.1 の C2 の比較の精度は 3e-3 程度に限られる（5.2 節）。
- RDpc の質量の誤差が N によらず約 1.5e-5 である（7.1 節）。dt³ で縮むことは確かめたが、N によらない理由を調べていない。
- FV 参照解は散逸の 1 つの極限にすぎない（5.2 節）。物理的な散逸（等方的な粘性と抵抗）での極限との関係は確かめていない。
- P1c の overshoot が N とともに増え、S2 の overshoot が N について単調でない（9.2 節）。
