## 1. 結論

定式化 C を採る。状態は (ln ρ, m) で、粘性は保存形、2/3 則のフィルタは m だけに掛ける。
これは Stage 1 で Fortran に実装した既定の組合せそのものなので、Stage 2 の結果を受けて Fortran を変える必要はない。

1D 等温 Euler の試作で、次の変種を比べた。どの変種も (問題, N) ごとに同じ dt で走らせた。

- 理想部の定式化 A・B・C
- 粘性の保存形と展開形
- dealiasing の 6 通り（D0–D5）
- SVV の 2 つの形

結果は次のとおりである。

- 半離散の保存（時間積分に渡す右辺で測った値）
  - C だけが質量と運動量を両方とも丸め誤差の範囲で保存する（|dM/dt| / A_M ≤ 3.2e-15、|dP/dt| / A_P ≤ 3.5e-15）。
    ζ と SVV の恒等式の残差も丸め誤差の範囲にある（R_ζ ≤ 9.7e-16、R_svv ≤ 6.8e-16）。
  - B は質量を保存する（2.2e-15）が、運動量は保存しない（|dP/dt| / A_P が最大 1.8e-4）。
  - A はどちらも保存しない（|dM/dt| / A_M が最大 0.11、|dP/dt| / A_P が最大 6.4e-4）。U4 では質量が N = 512 で最大 9.9%、N = 2048 でも 6.6% 変わる。
  - 理想部がエネルギーを保存するのは B だけである（6.3 節に導出）。
    C の理想部は、衝撃波の試験で粘性の散逸の 4.7e-4–1.7e-2 倍のエネルギーを生む。
- 完全離散の保存: C の質量誤差は max|ΔM/M0| ≤ 1.4e-7 である。時間刻みに対して O(dt³) で縮むことは Stage 1 で確かめた。
  運動量の誤差は max|ΔP| / √(2 M0 E_kin,max) ≤ 1.4e-16 である。
- 衝撃波: N = 512 → 2048 で、C の誤差は 4 問題とも縮む。B・A の衝撃波側の中間状態 ρ* の誤差は、U2・U4 で縮まない。
  - U2 の衝撃波側の ρ* 誤差: C は +1.1e-5 → −1.2e-5、B は +2.9e-4 → +3.4e-4、A は +4.8e-4 → +6.2e-4。
  - U4 の衝撃波側の ρ* 誤差: C は −8.4e-3 → +5.7e-4、B は +7.3e-3 → +1.1e-2、A は +2.5e-2 → +3.8e-2。
  - 非保存形の離散化は誤った衝撃波に収束しうる（Hou & LeFloch 1994）。この結果はその指摘と矛盾しない。
  - 弱い衝撃波（U1、Sod）では、A・B の速度と ρ* の誤差も 5e-4 以下である。
- 粘性の展開形は、運動量の保存を保ったまま（Cexp で 3.5e-15）、R_ζ の恒等式を失う（残差は散逸の最大 6.6%）。
  U4 の膨張側の ρ* 誤差は N = 2048 で 0.13 になり、保存形の 130 倍である。
- dealiasing の変種（9 節）
  - D0（フィルタなし）は、U2・U4 で dt を 1/4 にしても停止する。dt/4 で停止した実行では、どれも E が増えるステップがあった。
  - D2（s にもフィルタ）と D5（2N 格子で積を評価）は質量を失う（max|ΔM/M0| はそれぞれ 3.6e-3 と 4.7e-5）。
  - D3（微分のマスクだけ）は初期の m の高波数成分を凍結し、U4 ではどの dt でも停止する。
  - D4（ṁ にフィルタ）は C と丸め誤差の範囲で一致する（9.2e-15）。
- 滑らかな解では A・B・C の差は小さい。音波の振幅・位相誤差は 3 方式で表示の桁まで一致する。
  C_shock = 2 の単純波の L∞(u) も表示の桁まで一致する。
- SVV の形: U4 の ρ* の改善は ES-SVV の形による。
  - dt を ES-SVV と同じにしても、`linear` の膨張側の ρ* 誤差は N = 1024 で 3.0e-2、2048 で 1.6e-2 である。ES-SVV の 6.5e-3、9.7e-4 より大きい。
    Fortran でも同じ条件で 3 本走らせた。試作と同じ dt の 2 本では、最終の ρ が試作と 6.8e-13 以内で一致した。
  - ただし U2 では、`linear` の ρ* 誤差（7.6e-6）と overshoot（1.6%）が ES-SVV（3.6e-5、2.1%）より小さい。ES-SVV がすべての量で勝るわけではない。
  - 試作で t_end まで走らせる時間は、ES-SVV が `linear`（自身の dt）の 9.3 倍（U4、N = 1024）と 11.4 倍（U4、N = 2048）、2.4 倍と 3.0 倍（U2）である。
- Fortran のソースは変えていないので、MHD_INCOMP の回帰試験は走らせていない。

## 3. 比較した方式

### 3.1 理想部

微分は ∂_N = F⁻¹ i k_d M_d F とする（Stage 1 の 3.1 節）。M_d は微分に掛けるマスクで、既定では 2/3 マスクである。
ρ = e^s、u、m は格子点の値で、積はすべて格子上で作る。

- A（展開形の (ln ρ, u)）: ṡ = −u ∂_N s − ∂_N u、u̇ = −u ∂_N u − c² ∂_N s
- B（質量と整合する (ln ρ, u)）: ṡ = −∂_N(ρu) / ρ。u̇ は A と同じ。
- C（(ln ρ, m)）: ṡ = −∂_N m / ρ、ṁ = −∂_N(ρu² + c²ρ − q)

A・B の第 2 の状態 u には、C の m と同じ 2/3 フィルタを掛ける（D1 に相当する）。
s にはどの方式でもフィルタを掛けない。

### 3.2 散逸項

散逸項（shock viscosity と SVV）は全方式で共通にした（ユーザーの決定）。
保存変数 (ρ, m) で C と同じ (ρ̇_d, ṁ_d) を作り、A・B では点ごとに ṡ_d = ρ̇_d / ρ、u̇_d = (ṁ_d − u ρ̇_d) / ρ に直す。
散逸の定義を揃えたので、方式の差は理想部の離散化の差と、状態のフィルタがどの量に掛かるかの差だけになる。

### 3.3 粘性の形

q = ρζD、D = ∂_N u とする。

- 保存形（`'flux'`、既定）: ṁ_v = ∂_N q。∂_N が反自己共役なので Σ u ∂_N q = −Σ ρζD² が成り立つ（R_ζ の恒等式）。
- 展開形（`'expanded'`）: ṁ_v = ρζ ∂_N D + D ∂_N(ρζ)。連続系では保存形と同じ式である。

展開形は C（Cexp）と A（Aexp）で比べた。

### 3.4 dealiasing の変種

dealiasing の変種は C で比べた。

| 変種 | 内容 | 試作の設定 |
|---|---|---|
| D0 | フィルタなし（状態にも微分にもマスクを掛けない） | `filter_m=False` |
| D1 | m だけにフィルタ（既定、= C） | 既定 |
| D2 | s と m にフィルタ（Fortran の `filter_lnrho = T`） | `filter_s=True` |
| D3 | 微分のマスクだけ（状態にはフィルタを掛けない） | `filter_m=False, deriv_mask='mask'` |
| D4 | 状態でなく ṁ にフィルタ | `filter_rhs=True` |
| D5 | 2N 格子で積を評価（over-integration） | `pad=2` |

D5 は試作だけの変種で、Fortran の `pruned = T`（3/2 則）とは違う。`pruned = T` は s にも射影を掛けるので `filter_lnrho = T` を要する（Stage 1 の 9 節）。

### 3.5 SVV の形

既定の ES-SVV（`svv_form = 'entropy'`）と、初版の線形の SVV（`'linear'`）を比べた。
`linear` は ES-SVV と同じ dt（lin）と、`linear` 自身の dt の上限から決めた dt（lin_own）の 2 通りで走らせた。

## 4. 試験の組と時間刻み

- 衝撃波: U1・U2・U4・Sod（`gen_stage1.RIEMANN`、t_end は Stage 1 と同じ）を N = 512, 1024, 2048 で走らせた。
  - C, B, A, Cexp, Aexp, D0, D2, D3, D5 は全組で走らせた。
  - D4 は U2 の N = 1024 だけで走らせた。C と丸め誤差の範囲で一致するはずなので、確認に 1 本だけ走らせた。
  - lin, lin_own は U2・U4 の N = 1024, 2048 で走らせた。
- 音波: N = 32, 64、C_shock = 0, 2（振幅 1e-3、1 周期）を A・B・C で走らせた。
- 単純波（破砕前、t = t_b/2）: N = 32–512 で、C0_nosvv、C0_svv、C2_svv を A・B・C で走らせた。

計 174 本である。

dt は (問題, N) ごとに `gen_stage1.py` の SAFETY × DTMIN（SAFETY = 0.7）に固定し、全変種で同じ値を使った。
DTMIN は、試作の C（ES-SVV）を走らせたときの min(dt_adv, dt_visc) の最小値である（Stage 1 で測った表）。
dt が変種ごとの上限を超えたステップでは、黙って dt を縮めずに停止する（`cfl`）。
非有限値（`nonfinite`）や dt λ_svv > 2.51（`svv_unstable`）でも停止する。
停止した変種は dt/2、dt/4 で走らせ直し、全試行を記録した。dt を下げれば走る場合と、dt によらず停止する場合を区別するためである。

## 5. 測った量

半離散の量は、各ステップの第 1 段の状態で `proto1d.budget()` から求めた。
A・B は格子上の (ρ̇, ṁ) = (ρṡ, ρu̇ + uρṡ) に直し、C と同じ式で測る。

- dM/dt = Σ ρ̇ dV、dP/dt = Σ ṁ dV。規格化は A_M = Σ|ρ̇_ideal| dV と A_P = Σ|ṁ_ideal| dV である。
- エネルギー E = Σ [½ρu² + c²ρ(s − 1)] dV の時間微分は Σ (w_ρ ρ̇ + u ṁ) dV、w_ρ = c²s − u²/2 である。
  理想部・粘性・SVV の寄与をそれぞれ ε_ideal、ε_visc、ε_svv とする。
- R_ζ = ε_visc + visc（visc = Σ ρζD² dV で規格化）と R_svv = ε_svv + D_svv（A_svv = Σ|w_ρ ρ̇ + u ṁ|_svv dV で規格化）。
- どの量も、段ごとに状態に掛けるフィルタを時間微分に掛けた値で測る。時間積分が実際に使うのはこの値である。
  フィルタを掛ける前の値を括弧内に併記した。
- 時間積分した量は、dt × 第 1 段の値の和とした（Fortran の `budget.dat` の段の重み付き和とは違う）。

A は dM/dt ≠ 0 なので、A の ε_ideal は E の定数項の選び方に依存する。A の ε_ideal は参考値である。

完全離散の量は次の 3 つである。

- max|ΔM/M0|
- max|ΔP| / √(2 M0 E_kin,max)
- E が前のステップより増えたステップの数と、その最大の増分 / |E0|

衝撃波の精度は `analyze_stage1.riemann_analysis` をそのまま使って測った（衝撃波速度・ρ*・位置・over/undershoot・L1(ρ) とその観測次数）。
そのうえで Rankine–Hugoniot（RH）の残差を足した。
測った上流・下流の平坦部から S_mass = [m]/[ρ] と S_mom = [ρu² + c²ρ]/[m] を作り、当てはめた速度 S_fit との比 S_fit / S − 1 を残差とする。

滑らかな解には `sound_analysis` と `simple_wave_analysis` を使った。

方式ごとの保存の性質は次のとおりである。

| 方式 | 質量（半離散） | 運動量（半離散） | 理想部の E | R_ζ, R_svv の恒等式 |
|---|---|---|---|---|
| C | 保存 | 保存 | 保存しない | 成り立つ |
| B | 保存 | 保存しない | 保存 | u のフィルタで崩れる |
| A | 保存しない | 保存しない | 保存しない | u のフィルタで崩れる |
| Cexp | 保存 | 保存 | 保存しない | R_ζ が崩れる |
| D2 | s のフィルタで崩れる | 保存 | 保存しない | R_svv が崩れる |
| D5 | ṡ の切断で崩れる | 保存 | 保存しない | R_svv が崩れる |

完全離散では、C の運動量は丸め誤差の範囲で保存し、質量は O(dt³) の誤差を持つ。
m は状態そのものなので、RK 法の各段で Σ m の線形の保存がそのまま成り立つ。
これに対し、M = Σ e^s は状態 s の非線形関数で、RK 法はこれを厳密には保存しない。
B の質量誤差（1.0e-7）は C（1.4e-7）と同じ桁である。

A の質量誤差は、N = 512 / 1024 / 2048 の順に、U4 で 9.9e-2 / 7.9e-2 / 6.6e-2 である。
U2 では 3.1e-3 / 2.9e-3 / 2.9e-3、Sod では 2.7e-5 / 2.4e-5 / 2.4e-5、U1 では 7.4e-5 / 7.4e-5 / 7.6e-5 である。
U4 では N を 4 倍にして 2/3 になるだけで、ほかの問題ではほとんど変わらない。

B・A の R_ζ と R_svv は、u̇ にフィルタを掛ける前は丸め誤差の範囲（1.7e-15 以下）にある。掛けた後は 1.8e-1 と 4.2e-2（B）になる。
散逸項のエネルギー寄与のうち u̇ を通る部分は ⟨ρu, P[u̇_d]⟩ で、2/3 射影 P は自己共役だが ρu は帯域制限されていないので、⟨ρu, u̇_d⟩ と一致しない。
B・A では、散逸項の符号が理想部の外で保証されない。それでも全実行で E が増えたステップはなかった。

### 6.2 恒等式の確認

U4（N = 1024、C、t = 0.127）の状態を各変種に写して、右辺の恒等式を確かめた（`stage2.py check`）。
A・B の状態 u は、この状態の m/ρ に 2/3 フィルタを掛けて作った。

| 変種 | \|dM\|/A_M | \|dP\|/A_P | \|R_ζ\|/visc | \|R_svv\|/A_svv | ε_ideal |

### 6.3 B の理想部がエネルギーを保存する理由

B の理想部は、u が 2/3 則で帯域制限され、s にフィルタを掛けないとき、半離散で E を厳密に保存する。
導出は次のとおりである。⟨f, g⟩ = Σ f g dV と書き、∂_N の反自己共役性 ⟨f, ∂_N g⟩ = −⟨∂_N f, g⟩ を使う。

1. s にフィルタを掛けないので ρ̇ = ρṡ = −∂_N m（m = ρu は格子上の積）である。
   したがって ⟨c²s, ρ̇⟩ = c²⟨m, ∂_N s⟩ と ⟨½u², ρ̇⟩ = ⟨m, ∂_N(½u²)⟩ が成り立つ。
2. u̇ = P[−u ∂_N u − c² ∂_N s] で、P は 2/3 射影である。
   ∂_N s は M_d を含むので P[∂_N s] = ∂_N s となる。
   u は |k| < N/3 に帯域制限されているので、積 u ∂_N u の成分は |k| < 2N/3 にあり、N 格子での折り返しは |k| > N/3 に落ちる。
   P はこの折り返しを取り除くので、P[u ∂_N u] = ½ ∂_N(u²) が厳密に成り立つ。
3. よって ⟨ρu, u̇⟩ = −⟨m, ∂_N(½u²)⟩ − c²⟨m, ∂_N s⟩ である。
4. dE/dt = ⟨c²s + ½u², ρ̇⟩ + ⟨ρu, u̇⟩ なので、1 と 3 を足すと 0 になる。

射影の前では P[u ∂_N u] = ½ ∂_N(u²) が成り立たないので、和は 0 にならない（6.2 節の表で +1.6e-2）。

### 6.4 C の理想部がエネルギーを保存しない理由

C の理想部では ρ̇ = −∂_N m、ṁ = −∂_N(ρu² + c²ρ) なので、反自己共役性から次の式が得られる。

ε_ideal = c²(⟨m, ∂_N s⟩ − ⟨u, ∂_N ρ⟩) + (⟨m, u ∂_N u⟩ − ⟨m, ∂_N(½u²)⟩)

連続系では、連鎖律 ∂ρ = ρ ∂s と積の微分則 u ∂u = ∂(½u²) から、どちらの括弧も 0 になる。
格子上の ∂_N ではこれらが成り立たない。ρ = e^s も u = m/ρ も帯域制限されていないためである。
したがって C は運動量を保存してエネルギーを保存せず、B はエネルギー（理想部）を保存して運動量を保存しない。
質量・運動量・理想部のエネルギーを同時に保存する離散化は、今回の比較に含めていない。

衝撃波の試験では C の ∫ε_ideal は正であり、∫ε_ideal / ∫visc は U1 で 4.8e-4–5.9e-4、U2 で 2.5e-3–3.0e-3、Sod で 4.7e-4–8.0e-4、U4 で 1.33e-2–1.73e-2 である。
どの問題でも N とともに小さくなる。
理想部が作るエネルギーは粘性の散逸の 2% 以下で、粘性と SVV がそれを上回って散逸するので、E が増えたステップはない。

### 6.5 予想との照合

計画時の予想と結果を照らすと、次のとおりである。

- C: 半離散の M, P は丸め誤差の範囲、完全離散では M が O(dt³)、P は丸め誤差の範囲という予想は当たった。
- B: M が C と同じで、衝撃波では P を半離散で保存しないという予想は当たった。理想部の E の保存（6.3 節）は予想していなかった。
- A: M も P も保存しないという予想は当たった。滑らかな解で A・B・C の差が小さいという予想も当たった。
- 衝撃波の誤差が A・B では N を増やしても縮まないという予想は、U2・U4 の衝撃波側の ρ* と U2 の速度では当たった（7 節）。
  U4 の A の速度誤差と、膨張側の ρ* の B の誤差は、縮むが遅い（7.2 節）。
- 展開形の粘性が P の保存を失うという予想は外れた。⟨1, a ∂_N b + b ∂_N a⟩ = ⟨a, ∂_N b⟩ + ⟨b, ∂_N a⟩ = 0 なので、展開形の ṁ_v の和も 0 である。
  R_ζ の恒等式を失うという予想は当たった。
- D0 が U2・U4 で破綻し、D2 で質量誤差が増えるという予想は当たった。
- D3 の破綻（9 節）と D5 の質量誤差は予想していなかった。

初期の不連続から出る振動が、非保存形の u の式を通じて平均の状態をずらす可能性があるが、確かめていない。

各方式は、保存する量の RH 条件だけを満たす。

- U2 の質量の残差は C で 3.5e-4 / 1.6e-4 / 1.0e-5、B で 1.9e-4 / 6.8e-5 / 1.0e-5 と縮み、A では 6.1e-3 / 5.7e-3 / 5.6e-3 のまま変わらない。
- U2 の運動量の残差は C で 4.4e-4 / 1.4e-4 / 1.1e-4、A で 2.1e-3 / 3.8e-4 / 5.2e-4 で、B では 2.6e-3 / 2.6e-3 / 2.8e-3 のまま変わらない。

衝撃波側では S_mom = (ρ* − 17) / (−4) で、分子が 17.944 − 17 = 0.944 の差になるので、ρ* の相対誤差が約 19 倍に拡大される。
C の N = 2048 の運動量の残差 1.1e-2 は、ρ* の誤差 5.7e-4 の 19 倍にあたる。

### 7.4 速度の測定の分解能

速度は、衝撃波を検出できた出力時刻の位置を直線で当てはめて求める。
`linear` を ES-SVV の dt で走らせた U4（N = 1024）では、試作と Fortran（11 節）の最終時刻の ρ が 2.4e-13 で一致する。
それでも速度誤差は、試作で −1.35e-4（13 点）、Fortran で −1.26e-3（14 点）である。
Fortran の出力を試作と同じ 13 点に絞っても −8.7e-4 で、試作と一致しない。
試作と Fortran では出力の時刻が違うので、当てはめに使う標本の時刻が違い、その違いで値が 1e-3 程度動くとみられる。
したがって、U4 の N = 1024 の速度誤差は 1e-3 より細かい差を分解しない。
N = 2048 では試作と Fortran の速度誤差が一致する（`linear`、ES-SVV の dt で −3.351e-4 と −3.352e-4、どちらも 17 点）。
方式の比較には、N = 2048 の値と、ρ* と質量の RH 残差を使った。

## 8. 粘性の保存形と展開形

展開形は、質量と運動量の保存を変えない（Cexp は C と同じ dM/dt、dP/dt、ΔM、ΔP）。
変わるのは R_ζ の恒等式で、∂_N(ρζD) ≠ ρζ ∂_N D + D ∂_N(ρζ) なので、粘性のエネルギー寄与が −visc から散逸の最大 6.6% ずれる（m のフィルタを掛ける前は 14%）。
展開形の ṁ_v は帯域制限されていない積を含むので、保存形と違って m のフィルタがこの項に効く。

衝撃波側の精度は保存形とほぼ同じである（U4 の界面 1 の ρ* で +8.3e-4、保存形は +5.7e-4）。
膨張側では悪く、U4 の界面 2 の ρ* の誤差は N = 512 / 1024 / 2048 で +0.30 / +0.21 / +0.13、星領域内の ρ の振れ幅（最大 − 最小）/ ρ* は 0.84 / 0.50 / 0.41 である。
保存形の振れ幅は 0.31 / 0.11 / 0.032 である。
振れ幅が大きい理由は調べていない。

A の展開形（Aexp）は U4 の N = 512, 1024 で、dt を 1/4 にしても停止した（t = 0.225–0.228、0.283–0.309）。
停止時刻が dt にほとんどよらないので、時間積分の不安定ではなく、半離散の解が CFL の上限を下げているとみられる。
N = 2048 では t_end に達したが、U4 の速度誤差は 0.12、L1(ρ) は 0.75 である。

R_ζ の恒等式を持つのは保存形だけなので、保存形を既定のまま残す。

## 9. dealiasing の有無と位置

### 9.1 D0: フィルタなし

M_d = 1 では微分の最大波数が N/2 になり、kd² の最大値が 2/3 マスクの 2.25 倍になる。
dt_visc がこれに反比例するので、C の dt（dt/1）は dt_visc を超えて、全問題で停止する（`cfl`）。
U1・U2・U4 は最初のステップで、Sod は 28–30 ステップで停止した。
dt/2 では U1・U2 が最初のステップで停止し、U4 は 725–1222 ステップ（t = 0.0134, 0.0080, 0.0043）で停止した。Sod は dt/2 で t_end に達した。

dt/4 では U1 が t_end に達したが、U2 と U4 は停止した。
U2 は 1325–1470 ステップ（t = 0.0821, 0.0404, 0.0205）、U4 は 2121–2795 ステップ（t = 0.0195, 0.00963, 0.00495）で停止し、停止時刻は 1/N に比例する。
dt/4 で停止した 6 本では、E が増えたステップが 269–664 あり、増分は最大で E0 の 5.8e-5–1.7e-4 である。
dt/2 で停止した U4 の 3 本でも、E が増えたステップが 0 / 26 / 156 あった（N = 512 / 1024 / 2048）。
∫ε_ideal / ∫visc は 1.26–6.03 で、理想部が作るエネルギーが粘性の散逸を上回る。
折り返し誤差がエネルギーを注入し、それが散逸を上回ったために停止したと解釈できる。

### 9.2 D2: s と m にフィルタ

ṡ に射影を掛けると Σ ρ ṡ = 0 が崩れる。ρ = e^s が射影の外の波数を持つためである。
質量誤差 max|ΔM/M0| は U2 で 1.0e-4 / 1.6e-4 / 1.9e-4、U4 で 3.6e-3 / 1.9e-3 / 8.9e-4、U1 と Sod で 2.1e-5–2.7e-5 である。
U2（N = 1024）の 1.6e-4 は、Stage 1 の Fortran の `filter_lnrho = T`（`fs_nt6`）の値 1.6e-4 と一致する。
衝撃波の精度は C と同じ程度で、Sod の ρ* だけが 1.8e-4（C は 3.3e-7）に悪化する。

### 9.3 D3: 微分のマスクだけ

C では、ṁ のどの項も M_d で帯域制限されている。理想部、粘性の流束、SVV（Stage 1 の 3.3 節の A_L,d* が M を含む）のいずれもそうである。
そのため、m の状態に掛けるフィルタは、実際には初期条件にしか効かない。
D3 は初期の m を切断しないので、m の k ≥ k_c 成分が時間発展せずに残る（U4、N = 1024 で max|m̂(k ≥ k_c)| = 1.73e-3 のまま変わらない）。
初期の m だけを切断した D3 は、C と ŝ で 3.8e-15、m̂ で 6.3e-16（相対）まで一致した。

- Sod は初期に u = 0（m = 0）なので、D3 は C と丸め誤差の範囲で一致する（Δρ ≤ 6.5e-15）。
- U1・U2 は t_end に達するが、膨張側の ρ* 誤差が大きい（U2、N = 2048 で −4.7e-3、C は −1.7e-6）。
- U4 はどの dt でも停止する。dt を 1/4 にしても停止時刻は 0.0367 → 0.0392（N = 1024）しか延びず、停止時の ρ_min は 2.8e-3、1.1e-3、4.7e-4 と下がる。
  半離散の解そのものが t ≈ 0.04 で ρ → 0 に向かうとみられる。凍結した高波数の m がどのようにしてこれを引き起こすのかは調べていない。

### 9.4 D4: ṁ にフィルタ

9.3 節の理由で、D4 は C と同じ軌道になる。U2（N = 1024）の最終の ρ の差は 9.2e-15（max ρ に対する比）である。

### 9.5 D5: 2N 格子での評価

D5 は積を 2N 格子で評価し、時間微分を N の成分に切断する。
ṡ の切断で Σ ρ ṡ = 0 が崩れる点は D2 と同じで、2N 格子の ρ が N の成分の外の波数を持つためである。
質量誤差は U2 で 1.3e-6 / 6.9e-7 / 5.7e-7、U4 で 4.7e-5 / 3.7e-5 / 3.0e-5、Sod で 4.0e-7 / 2.2e-7 / 1.3e-7 である。
Fortran の `pruned = T`（Stage 1、N = 1024）の質量誤差は U2 で 4.3e-5、Sod で 6.8e-6 だが、こちらは s も射影する別の方式なので、値は比べられない。
精度は C と同じ程度で（U4 の N = 2048 で ρ* の誤差 +5.4e-4 / −1.0e-3、C は +5.7e-4 / −9.7e-4）、1 ステップの時間は C の 1.6 倍である。

### 9.6 dealiasing の選択

既定の D1 を残す。D1 は質量・運動量・恒等式をすべて保ち、D5 より安い。
D1 の m のフィルタは初期条件だけに効くが（9.3 節）、Fortran の既定（`filter_mom = T`）は段ごとに掛けており、結果は同じである。

## 12. 状態変数と離散化の関係

(s, u) を状態にしても、u の式を u̇ = (ṁ_C − u ρ̇_C) / ρ とすれば、状態のフィルタを除けば半離散の軌道は C と同じになる。
したがって、A・B と C の差は理想部の離散化から生じ、状態変数の選び方からは生じない。
状態変数の選び方が効くのは、時間積分とフィルタの段階である。

- 時間積分: RK 法は状態の線形の量を保存する。(s, m) では Σ m が保存される。(s, u) では Σ ρu が状態の非線形関数なので、同じ右辺でも P の誤差が残る。
  3 次の RK 法なら O(dt³) と見積もられるが、この組合せは走らせていないので数値では確かめていない。
- フィルタ: 2/3 射影を m に掛けるか u に掛けるかで、Σ m や散逸の恒等式が崩れるかどうかが決まる（6.1 節の B・A の R_ζ）。

## 13. 方式の選択

C（保存形の粘性、D1）を採る。理由は次の 3 つである。

- 質量と運動量を両方とも半離散で丸め誤差の範囲で保存し、散逸の恒等式（R_ζ、R_svv）がフィルタの後も成り立つのは、比べた方式のうち C だけである。
- 4 つの Riemann 問題すべてで、ρ*・速度・RH の質量の残差が N とともに縮む。
- 1 ステップの費用は B・A より 12–13% 小さい（試作、収支の計算を含む。Fortran では測っていない）。

C の弱点は理想部がエネルギーを保存しないことで、エネルギーの安定性は粘性と SVV の散逸に頼る。
C の衝撃波の試験で理想部が作るエネルギーは粘性の散逸の 2% 以下（6.4 節）だが、強い衝撃波を含む多次元の計算でこの比がどうなるかは調べていない。

B は理想部のエネルギーを保存するが、運動量を保存せず、U2・U4 の衝撃波側の ρ* と速度の誤差が N = 2048 まで縮まない。
A は質量も保存せず、U4 で質量が 6.6–9.9% 変わり、衝撃波の位置が最大 3.6 格子ずれる。
衝撃波を含む問題で B・A を使う利点は見つからなかった。
