## 1. 結論

Stage 1–3 の離散化（定式化 C、ES-SVV、衝撃波粘性 ζ、η_shock、eSSPIFRK3）を変えずに、2D の x-z 面と 3D の周期箱で 4 種の問題を走らせた。
円偏光 Alfvén 波と斜めの平面問題は、多次元でも 1D と同じ精度で解ける。
等温 Orszag–Tang 渦（OT）は N = 1024 まで停止せずに走り、散逸の量は収束したが、電流層の中の各点の値は収束しなかった。
3D の減衰乱流は、M_s = 1 が 64³ と 128³ で t_end まで走ったが収束は示せていない。
M_s = 4 は格子 1–3 点の幅の密度の穴で dt が縮み続け、t_end に届かなかった。
段ごとの判定は、S4.0 と S4.2 が合格、S4.1 が 1 本を除いて合格、S4.3 と S4.4 が不合格である（10.1 節）。

元の指示の評価項目ごとの結果は次のとおりである。

- 安定性（4–8 章）
  - OT と乱流で非有限値は出ていない。dt λ_svv の最大は 2.00 で、ES-SVV の安定の上限 2.51 の内側にある。
  - 質量の相対変化は OT と乱流で 1.4e-7 以下である。恒等式の残差 R_ζ, R_svv/A_svv, R_η は OT と乱流で 1.3e-13 以下、平面問題で 5.4e-12 以下（条件 1e-10）である。div B の指標は 1.0e-17 以下である。
  - MPI 分割による 10 step 後の面の差は、OT（N = 256、P = 4–256）で 8.9e-16 以下、乱流（64³、P = 1, 8, 64）で 3.6e-15 以下である。
  - 固定 dt で CFL の条件を超えて止まった 2 本は、dt を下げて走らせ直した。そのうち M_s = 1 の 128³ は t_end まで走った。
  - M_s = 4 の 2 本では、ρ が格子 1–3 点の幅の穴で 0 に向かい（ρ_min 1.2e-4–3.4e-4）、ρ で重みをつけた SVV の剛性と、箱全体で決まる SVV の係数 ε_d が増えて、dt が 2e-8 以下まで縮んだ（8.3 節）。δB を B0 まで弱めても起きた。密度の床や一様な粘性は足していない。
  - 円偏光 Alfvén 波の振幅 1 の理想の実行は、m と B を 2/3 マスクで打ち切ったことによる偽の不安定で育つ。成長率はコードの系を線形化した値と一致し、ES-SVV が N ≥ 32 でこれを抑える（5.3 節）。
- 乱流スペクトル（8.4 節）
  - M_s = 1 の 64³ と 128³ のスペクトルが合う帯域 k_eff は、t ≤ 1.5τ0 で 15–16（64³ の SVV のかかり始める m_N = 10.7 と k_c = 21.3 の間）で、t = 3τ0 では 6 に下がる。
  - 256³ と比べていないので、128³ の帯域と k_eff の比は求めていない。
- エネルギー散逸（7.4 節、7.7 節、8.4 節）
  - OT（C_eta = 0）の散逸率の最大値は N = 128–1024 で 25.6, 25.4, 25.1, 24.9 で、隣り合う N の差は 1.5% 以下である。[0, π] の散逸の 93%（N = 1024）を衝撃波粘性が担う。
  - M_s = 1 の乱流では、[0, 3τ0] の散逸の総量の差は 1.3%、散逸率の最大値の差は 3.1% だが、最大の時刻は 29% 違う。散逸の 7 割を SVV が担う。
- 解像できる高波数帯域（7.5 節、7.7 節）
  - OT の k_eff は、t = 2, 3 で N = 512 から 1024 へ 1.88, 2.02 倍になり、N に比例して広がる。
  - 衝撃波ができかけの t = 1 では、k_eff は N = 128–256, 256–512, 512–1024 の比較で 21, 33, 51 と、N^0.64 でしか増えない。その原因は調べていない。
- 衝撃波粘性の空間分布（7.5 節、8.4 節）
  - OT では ζ の強い帯が衝撃波の線に沿う。ρ ζ D² の 90% を占める面積比 a90 は、N を倍にするごとに t = 2, 3 で 0.50–0.54 倍になり、衝撃波粘性の散逸は幅が Δ に比例する帯に集まる。
  - M_s = 1 の乱流では、ζ > 0.01 ζ_max の点が面のほぼ全体を覆い、a90 の比は 0.79–0.92 である。ζ の散逸の多くは格子幅の衝撃波でなく、広い領域の滑らかな圧縮が担う。
  - 計画の「ζ > 0.01 ζ_max の面積比」は、滑らかな圧縮でも閾値を超えるので、衝撃波の局在の指標にならなかった。a90 に替えた。
- 並列計算性能（9 章）
  - 1 ノード（256 コア）の中の強スケーリングの効率は、2D の 1024² で P = 128 まで 0.72 以上、3D の 256³ で P = 256 で 0.63 である。1 ノードの実行では、SVV が step の 39–49%、収支の計算が 18–23% を占める。
  - 複数のノードにまたがると速くならない。2D の 1024² の 1 step は、1 ノード（P = 256）に対して 2 ノードで 13.6 倍、4 ノードで 32–36 倍（10 step からの推定）かかり、3D の 256³ は 2 ノードと 4 ノードで 1 ノードの 1.10 倍と 0.89 倍である。

ほかに次のことが分かった。

- C_eta の既定値は多次元でも 0 とする。η_shock は fast 衝撃波の B_t の overshoot を約 3 分の 1 にするが、N ≤ 512 では L1 誤差を 1.2–1.4 倍に増やし（6.4 節）、円偏光 Alfvén 波の偽の成長を強め（5.4 節）、OT の散逸率の最大値は N = 256–512 で 6.1% 違う（7.5 節）。
- Stage 1–3 の代表 6 ケースの出力は、Stage 3 の実行ファイルとビット一致する（4.2 節）。MHD_INCOMP とほかのモデルが使うファイルは変えていない。
- s4 までの実行ファイルは、check_terminate で止まった実行の最後の step の budget.dat の行を書かないので、restart でつないだ実行の収支の時系列は、つなぎ目ごとに 1 行欠ける。つなぎ目で欠けた行のエネルギーの変化は全エネルギーの変化の 4.3e-4 以下で、ほかの行の収支は閉じている。`advance.F90` を直し、止めてつないだ実行が止めずに走らせた実行とビット一致することを確かめた（3.3 節）。

## 3. 多次元の実行の組み立て

### 3.1 初期値

多次元の初期値は、コードに初期化の分岐を足さずに Python で作った。
`gen_ic.py` が Fourier 係数を restart の形式（複素数の大域配列、1/(nlx nly nlz) の規格化）で `ic/` に書き、コードは `init_type = 'restart'` で読む。
これで初期値は MPI 分割によらず、乱数の seed も Python 側で固定できる。

書き出す前に、m と B に 2/3 マスクをかけ、B はコードと同じ波数（Nyquist を含む）で div B = 0 に射影する。
そのため、読んだ直後の `div_free` とマスクは状態を変えない。
s = ln ρ は、滑らかな初期値ではマスクをかけ、不連続を含む初期値ではかけない（Stage 3 と同じ）。

### 3.2 2D の面と分割

2D の実行はすべて x-z 面（nly = 2、`dim_decomp = 1`）で行った。
P3DFFT の分割では、x-y 面（nlz = 2）を分割できる rank 数が 4 以下に限られるが、x-z 面は N rank まで分割できる。

### 3.3 時間刻みと restart の連鎖

dt は（問題, N）ごとに固定した。
reset_method = 'stop' なので、CFL を超えれば止まって分かる。
ジョブスクリプトは、30 分のジョブの中で終わらなかった実行を、残りのステップ数で restart から続ける。
残りのステップ数は入力の dt から計算するので、この連鎖が正しいのは dt を変えない実行に限る（dt が変われば `dt_changed` で止める）。

例外は乱流の `turb4_N64_a`、`turb1_N128_a`、`turb4b_N64` で、dt を下げながら走らせた（8.1 節、8.3 節）。
そのための仕組みとして、ケースにファイル `t_end` を置くと、ジョブスクリプトは reset_dt が残した dt で t_end まで走らせる。
続きの実行では、cfl.dat の最終行（毎 step、全精度で書く）から最後の step の dt を取り、その t + dt が `restart/time.dat` の t と一致することを確かめる。
残りのステップ数は (t_end − t)/dt を四捨五入した値とする。
dt を下げたために t_end − dt/2 の手前で正常に終わった実行は、`incomplete` として次のジョブで続ける。

restart でつないだ実行の収支の時系列には、つなぎ目ごとに 1 step 分の行が欠けていた。
budget.dat の行は、その step の収支を次の step の非線形項の計算の中で書くので、check_terminate（`max_wall_time` かファイル `terminate`）で止まった実行は、最後の step の行を書かずに終わる。
`check_seams.py` で、つないで走らせた本番の 9 本（OT 3 本、平面問題 3 本、乱流 3 本）を調べた。
欠けた行は、7 本でつなぎ目ごとに 1 行（1 本あたり 1–3 行）、最後の実行を途中で止めた M_s = 4 の 2 本で末尾の 1 行だった。
残りの行は丸め誤差で閉じている。全エネルギーの変化から、行の収支の積分とつなぎ目の跳びを引いた残差は、9 本とも 0 だった。
つなぎ目で欠けた行のエネルギーの変化（つなぎ目の跳び）は、各ケースの全エネルギーの変化の 4.3e-4 以下（OT と乱流で 1.4e-4 以下）である。
M_s = 4 の末尾の 1 行は、dt が 2e-8 以下に縮んだ後の step である。
したがって、この報告の散逸の量と割合は欠けた行で変わらない。

終了処理（`advance.F90` の `deallocate_advance`）を直し、check_terminate で nstep の前に止まった実行でも、最後の状態の非線形項を 1 回求めて、monitor と line の出力（最後の step の budget.dat の行を含む）を書くようにした。
この修正の実行ファイル `bin/calliope_isoth_s4b` で、64³ の乱流（`turb1` の初期値、P = 64、30 step）を 2 通りに走らせた（job 481755、`runs/stage4/seam`）。
1 つは止めずに走らせ、もう 1 つは 1 step の後にファイル `terminate` で止めて restart から 29 step 続けた。
つないだ実行は 30 行すべてを書き、budget.dat のすべての列と restart の状態が、止めずに走らせた実行とビット一致した。
修正前の実行ファイルでは、つないだ実行の行が 1 つ欠けた。止めずに走らせた実行の出力は、修正の前後でビット一致した。
この報告の数値は、すべて修正前の実行ファイルの出力から求めた。

### 3.4 1 ジョブで複数の実行を同時に走らせる場合

小さい実行は、1 ジョブの中で `PAR` を使って同時に走らせた。
最初のジョブ（481200、3 ノード）では、64³ の乱流が較正（4.3 節）の約 20 倍遅く、途中で止めた。
Intel MPI の mpirun は `-hosts` を与えないと `$PBS_NODEFILE` の先頭のノードから rank を詰めるので、同時に起動した実行がすべて 1 ノードに集まっていた。
ジョブスクリプトを直し、各実行の rank を置くノードを `-hosts` で指定するようにした。
1 ノードに収まる実行は空きのある 1 ノードに置き（小さい実行どうしは 1 ノードを分け合う）、収まらない実行には空いたノードを丸ごと与える。
配置は、偽の mpirun と 3 ノード分の nodefile で確かめてから投げ直した（481212）。
481200 で終わった分割試験の 3 本（10 step）は、詰め込まれて遅かっただけで、数値は有効なのでそのまま使う。

## 4. S4.0 基盤

### 4.1 読み戻し

16² の x-z 面と 16³ の非対称な滑らかな場（job 480835, `runs/stage4/readback`）で、次を確かめた。

- nstep = 0 の実行が書いた `restart/*.dat` は `ic/*.dat` とビット一致する。

conservation.dat などの総和の列は、MPI_Allreduce の加算順で 5 ulp 程度ずれる（各ファイルの尺度に対し 1.6e-15）。
判定は「状態はビット一致、総和は 1e-13 以内」とした。

### 4.2 回帰

Stage 3 の実行ファイル（60d78cc）と Stage 4 の実行ファイルで、Stage 1–3 の代表 6 ケース（sound64、U2 の N = 512、selftest の np = 1, 2, 4、C3 の N = 256 を z 方向に np = 4）を FFTW_ESTIMATE で走らせた（`runs/stage4/regress`）。

### 4.3 費用

各ケースを 100 step 走らせ、FFTW_MEASURE で 1 ケースずつ測った（job 480850, `runs/stage4/calib`）。
step の時間は rank の最大値である。

費用は計画の見積もり（Stage 1 の 16³ から 2e-6 core·s/点·step）の 2–9 倍だった。
SVV（エントロピー変数への変換と、そのエネルギーの寄与の計算）が step の 41–51% を占め、収支の計算（stage_budget）が 17–22% を占める。
収支は RK の各段で全エネルギーの変化を機構ごとに分けるので、間引くと時間積分の収支（err_t）が閉じなくなる。そのため間引いていない。

M_s ≈ 4 の乱流では、dt を SVV の安定条件が決める（64³ で dt_visc = 1.38e-4、移流の dt の 1/8.7）。
λ_svv と線形の上限 Σ_d ε_d k_d,max² の比は M_s ≈ 1 で 0.8–1.0、M_s ≈ 4 で 7.0–7.9 だった。
エントロピー変数のヤコビアンに |u|²/c_s² の項があることが原因と推定しているが、確かめていない。

## 5. S4.1 円偏光 Alfvén 波

### 5.1 設定と最初の実行の失敗

一様な ρ = 1、B0 = 1、c_s = 1 の上の有限振幅の円偏光 Alfvén 波は、等温 MHD の厳密解である（δB⊥/B0 = 0.1 と 1）。
D = ∇·u = 0 が解析的に成り立つので、ζ と η_shock は丸め誤差の水準でしか立たない。
波数は 2D x-z 面の k = (1,1), (1,2) と、3D の k = (1,1,2) とその軸の入れ替えで、N = 16–64（2D）、16–32（3D）、1 周期と 10 周期、dt を 3 通りにした。
係数をすべて 0 にした理想の実行と、既定の設定（C_shock = 2、ES-SVV、C_eta = 2）を比べた。

最初のジョブ（480849）の 63 ケースは、すべて dt_changed で無効だった。
ps1 の numpy 2.0.2 では `repr(np.float64(x))` が `'np.float64(x)'` になり、calliope.in の dt がこの形で書かれた。
`time.F90` は namelist の読み込みの失敗を表示するだけで、既定値（dt = 1, nstep = 100）で走った。
`isoth_case.fmt` で numpy のスカラーを Python の値に直し、`analyze_stage4.status` が `.std` から namelist の読み込みの失敗を検出するようにした（再実行は job 480854）。

### 5.2 結果

振幅 0.1 は全項目が合格した。

- |ρ − 1| と u の波数方向の成分は 3.0e-14 以下、div B の指標は 2.0e-18 以下である。
- ζ と η の最大値は 3.3e-14 以下、SVV の散逸は丸め誤差の床の範囲にある。
- B の誤差は dt³ に比例する（dt を半分にして 1/8）。
- 軸の入れ替えと MPI 分割による差は判定値（1e-12、1e-13）以内である。

振幅 1 は、1 周期の時点の項目が合格した。
10 周期では丸め誤差の成長が見え、N・dt・軸の入れ替えの比較が許容を超えた。
この成長は CP 波の線形不安定で説明できる（5.3 節）。
そこで振幅 1 の判定は、実行間の比較を 1 周期の時点で行い、10 周期では成長率を線形解析と照合することにした。

### 5.3 線形安定性と打ち切りによる偽の不安定

`cp_stability.py` で、波の座標系（ポンプが定常な流れ u0 = −B(φ) になる系）の Hill 行列を組んだ。
摂動 Σ_n X_n exp(i(q + n k0)·x) の Bloch の族ごとに、次の 2 つの系の最大成長率を求めた。

- 物理: 理想等温 MHD を (ρ, u, b) で線形化した系。|n − n_c| ≤ 40 で打ち切る。
- Galerkin: コードの (s, m, B) を線形化し、m と B の成分を 2/3 マスクの内側に限った系。

打ち切らなければ 2 つの系の成長率は一致する（`cp_stability.py check`）。

| k0 | N | Galerkin の最大（族の k⊥） | 同じ族の物理 | 格子上の物理の最大 |
|---|---|---|---|---|
| (1,0,1) | 16, 32, 64 | 0.132, 0.181, 0.245（6.4, 10.6, 21.9） | 0.002 以下 | 0.040 |
| (1,0,2) | 16, 32, 64 | 0.241, 0.489, 0.762（4.9, 11.2, 25.9） | 0.059, 0.001, 0.050 | 0.084 |
| (1,1,2) | 16, 32 | 0.237, 0.520（6.4, 12.9） | 0.092, 0.002 | 0.098 |

成長率の単位は ω0 = |k0| v_A である。

理想の実行の成長率は Galerkin の最大成長率と一致した（k = (1,2) の N = 16, 32, 64 で 0.23, 0.487, 0.762 に対し 0.241, 0.489, 0.762）。
最大の族は格子規模の k⊥ にあり、同じ族の物理の成長率は 0.06 を超えない。
したがって、理想の実行の成長は、m と B をマスクで打ち切ったことによる偽の不安定である。
N とともに成長率が上がるのは、打ち切りの位置が高い k⊥ に移るためである。

既定の実行では、ES-SVV が N ≥ 32 で偽の族を抑えた。
成長率は、k = (1,1) の N = 32, 64 で 0.009, 0.019（格子上の物理の最大 0.040）、k = (1,2) の N = 32 で 0.092（同 0.084）で、N = 64 では測れる成長がない。
3D の N = 32 は 0.132 で、格子上の物理の最大 0.098 の 1.35 倍である（5.4 節）。

### 5.4 η_shock の項による成長

既定の N = 16 では、SVV が偽の族を抑えた後に残る族が、その族の Galerkin の成長率より速く育った。
k = (1,2) では成長率 0.19–0.22 の族の Galerkin の成長率が 0.035–0.078、3D の k = (1,1,2) では 0.30–0.31 に対し 0.054–0.063 である。
3D の成長率は理想の実行（偽の族で 0.237）も上回る。
線形モデルに入っていない項のうち、ζ の項（q = ρ ζ D）は摂動について 2 次になる。
一方、η_shock の項 curl(η J0) は摂動の 1 次である。η は摂動の圧縮 max(0, −δD) に比例し、J0 は波の電流で O(1) だからである。
ただし η は δD の正の部分だけを拾うので、この項は線形ではない。

切り分けとして、η_shock と SVV を個別に外した実行（noeta、nosvv、etaonly、svvonly）を、2D の N = 16 と 3D の N = 16, 32 で走らせた（job 481014, `runs/stage4/cpdiag_analysis.txt`）。
次の表は、成長率を支配的な族の Galerkin の成長率で割った値である。

| 実行 | noeta | etaonly | default |
|---|---|---|---|
| 2D (1,2) N = 16 | 0.72 | 7.04 | 6.12 |
| 3D (1,1,2) N = 16 | 1.07 | 5.17 | 4.84 |
| 3D (1,1,2) N = 32 | 0.99 | 1.00 | 1.39 |

noeta と svvonly、nosvv と etaonly はそれぞれ一致した（振幅の差は相対 8.3e-4 以下）。ζ の項は成長に寄与していない。
SVV だけの実行は Galerkin の成長率で育つ。理想の実行より速い成長は、η_shock の項から来る。
3D の N = 32 の etaonly は、SVV がないので偽の族の成長率（Galerkin と同じ）で育つ。
η_shock による超過は N とともに減る（3D の default の成長率は N = 16 で 0.30、N = 32 で 0.132。支配的な族の Galerkin の成長率はそれぞれ 0.063、0.095）。

再解析（`runs/stage4/alfven_analysis.txt`）で不合格になったのは、3D k = (1,1,2)、振幅 1、N = 32 の既定の実行（1 周期 400 step、8 rank）の 1 本だけである。
支配的な族は k⊥ = 3.65 の物理の族（Galerkin 0.095、物理 0.096）で、成長率 0.132 が上限（格子上の物理の最大 0.098 の 1.25 倍）を超え、10 周期の散逸が床を超えた。
原因は上の η_shock の項で、判定は緩めていない。
滑らかな解では η_shock は丸め誤差の水準でしか立たないが、η ≥ 0 の整流があるため、curl(η J0) は摂動に対して 1 次の源になる。

### 5.5 既存の不具合

out3d の記録 r は、ファイルの 2r 記録目の位置から書かれ、あいだは 0 で埋まる。
`src/mpiio_write_var.F90` が、ファイルの位置に配列の大きさとバイト数の積を足した後、複素数ならさらに同じ量を足すためである（バイト数は複素数の 16 で既に 2 倍になっている）。
全モデルに共通のコードなので Fortran は直さず、読み出し側（`gen_ic._read_out3d_k`）で補正した。

## 6. S4.2 斜めの平面問題

### 6.1 写像と 3 種の試験

Stage 3 の 1D の分布 F（N 点、周期 L）を、x-z 格子の点 (i, l) に p(i, l) = mod(a i + b l, N) で写した。
法線は n = (a, 0, b)/|k| で、u と B の成分は n, t1 = (b, 0, −a)/|k|, y に置く。
スキームのどの演算子も格子の平行移動 (i, l) → (i + 1, l), (i, l + 1) と可換で、その移動は p を a, b ずらす。
そのため、状態は発展しても p だけの関数のままである。
L² の箱の上では、これは 1D の問題を 1/|k| に縮めたもの（n 方向の周期 L/|k|）になり、実行の長さも t_end/|k| にした。

問題は Stage 3 の F1（fast 衝撃波）、C2（B_t が反転する複合問題）、TDS_w1（静止した接線不連続、幅 1 格子）、RDh_w4（Δψ = π/2 の回転不連続、幅 4 格子）、RDpc（鋭い 180° の共面回転不連続）で、F1 と C2 は C_eta = 0 と 2 の両方を走らせた。
試験は次の 3 種である。

- 対照（ctl）: k = (1,0) の 2D の実行を、同じ dt の 1D の実行と比べる。1e-11 以内で一致すれば合格とする。
- 演算子の等価性（eqv）: k = (1,1)、SVV なし、200 step の 2D の実行を、縮めた 1D の実行（shock_nmax = shock_nsmooth = 2、shock_dl = L/N）と比べる。1e-10 以内で一致すれば合格とする。
  既定（shock_nmax = shock_nsmooth = 1）の get_zeta は、全方向の max のパスを済ませてから平滑化のパスをかける。
  p の上では x と z のパスがどちらも同じ 3 点の演算（p ± 1 の max、[1, 2, 1]/4 の平滑化）になるので、2D の 1 回は 1D で 2 回かけたもの（p ± 2 の max、[1, 4, 6, 4, 1]/16）と等しい。
  SVV の ε_d は方向ごとに決まるので、この等価には含めていない。
- 物理（phy）: 既定の設定で k = (1,1), (1,2)、N = 256, 512 を走らせ、2D の実行の L1 誤差を同じ N の Stage 3 の 1D の実行と比べる。並進対称性の破れは 1e-12 以下、恒等式の残差 R_ζ, R_svv/A_svv, R_η は 1e-10 以下を条件とした。

### 6.2 k = (1,2) の帯域

分布の Fourier mode m は x-z 格子の (a m, b m) に乗る。
2/3 マスクは |a m|, |b m| < N/3 を残すので、残る mode は |m| < N/(3 max(|a|, |b|)) である。
k = (1,1) では縮めた 1D の実行と同じ帯域だが、k = (1,2) では半分になる。
そこで k = (1,2) の参照として、同じ分布を N/2 点に取り、幅を格子数で半分にした 1D の実行（`_1dh`、Δ = L/N）を加えた。
帯域と Δ がどちらも 2D の実行に揃う。

### 6.3 結果

N = 256（46 ケース）と N = 512（42 ケース）のすべてが条件を満たした（`runs/stage4/planar_analysis3.txt`）。

| 項目 | 条件 | 最大値 |
|---|---|---|
| ctl: 2D と 1D の差 | 1e-11 | 2.4e-14（TDS_w1） |
| eqv: 2D と 1D の差 | 1e-10 | 4.9e-15（F1） |
| 並進対称性の破れ（N = 256 / 512） | 1e-12 | 1.9e-14 / 3.4e-14（C2_eta2, k = (1,1)） |
| R_ζ, R_svv/A_svv, R_η（2D、N = 256 / 512） | 1e-10 | 5.4e-12 / 7.5e-13（RDh_w4, k = (1,1)） |
| B_n の変化（2D） | — | 1.9e-15 |

当初、RD と TD の ζ, D, η の差と並進対称性の破れが O(1) に見えた。
相対差の分母に使った max|ζ| などが丸め誤差の水準だったためで、分母に丸め誤差の尺度を入れて直した（D は U/Δ、ζ と η は U Δ、U = max(|u| + c_f)）。
u の丸め誤差は max|u| ではなく力の大きさ（fast 速度）で決まる（TDS では u は 1e-3 の程度しかない）。

L1 誤差の比は、2D の実行と、帯域と Δ を揃えた 1D の参照（k = (1,1) は圧縮 1D、k = (1,2) は `_1dh`）の比である。
C2 の L1 は Stage 3 の FV 参照解との距離、そのほかは厳密解との距離で、6 変数の和をとった。

| 問題 | k = (1,1), N = 256 / 512 | k = (1,2), N = 256 / 512 | k = (1,2) の圧縮 1D との比 |
|---|---|---|---|
| F1 | 1.03 / 1.03 | 1.02 / 0.96 | 1.24 / 1.30 |
| F1_eta2 | 1.05 / 1.05 | 1.03 / 1.02 | 1.12 / 1.13 |
| C2 | 1.03 / 1.04 | 1.06 / 0.97 | 1.37 / 1.37 |
| C2_eta2 | 1.14 / 1.16 | 1.11 / 1.05 | 1.36 / 1.45 |
| RDh_w4 | 1.06 / 1.00 | 1.06 / 1.03 | 37 / 35 |
| RDpc | 1.02 / 1.02 | 1.00 / 1.00 | 1.50 / 1.50 |
| TDS_w1 | 1.03 / 1.03 | 1.07 / 1.08 | 2.53 / 2.55 |

参照を `_1dh` にすると、k = (1,2) の比は 0.96–1.11 になり、k = (1,1) と同じ程度になった。
圧縮 1D との比が大きい（RDh_w4 で 37）のは、6.2 節の帯域の違いのためである。
初期値を 2D と同じ帯域で切り捨てただけで、RDh_w4 の L1 は 7.9e-6 から 2.1e-3 に、TDS_w1 は 5.8 倍になる（N = 256）。
C2_eta2 の k = (1,1) は 1.14–1.16 で、C_eta = 0 の 1.03–1.04 より大きい。
6.1 節の等価性から、2D の ζ は p の上で 2 回のパスをかけた 1D の ζ と等しく、既定の 1D（1 回）より広い。
η_shock は B_t の反転を ζ の幅に広げるので、その差が C_eta = 2 でだけ目立つと考えているが、確かめてはいない。

TDS_w1 の max|u_n| の参照との比は 0.91–1.19 で、条件の 1.5 以下である。
RDpc の |ΔM/M| は 2D で 8.7e-8–2.3e-6、Stage 3 の 1D で 1.5e-5–1.6e-5 で、条件の 2e-5 以下である。
どちらも N = 256 → 512 で減らない。
この質量の誤差は時間積分の誤差（Stage 3 の 7.1 節。dt を半分にすると約 1/8 になる）で、N によらない理由は多次元でも調べていない。
RDpc の速度の誤差は 2D で −0.013 から −0.015、Stage 3 の 1D で −0.017 である。

### 6.4 多次元での η_shock

F1 と C2 で C_eta = 0 と 2 を比べた（左が C_eta = 0）。
2D の欄は k = (1,1) で、参照の欄は帯域と Δ を揃えた圧縮 1D である。
1D の欄は Stage 3 の実行（Δ が 1D の格子間隔そのもの）である。

| 量 | 2D, N = 256 | 2D, N = 512 | 圧縮 1D, N = 512 | Stage 3 の 1D, N = 512 |
|---|---|---|---|---|
| F1 の B_t1 の overshoot/跳び | 3.8e-3 → 1.4e-3 | 4.0e-3 → 1.3e-3 | 5.4e-3 → 1.2e-3 | 2.1e-2 → 3.7e-3 |
| F1 の ρ の overshoot/跳び | 1.7e-2 → 3.9e-3 | 1.7e-2 → 3.8e-3 | 1.8e-2 → 2.8e-3 | 7.5e-2 → 1.4e-2 |
| F1 の L1（6 変数） | 0.0195 → 0.0247 | 0.0098 → 0.0124 | 0.0095 → 0.0117 | 0.0094 → 0.0093 |
| C2 の FV 参照解との距離（6 変数） | 0.086 → 0.118 | 0.048 → 0.066 | 0.045 → 0.057 | 0.045 → 0.052 |

k = (1,2) も同じ傾向で、N = 512 の F1 の B_t1 の overshoot は 1.1e-2 → 3.0e-3、C2 の FV 参照解との距離は 0.079 → 0.102 である。

η_shock は、fast 衝撃波の B_t1 の overshoot を 2D でも約 3 分の 1 にする。
一方で、F1 の L1 と C2 の FV 参照解との距離は、C_eta = 2 で 1.2–1.4 倍に増える。
同じ N の Stage 3 の 1D でも C2 の距離は 1.14–1.16 倍に増えるので、N ≤ 512 で η_shock が精度を上げないことは多次元に特有ではない。
Stage 3 で C_eta = 2 を推奨した根拠は N = 4096–8192 での FV 参照解との距離で、その範囲は多次元では試していない。
2D の増え方（1.37–1.38 倍）が圧縮 1D（1.24–1.25 倍）より大きいのは、2D の ζ が広いためと考えている（6.3 節）。

以上と 5.4 節（η_shock が CP 波の偽の成長を強める）から、C_eta の既定値は 0 のままとし、多次元では C_eta = 2 を一般には推奨しない。
B_t が反転する構造を N ≥ 2048 相当で分解する多次元の問題で、C_eta = 2 が FV 参照解との距離を縮めるかは確かめていない。

## 7. S4.3 等温 Orszag–Tang 渦

### 7.1 設定

Mignone（2007）の 5.5 節の等温 OT 渦（音速 a = 2）を、u と B を a で割り t に a を掛けて c_s = 1 に直した。
x-z 面で ρ = 1、u = (−sin z, 0, sin x)、B = B0 (−sin z, 0, sin 2x)、B0 = √(3/5)（β = 2 c_s²/⟨B²⟩ = 10/3）である。
Mignone の t = 1.5, 3 は t = 3, 6 にあたるので、t_end を計画の π から 2π に延ばした。
係数は C_shock = 2、ES-SVV（svv_eps0 = 0.5）、C_eta = 0 と 2 で、面の出力は Δt = 0.25 ごとである。

dt は N ごとに固定した。
N = 128, 256 は dt = dt_adv(t = 0)/4 で走らせ、N = 512 はその 2 本の min(dt_adv, dt_visc) から dt = 0.85 (N_src/N) × 1.05^{−log2(N/N_src)} × min dt_cfl で決めた。
分解された衝撃波では、移流・粘性・SVV のどの制約も 1/N で縮むと見込んだ。

### 7.2 停止、保存則、恒等式

N = 128, 256, 512 と C_eta = 0, 2 の 6 本は、どれも t = 2π まで停止しなかった（`runs/stage4/ot_analysis2.txt`）。

| 項目 | 6 本の最大値 |
|---|---|
| 質量の相対変化 \|ΔM/M\| | 1.4e-7 |
| 恒等式の残差 R_ζ, R_svv/A_svv, R_η | 6.1e-14 |
| div B の指標（rms と max） | 5.1e-18 |
| dt/min(dt_adv, dt_visc) | 0.74–0.95 |
| dt λ_svv | 1.15–1.44 |
| エネルギー収支の時間積分の誤差 \|∫ err dt\| | 1.5e-4（初期の E_K + E_M = 198 に対して 8e-7） |

ρ の範囲は N = 512、C_eta = 0 で 0.135–7.68 だった。
\|ΔM/M\| は N とともに少し減る（C_eta = 0 で 1.4e-7, 1.4e-7, 8.9e-8）。
6.3 節の RDpc と同じ時間積分の誤差と考えているが、OT では dt を変えて確かめていない。

### 7.3 MPI 分割

N = 256、C_eta = 2 の実行を P = 4, 64, 256 で走らせ、P = 16 と比べた（t = 1 まで 1511 step）。
P = 256 では 1 rank が x の 1 面だけを持つ。

| 4 | 8.9e-16 | 3.3e-13 | 3.6e-15 |
| 64 | 6.7e-16 | 9.0e-14 | 4.0e-15 |
| 256 | 5.6e-16 | 1.0e-13 | 5.6e-15 |

10 step 後の差は条件の 1e-12 を下回った。
面の差は t = 0.25 の 1.1e-15–1.2e-15 から t = 1 の 3.6e-15–5.6e-15 に増えるだけで、衝撃波ができた後も分割による差は丸め誤差の水準にとどまる。
conservation.dat の差は、各列の最大の絶対値に対する相対差である。

### 7.4 散逸の内訳と η_shock

散逸率 ε(t) = −dE/dt は t ≈ 1.68 で最大になる（図 `fig/stage4_ot_eps.png`）。
最大値は C_eta = 0 で 25.6, 25.4, 25.1（N = 128, 256, 512）、C_eta = 2 で 30.4, 27.9, 26.3 だった。
C_eta = 2 の最大値は N とともに C_eta = 0 の値に近づくが、N = 512 でもまだ 5% 大きい。

t = 0 から 2π までの散逸に占める割合は次のとおりである（N = 512）。

| C_eta | 衝撃波粘性 ε_shock | SVV（u） | SVV（B） | η_shock |
|---|---|---|---|---|
| 0 | 0.732 | 0.207 | 0.061 | — |
| 2 | 0.521 | 0.034 | 0.007 | 0.437 |

C_eta = 0 では散逸の 7 割を衝撃波粘性が担い、SVV は 27% である。
C_eta = 2 では η_shock が 44% を担い、SVV は u と B を合わせて 4% に減る。
t = π の E_M は、C_eta = 0 で 91.91, 92.77, 93.30（N = 128, 256, 512）、C_eta = 2 で 84.19, 89.39, 91.73 である。
C_eta = 2 の E_M は C_eta = 0 より小さく、その差は 7.7, 3.4, 1.6 と N を倍にするごとにほぼ半分になる。
η_shock による B の余分な散逸は一次で減る。

### 7.5 解像度による収束

判定は上位 2 解像度（N = 256 と 512）の比較で、条件は 5 節の計画のとおりである。

| 項目 | 条件 | C_eta = 0 | C_eta = 2 |
|---|---|---|---|
| ε の最大値の差 | 5% | 1.5%（合格） | 6.1%（不合格） |
| 最大の時刻の差 | 2% | 0.04%（合格） | 0.28%（合格） |
| ε_shock の割合の差 | 10% | 1.9%（合格） | 9.2%（合格） |
| t = 2π の ρ_min, ρ_max, E_K, E_M の差 | 2% | 82%, 25%, 3.1%, 0.5%（不合格） | 47%, 42%, 2.7%, 5.6%（不合格） |

t_end を計画の π にしていれば、状態の差は C_eta = 0 で 2.4%, 0.1%, 0.3%, 0.6%（ρ_min だけ条件を超える）、C_eta = 2 で 3.1%, 2.7%, 2.6%, 2.5% だった。
C_eta = 0 の ρ_min の差は、t = 4 で 6.9%、t = 5 で 21%、t = 6 で 37% と、t ≈ 4 から増える。
この原因は 7.6 節で調べる。

有効帯域 k_eff は、E_tot(k) の比 \|E_N/E_2N − 1\| が 1 から k まで 0.25 以下にとどまる最大の k である。
閾値 0.25 はこの報告で決めた値で、文献の基準とは照合していない。
k_eff(256–512)/k_eff(128–256) の比は次のとおりである。

| t | 1 | 2 | 3 | 4 | 5 | 6 | 2π |
|---|---|---|---|---|---|---|---|
| C_eta = 0 | 1.57 | 1.82 | 2.15 | 1.93 | 2.52 | 1.0 | 1.0 |
| C_eta = 2 | 1.82 | 1.82 | 1.80 | 2.0 | 4.25 | 4.5 | 7.0 |

C_eta = 0 の t = 2–4 と C_eta = 2 の t = 1–4 は条件の [1.7, 2.3] に入り、帯域は N に比例して広がる。
C_eta = 0 の t ≥ 6 では k_eff が 9–11 で止まり、N を倍にしても広がらない。
C_eta = 2 の t ≥ 5 の大きな比は、N = 128 と 256 の比較で k_eff が 2–4 まで落ちたためである。

ζ > 0.01 ζ_max の面積比は、N を倍にしても 0.6–0.9 倍にしかならない。
滑らかな圧縮でも ζ/ζ_max は w Δ \|∇u\|/δu の程度で、N ≈ 2000 まで 0.01 を超えるためである。
そこで判定には a90（ρ ζ D² の 90% を占める最小の面積比）を使った。
衝撃波の帯は幅が Δ に比例し、その散逸は Δ によらないので、衝撃波が散逸を担えば a90 ∝ Δ で、比 a90(2N)/a90(N) は 0.5 になる。
滑らかな圧縮の散逸は Δ² に比例して減るので、その寄与が残る低い N では a90 が広がり、比は 0.5 を下回りうる。

| t | 1 | 2 | 3 | 4 | 5 | 6 | 2π |
|---|---|---|---|---|---|---|---|
| C_eta = 0, 128–256 | 0.31 | 0.52 | 0.52 | 0.50 | 0.63 | 0.64 | 0.63 |
| C_eta = 0, 256–512 | 0.395 | 0.539 | 0.512 | 0.535 | 0.587 | 0.650 | 0.599 |
| C_eta = 2, 256–512 | 0.330 | 0.521 | 0.544 | 0.531 | 0.580 | 0.571 | 0.526 |

t ≥ 2 は条件の [0.4, 0.65] に入る。
t = 1 は範囲外で、比は N = 128–256 の 0.31 から 256–512 の 0.395 に上がり、0.5 に近づいている。
ζ_max(2N)/ζ_max(N) は t = 0.5 で 0.27、t ≥ 1 で 0.5 なので、衝撃波は t = 0.5 から 1 のあいだにでき始める。
t = 1 は、できかけの弱い衝撃波と、面積が O(1) で散逸が Δ² に比例する滑らかな圧縮が並ぶ前漸近の領域と考えている。
判定の範囲は変えずに不合格として扱い、N = 1024 で比が 0.4–0.5 に入るかを確かめる（7.7 節）。

ζ の分布（図 `fig/stage4_ot_zeta.png`、t = 3、C_eta = 2）では、ζ の強い帯は衝撃波の線に沿い、N = 256 から 512 で細くなる。
滑らかな圧縮の領域にも、ζ_max の 1e-2 を超える ζ が広く分布する（ζ > 0.01 ζ_max の面積比は N = 512 で 0.32）。

### 7.6 後半の非収束の原因

ρ_max は t = 3 では収束している（N = 128, 256, 512 で 3.41, 3.40, 3.38）が、t = 5 では 2.82, 5.51, 7.16 と N とともに増える。
図 `fig/stage4_ot_late_J.png` は、C_eta = 0 の J_y = ∂_z B_x − ∂_x B_z を t = 3, 5, 6 で並べたものである。
t = 3 の電流層の形は 3 つの N で揃っている。
t = 5–6 には、N = 256, 512 で中央の電流層に磁気島ができ、斜めの電流層にはプラズモイドの列が並ぶ。
N = 128 にはどちらもない。
max\|J\| は N にほぼ比例し（t = 3 で 21.7, 48, 97、t = 5 で 24, 62, 143）、電流層の幅は格子幅のままである。

格子の散逸しかない OT では、電流層の Lundquist 数に相当する量が N とともに増える。
そのため N ≥ 256 では後半にプラズモイド不安定性が起き、磁気島の位置と数が N ごとに違うと考えている。
t ≥ 4 の各点の量（ρ_min, ρ_max）が収束しないのはこのためと判断した。
スキームの不安定を疑わないのは、恒等式の残差（7.2 節）、div B、dt の余裕がどれも後半でも保たれ、t = 2π の E_K と E_M の差も 0.5–5.6% にとどまるためである。
物理の抵抗率を与えれば後半も収束すると見込まれるが、物理散逸のない計算という今回の設定から外れるので試していない。

### 7.7 N = 1024

N = 1024、C_eta = 0 は、1 ノードの 256 rank で t = π（25146 step）まで走らせる。
dt は、50292 step で t = 2π に達する値（7.1 節の式）のままである。
最初は 2 ノードの 512 rank で t = 2π まで走らせたが、1 step に 1.9 s かかったので打ち切った（9 章）。
256 rank では 1 step が 0.136 s なので、t = π までは約 57 分、30 分のジョブ 3 本になる。
終端を π にしたのは、計画の t_end が π で、ε の山（t = 1.68）を含み、t ≥ 4 では N = 512 までで各点の収束が見込めない（7.6 節）ためである。
N = 512 と 1024 の比較は両者に共通の終端 t = π で行い、散逸の割合も [0, π] の積分で比べる。
C_eta = 2 は費用のため走らせない（C_eta の既定値は 0、6.4 節）。

N = 1024 は t = π まで停止しなかった（ジョブ 4 本の連鎖）。
\|ΔM/M\| は 3.6e-8、恒等式の残差は 1.3e-13、div B の指標は 1.1e-18、dt/min(dt_adv, dt_visc) の最大は 0.66、dt λ_svv の最大は 0.95 である。
N = 512 との差は次のとおりである（判定の時刻は両者に共通の t = π、差は N = 1024 の値に対する相対差）。

| 項目 | 条件 | 512–1024 |
|---|---|---|
| ε の最大値の差 | 5% | 0.78%（25.07 と 24.88、合格） |
| 最大の時刻の差 | 2% | 0.05%（合格） |
| [0, π] の散逸に占める ε_shock の割合の差 | 10% | 0.45%（0.926 と 0.930、合格） |
| t = π の ρ_min, ρ_max, E_K, E_M の差 | 2% | 9.5%, 0.07%, 0.007%, 0.27%（ρ_min で不合格） |
| k_eff の比（t = 1, 2, 3） | [1.7, 2.3] | 1.55, 1.88, 2.02（t = 1 で不合格） |
| a90 の比（t = 1, 2, 3） | [0.4, 0.65] | 0.465, 0.539, 0.502（合格） |

散逸の量は N = 1024 で収束した。
ε の最大値は N = 128–1024 で 25.6, 25.4, 25.1, 24.9 で、隣り合う N の差は 0.7%, 1.5%, 0.8% と、どれも 5% より小さい。
t = π の E_M は 91.91, 92.77, 93.31, 93.56 で、N を倍にするごとの増分は 0.86, 0.53, 0.25 とほぼ半分ずつ減る。
[0, π] の散逸に占める ε_shock の割合は 0.875, 0.913, 0.926, 0.930 である。
残りはほぼ SVV で、[0, π] では N = 512 で約 7.4%、N = 1024 で 7.0%（u と B の和）である。
[0, 2π] の N = 512 の 27%（7.4 節）より小さいので、SVV の散逸の多くは t > π にある。

7.5 節の予測どおり、t = 1 の a90 の比は 0.31, 0.395, 0.465（N = 128–256, 256–512, 512–1024）と上がって 0.4–0.65 に入った。
t = 1 は衝撃波ができかけの前漸近の領域で、N を上げると a90 ∝ Δ の振る舞いに近づくという 7.5 節の見方と合う。

不合格の 2 項目のうち、ρ_min の差は解の局所的な構造から来ている。
t = π の ρ_min は N = 128–1024 で 0.361, 0.341, 0.349, 0.319 と単調でない。
N = 1024 の最小の点は (x, z) = (3.283, 3.209) で、中央の電流層の中の幅の狭い構造にある（図 `fig/stage4_ot_late_J.png` の N = 1024、t = π）。
max\|J\| は t = 3 で 97（N = 512）と 215（N = 1024）で、電流層の幅は N = 1024 でも格子幅のままである。
7.6 節で t ≥ 4 に見た非収束と同じく、格子の散逸しかない電流層の中の各点の値は N によって変わると考えている。
ρ_max, E_K, E_M の差は 0.3% 以下である。

もう 1 つの t = 1 の k_eff は、N を倍にするごとに 21, 33, 51 と 1.55–1.57 倍にしかならず、N^0.64 で増える。
N = 512 のスペクトルが N = 1024 から離れる k = 51 は、N = 512 の SVV のかかり始める波数 m_N = k_c/2 = 85 より小さい（図 `fig/stage4_ot_spec.png`）。
m_N は N に比例するので、この遅い伸びは SVV の帯域では説明できない。
t = 2, 3 の比は 1.88, 2.02 で範囲に入るので、衝撃波ができかけの時刻に限った振る舞いである。
原因は調べていない（11.2 節）。

7.5 節と合わせて、S4.3 は不合格とする。
不合格の項目は、N = 512–1024 の t = π の ρ_min と t = 1 の k_eff、C_eta = 2 の N = 256–512 の ε の最大値である。
停止、保存則、恒等式、MPI 分割の条件はすべて満たした。

## 8. S4.4 3D 減衰乱流

### 8.1 設定

周期箱 (2π)³ で、ρ = 1、B = B0 ẑ + δB、B0 = 1 とした。
c_s = 1 なので β0 = 2 c_s²/B0² = 2、v_A0 = c_s である。
u と δB はどちらもソレノイダルな乱数場で、スペクトルを E(k) ∝ k⁴ exp(−2k²/k_p²)（k_p = 2）とし、1 ≤ |k| ≤ 4 に限った。
乱数は numpy の `default_rng`（seed 20261103）で 16³ の格子の上に引き、その Fourier 係数をどの N の格子にも同じ波数で埋め込んだ。
これで初期値は N にも MPI 分割にもよらない。
u と δB の振幅から、次の 3 つの問題を作った。

| 名前 | M_s = rms\|u\| | rms\|δB\|/B0 | E_M/E_K（δB） | ⟨p_B⟩/p_th | max p_B/p_th | σ_c | H_m |
|---|---|---|---|---|---|---|---|
| `turb1` | 1 | 1 | 1 | 1.0 | 4.3 | −0.063 | −0.025 |
| `turb4` | 4 | 4 | 1 | 8.5 | 42 | −0.063 | −0.40 |
| `turb4b` | 4 | 1 | 1/16 | 1.0 | 4.3 | −0.030 | −0.025 |

p_B = B²/2 は B0 を含み、p_th = ρ c_s² = 1 である。
σ_c = 2⟨u·δB⟩/⟨u² + δB²⟩ は交差ヘリシティ、H_m = ⟨A·δB⟩ は磁気ヘリシティで、値は 64³ の格子で求めた。
`turb1` と `turb4` は計画どおり E_M = E_K とした。
`turb4` では平均の磁気圧が気体圧の 8.5 倍になり、64³ の実行は ρ の 1 格子点の穴で dt が縮み続けて止まった（8.3 節）。
そこで M_s = 4 は、u を `turb4` と、δB を `turb1` と同じ場にした `turb4b` に替えた（2026-11-03、ユーザーと決めた）。
`turb4b` の磁場は `turb1` と同じなので、M_s = 1 と 4 の違いは u の振幅だけになる。

時間の単位は τ0 = π/M_s で、t_end = 3τ0 とした。
係数は OT の結論（6.4 節、7.4 節）に合わせて C_shock = 2、C_eta = 0、ES-SVV（svv_eps0 = 0.5）で、収支は毎 step 計算する。
出力の間隔は、面（y0 と z0）が τ0/8、out3d が τ0/2 である。
y0 面は B0 を含み、z0 面は B0 に垂直である。

64³ の最初の dt は、較正の実行（4.3 節、t = 0 から 100 step）の min(dt_adv, dt_visc) の 0.5 倍とし、cfl.dat を毎 step 書く。
M_s = 1 では dt = 1.32e-3（7134 step）、M_s = 4 では dt = 6.91e-5（34080 step）である。
M_s = 4 の dt は、移流でなく SVV の安定条件が決める（4.3 節）。
`turb4b` の u は `turb4` と同じで磁場は弱いので、`turb4b` の最初の dt も 6.91e-5 とした。
128³ の `turb1` の最初の dt は、64³ の実行の全時間の min dt_cfl から OT と同じ式（7.1 節）で決めた（dt = 5.48e-4、128 rank）。

最初は dt を固定し、reset_method = 'stop' とした。
`turb1_N64` はこの方式で t_end まで走ったが、`turb4_N64` と `turb1_N128` は dt_cfl が dt を下回って止まった（8.3 節）。
そこで両方を同じ初期状態と最初の dt で、reset_method = 'decrement' として走らせ直した（`turb4_N64_a`、`turb1_N128_a`）。
`turb4b_N64` は最初からこの方式で走らせた。
'decrement' は、dt_cfl が dt を下回るたびに dt の最上位の桁を 1 下げ（5.48e-4 → 4.48e-4、仮数が 1.x なら 0.9 × 10^d）、dt を上げることはない。
30 分のジョブの間は t_end を目標に restart で連鎖させる（3.3 節）。
M_s = 4 の 128³ は、`turb4b_N64` に穴ができず、費用が A_dev の 3 本程度に収まるときだけ走らせることにしていた（穴ができたので走らせていない、8.3 節）。

MPI 分割の試験は `turb4` の 64³ で行う（止まる t = 0.10 より前の 1000 step までを比べるので、8.3 節の問題の影響は受けない）。
P = 1, 8, 64 で 10 step 走らせて面を比べ、P = 1, 8 で 1000 step 走らせて conservation.dat の毎 step の値を P = 64 の本番の実行と比べる。

### 8.2 評価

out3d の各記録から、殻で和をとったスペクトルを求める。
対象は E_u、E_√ρu、E_B、E_u のうち圧縮成分の割合 χ(k)、δρ と ln ρ のパワー、Elsässer 変数 u ± B/√ρ のエネルギーである。
有効帯域 k_eff、ζ > 0.01 ζ_max の体積比、a90 は OT（7.5 節）と同じ定義で、面 y0 と z0 のそれぞれで求める。
s = ln ρ にはマスクをかけないので、s の分散のうち 2/3 マスクの外にある割合 s_out を、s のエイリアシングの指標として記録する。
M_s = 4 では、ρ_min、s_out、dt λ_svv の時間変化を見る。

### 8.3 固定 dt での停止と M_s = 4 の密度の穴

固定 dt（6.91e-5）の M_s = 4 の 64³ は、t = 0.1016（1471 step）で CFL の条件を超えて止まった（reset_method = 'stop'）。
この間に cfl.dat では、max(|u| + c_f) が 14.5 から 20.4（1.41 倍）に、ε_d が 0.62–0.71 から 0.87–1.00 に、F_svv が 7.02 から 9.73 に増えた。
λ_svv は 1.45e4 から 2.76e4（1.91 倍）に増え、ρ_min は 1 から 0.084 に下がった。
dt を決めていたのは粘性の条件 dt_visc で、その大半は SVV の cfl_svv/λ_svv である（止まった時点で 7.2e-5、ζ を含めた dt_visc は 6.94e-5）。
dt_visc と移流の dt の比は、t = 0 の 0.115 から 0.080 に下がった。
ε_d は速い波の速さに比例し、F_svv もその速さとともに増えるので、λ_svv はおよそ cmax² に比例する（1.41² = 1.99 に対し 1.91 倍）。
そのため cmax が 1.4 倍になっただけで dt_visc が約半分になり、較正の 0.5 倍とした余裕を使い切った。

止まるまでの実行には、不安定を示すものはない。
質量の変化は 2.1e-10、恒等式の残差は 1.9e-14、div B の指標は 4.8e-18 で、非有限値もない。
dt λ_svv の最大は 1.91 で、ES-SVV の安定の上限 2.51 の内側にある。
この停止は SVV の安定条件が正しく縮んだ結果と判断し、粘性は増やさずに dt を下げて走らせ直した。
走らせ直した実行（`turb4_N64_a`）は、初期値、最初の dt、rank 数が同じで、reset_method = 'decrement' として t_end = 3τ0 まで連鎖させる（3.3 節）。

しかし `turb4_N64_a` でも dt は下がり続けた。
dt は t = 0.1034 で 4.9e-5、0.1201 で 5.0e-6、0.1250 で 9.0e-7、0.1267 で 4.0e-8 になった。
t = 0.1273 で dt が 1e-8 になったところで止めた。41649 step を使って、t_end = 2.36 の 5.4% しか進んでいなかった。
この間に ρ_min は 0.067（t = 0.110）から 5.8e-3（0.120）、3.4e-4（0.1273）へ下がった。
F_svv は 10.6 から 1939 に、max(|u_d| + c_f,d) は 345 に、λ_svv は 1.0e8 に増え、dt_visc は dt_adv の 1/2400 になった。
全エネルギーは 3844.8 から 3637.4 に減り、div B の指標は 3.0e-18 で、非有限値は出ていない。
dt λ_svv の最大は 2.00 で上限 2.51 の内側にあり、計算が発散したのではなく、安定条件を守るために dt が縮んでいる。

最後の restart（t = 0.12725）を読んで、ρ の最小の点のまわりを調べた（`void_probe.py`）。
ρ_min = 3.37e-4 は格子 1 点だけの値で、隣の点の ρ は x 方向に 0.617 と 2.17、y 方向に 0.144 と 0.058、z 方向に 0.140 と 0.056 である。
ρ < 0.01 の点の質量は全体の 9.4e-8 にすぎない。
|B| は穴の前後でなめらかで（x 方向に 6.06、6.29、4.83）、穴の点の β は 1.7e-5、v_A は 343 である。
箱全体の max_d(|u_d| + c_f,d) はこの点にあり、値 345 は cfl.dat と一致する。
穴の点の |u| は 3.03 なので、速い波の速さは穴の中の v_A で決まっている。
m と B の 2/3 マスクの外のパワーは 0 で、s ではマスクの外が分散の 7.4e-3 を占める。

穴が深まり dt が縮む機構を、次のように推定する。
Formulation C の質量の式は ds/dt = −(div_N m)/ρ で、m は 2/3 マスクで帯域が限られる。
そのため m は 1 格子点の穴の形に追従できず、穴の点の dρ/dt = ρ ds/dt = −div_N m は ρ → 0 でも O(1) のまま残る。
実際、ρ_min は t = 0.12688 の 4.79e-4 から 0.12725 の 3.37e-4 へ、ほぼ一定の dρ/dt ≈ −0.38 で減っていた。
この減り方が続けば、ρ_min は約 9e-4 後に 0 になる（s = ln ρ は −∞ になる）。
一方、ρ で重みをつけた SVV（du/dt ~ ρ⁻¹ A*(ε ρ A u)）の剛性 F_svv は、ρ_min が 1e-3 を下回ってから F_svv ρ_min ≈ 0.65 とほぼ 1/ρ_min に比例して増えた。
ε_d は箱全体の max(|u_d| + c_f,d) で決まるので、穴の点の v_A ∝ ρ_min^(−1/2) が全体の ε_d を決める。
両方を合わせると λ_svv ∝ ε_d F_svv ∝ ρ_min^(−3/2) で、ρ_min が有限時間で 0 に近づくと dt_visc も 0 に近づく。
このため、`turb4` は A_dev の範囲では t_end に届かない。
この時点では、きっかけを磁気圧が支配的な初期値（平均の β_eff = 0.12）と考えた。
磁気圧が気体を押し出して低密度の領域を作り、それが格子 1 点まで細くなったという見方である。
密度の床や一様な粘性の追加はせず、M_s = 4 は δB を弱めた `turb4b`（8.1 節）に替えた。

しかし `turb4b_N64` にも穴ができ、磁気圧が支配的な初期値がきっかけという見方は成り立たなくなった。
dt は t = 0.138 まで最初の 6.91e-5 のままだったが、その後 0.162 で 1.9e-5、0.175 で 1e-6、0.1834 で 2e-8 に下がった。
2 本のジョブで 50732 step を使い、t_end = 2.36 の 7.8% まで進んだところで続けるのをやめた。
ρ_min は 0.315（t = 0.110）、0.080（0.138）、6.8e-3（0.162）、1.0e-3（0.174）と下がった。
t = 0.178 から 0.180 の間は 7.9e-4 前後にとどまったが、その後また下がり、0.1834 で 1.2e-4 になった。
この間に F_svv は 7.0 から 3015 に、max(|u_d| + c_f,d) は 10 から 150 に、λ_svv は 1.0e4 から 6.8e7 に増え、dt_visc は dt_adv の 1/3700 になった。
F_svv ρ_min は、ρ_min がとどまった間に 0.23 から 0.35 に増え、その後は 0.35–0.37 でほぼ一定である（`turb4` では 0.65）。
dt λ_svv の最大は 2.00 で、全エネルギーは 1984.4 から 1876.5 に減り、div B の指標は 4.2e-18 以下で、非有限値は出ていない。

最後の restart（t = 0.18347）を `void_probe.py` で調べると、穴の形は `turb4` と違った。
ρ_min = 1.18e-4 の点の隣は、x 方向が 3.4e-4 と 3.3e-2、y 方向が 4.1e-4 と 2.2e-2 で、ρ < 0.01 の点が x と y にそれぞれ 3 点続く。
これに対し z 方向（B0 の方向）の隣は 0.33 と 0.66 で、穴は B0 の方向に 1 格子点の厚さしかない。
穴の点の |B| は 1.59、|u| は 6.25、β は 9.3e-5 で、v_A = 147 が箱全体の max(|u_d| + c_f,d) = 152 を決めている。
ρ < 0.01 の点は 18 点で、質量は全体の 2.8e-7 である。

M_s = 4 の流れでは、物理の解でも密度は大きく下がりうる。
対称な等温の Riemann 問題で両側の気体が速さ U で離れると、中央の密度は ρ0 exp(−U/c_s) になり、ρ = 1.2e-4 は U ≈ 9 c_s に当たる。
B0 に沿った流れは磁場に妨げられないので、この種の希薄化は B0 の方向に起こりやすい。
ただし物理の希薄波は時間とともに広がるので、B0 の方向に 1 格子点の厚さのまま深まり続ける極小は、その形と合わない。
深まり方と dt の縮み方は、上に推定した `turb4` の機構（帯域の限られた m、箱全体で決まる ε_d、F_svv ∝ 1/ρ_min）で説明できる。
M_s = 4 では δB の強さによらず穴ができるので、この機構を直さない限り、M_s = 4 の乱流は t_end に届かない。
取り決め（`turb4b_N64` に穴ができなければ 128³ に進む）により、M_s = 4 の 128³ は走らせていない。
`turb4_N64_a` と `turb4b_N64` は判定では不合格のまま残し、手法の限界の例として 11 章に挙げる。

128³ の `turb1_N128`（固定 dt 5.48e-4）も t = 2.22（step 4057）で止まったが、原因は穴ではない（ρ_min は 0.104、F_svv は 1.42）。
max(|u_d| + c_f,d) が t = 0.2 の 4.4 から 2.2 の 6.8 へゆるやかに増え、dt_visc が t = 2.2 の 5.73e-4 から下がって dt を下回った。
64³ の dt_visc に対する 128³ の dt_visc の比は、t = 0.2 で 1/1.80、1.0 で 1/2.33、2.2 で 1/2.58 と、時間とともに小さくなった。
7.1 節の式はこの比を 1/(2 × 1.05) = 1/2.1 と見込んでいた。
SVV の dt_visc は Δ/(cmax F_svv) に比例し、細かい格子ほど小さい構造を解像して cmax と F_svv が大きくなる（t = 2.2 の cmax は 64³ で 6.05、128³ で 6.76、F_svv は 1.16 と 1.42）ので、比は 1/2 より小さくなる。
走らせ直した `turb1_N128_a` では、dt は t = 2.22 から 2.78 の間に 3 回下がって 2.48e-4 になった（dt_cfl の最小は t = 2.78 の 3.33e-4）。
その後 dt_visc は 8.8e-4 まで戻ったが、'decrement' は dt を上げないので、t = 2.78 から先は dt_cfl の約 1/3.5 の dt で走る。

[0, 3τ0] の散逸の総量は 192.0 と 189.6 で、1.3% 違う。

t ≥ τ0 では ε_shock（図の破線）は 2 つの N でほぼ重なる（t = τ0 で 8.5 と 8.3、2τ0 で 2.13 と 1.96）。
t = 0.5τ0 の ε は 64³ で 32.9、128³ で 22.7 と 10.2 違い、そのうち ε_shock の差は 1.5（13.2 と 11.7）で、残りの 8.7 はほぼ SVV（u と B）の差である。
64³ の SVV は m_N = k_c/2 = 10.7 から上にかかるので、初期値の帯域（k ≤ 4）から乱流が広がる早い時刻に、エネルギーの多い波数を直接散逸させていると考えている。

スペクトル（図 `fig/stage4_turb_spec.png`）から求めた k_eff（64³–128³）は、t/τ0 = 0.5, 1, 1.5, 2, 2.5, 3 で 15, 16, 16, 10, 8, 6 である。
t ≤ 1.5τ0 の 15–16 は、64³ の m_N = 10.7 と k_c = 21.3 の間にある。
t = 3τ0 では 64³ のスペクトルが k = 4–13 で 128³ より高く、k_eff は 6 まで下がる。
128³ の帯域を 256³ と比べていないので、k_eff の比（条件 [1.7, 2.3]）は求められない。

S4.3 の条件を 64³ と 128³ に当てると、ε の最大値の差（3.1%）は合格するが、最大の時刻の差（29%）、ε_shock の割合の差（15%）、t = 3τ0 の状態の差（ρ_min 13%、ρ_max 2.8%、E_K 1.7%、E_M 1.1%）は不合格である。
a90 の比（t ≥ τ0 で 0.75–0.96）も条件 [0.4, 0.65] の外にある。
この条件は衝撃波が ζ の散逸を担うことを前提にしており、M_s = 1 の乱流ではその前提が成り立たない（下の ζ の分布の段落）。
t = τ0 と 2τ0 の状態の差はそれぞれ ρ_min 23% と 70%、E_K 9.1% と 6.2% で、t_end の差より大きい。
64³ と 128³ はどちらもまだ解像度の影響を強く受けており、収束は示せていない。
256³ の本番は走らせていない（10.2 節）。

ζ の分布（図 `fig/stage4_turb_zeta.png` の左、z0 面、t = τ0）は、OT の衝撃波の線のような細い帯にまとまらない。
ζ > 0.01 ζ_max の面積比は、y0 面で t ≥ τ0 に 64³ で 0.99–1.00、128³ で 0.98–0.99 と、ほぼ面全体を覆う。
ρ ζ D² の 90% を占める面積比 a90 は、y0 面で 64³ が 0.33–0.36、128³ が 0.26–0.32（t ≥ τ0）で、128³/64³ の比は 0.79–0.92 である（z0 面で 0.75–0.96）。
衝撃波が散逸を担えば比は 0.5 になる（7.5 節）ので、M_s = 1 の ζ の散逸は格子幅の衝撃波ではなく、広い領域の滑らかな圧縮が担っている。
一方、領域全体の ζ_max は t = τ0 で 0.150（64³）と 0.070（128³）、t = 3τ0 で 0.053 と 0.025 で、128³/64³ の比は t/τ0 = 0.5–3 で 0.46–0.60 である。
滑らかな圧縮なら ζ ∝ Δ² で比は 0.25 に、格子幅の衝撃波なら D ∝ 1/Δ から ζ ∝ Δ で比は 0.5 になるので、ζ_max の点の圧縮は格子幅まで急峻になっている。
ζ > 0.01 ζ_max の点のうち D < 0 の点は 41–52% で、残りは ζ の max と平滑化（Stage 3）で圧縮の隣の膨張域に広がった分である。

s のマスクの外の分散 s_out は、64³ で最大 2.3e-3（t = 1.5τ0）、128³ で最大 1.3e-3 と、N を倍にしてほぼ半分になった。

MPI 分割の試験は、`turb4` の 64³ を P = 1, 8 で走らせ、P = 64 の `turb4_N64` と比べた。
10 step 後の面の差は P = 1 で 2.7e-15、P = 8 で 3.6e-15 である。
conservation.dat の各列について、最初の n step の差の最大を同じ範囲の列の最大値で割ると、n = 10, 100, 1000 で P = 1 が 6.6e-14, 9.4e-15, 6.3e-15、P = 8 が 4.8e-14, 7.1e-15, 1.6e-15 で、1000 step まで丸め誤差の水準にとどまる。

M_s = 4 の 2 本は t_end に届かず（8.3 節）、解像度の比較はしていない。
そのため S4.4 は不合格とする。
不合格の項目は、M_s = 1 の 64³–128³ の収束と、M_s = 4 の完走である。
M_s = 1 の 2 本と M_s = 4 の止まるまでの実行では、保存則、恒等式、div B、MPI 分割の条件を満たした。

## 9. S4.5 並列性能

### 9.1 測り方

本番と同じ設定（C_shock = 2、C_eta = 0、ES-SVV、収支を毎 step、FFTW_MEASURE）で、t = 0 から 10 step と 110 step の 2 本を走らせた。
1 step の費用は (T(110) − T(10))/100 とし、初期化と最初の step の時間を差で消した。
T は step 全体と各部分（div u と ζ と η、get_svv_es、svv_power、stage_budget）の、rank の最大値である。
FFT と非線形項の時間は proc0 の値しか出ないので、参考として載せる。

問題と rank 数は次のとおりである。

| 種類 | 2D（OT、x-z 面） | 3D（乱流 M_s = 4） |
|---|---|---|
| 強スケーリング | 1024² を P = 16–1024 | 256³ を P = 64–1024 |
| 弱スケーリング | 1 rank あたり 4096 点: (256², 16), (512², 64), (1024², 256), (2048², 1024) | 1 rank あたり 64³/2 点: (64³, 2), (128³, 16), (256³, 128) |

dt は OT が 0.5 dt_adv(t = 0)、乱流が較正の実行（4.3 節）の min(dt_adv, dt_visc) の 0.8 倍で、110 step のあいだ dt は変わらない。
2D と 3D でジョブを 1 本ずつ（select=4、1024 core）使い、各実行は 1 本ずつ順に走らせた。
256 rank に満たない実行でもノードを他と共有しない。
効率は、強スケーリングで T(P0) P0/(T(P) P)、弱スケーリングで T(P0)/T(P) とした。
FFT の演算量は点数 n に対して n log n で増えるので、弱スケーリングでは log2(n)/log2(n0) を掛けた値も示す。
効率は記録するだけで、合否には使わない。

FFT の中の転置と局所の変換は分けて測っていない。
弱スケーリングの効率も 1 ノードの中で下がり、2D の 256 rank で 0.40、3D の 128 rank で 0.47 である。

複数のノードにまたがると、2D と 3D で振る舞いが違う。
2D の 1024² は、2 ノード（P = 512）で 1 step が 1.85 s、4 ノード（P = 1024）で 4.3–4.9 s（推定）になり、1 ノードの P = 256 の 0.136 s の 13.6 倍と 32–36 倍だった。
2048² の 4 ノードも 9.0–10.2 s（推定）で、弱スケーリングの効率は 0.006 以下である。
3D の 256³ は、2 ノードで 0.628 s、4 ノードで 0.510 s で、1 ノードの 0.571 s とほとんど変わらない。
どちらでも proc0 の FFT の割合が 90–99% に上がるので、ノードをまたぐ転置が step の時間を決めているとみられる。

2 つの違いは、FFT の分割の違いで説明できると考えている。
2D の x-z 面は 1 次元分割（dim_decomp = 1、P3DFFT の rank の格子 1 × P）なので、1 回の転置で全 P rank が互いに送り合う。
1 組のメッセージは 1024² の 512 rank で約 64 B、1024 rank で約 16 B と小さく、ノード間の組の数は P² に比例して増える。
3D は 2 次元分割（dim_decomp = 2、1024 rank で 32 × 32）なので、1 回の転置は 32 rank の中で行われ、1 組のメッセージは約 4 KB ある。
この説明はメッセージの大きさと数からの推定で、ノード間の通信の時間は測っていない。

本番の実行で core·時間の増分を 1.4 倍以内に抑えるなら、rank 数は効率 0.7 以上の最大の値（2D の 1024² で P = 128、3D の 256³ で P = 128）になる。
今の実装では、2D の実行を複数のノードに広げると 1 ノードより遅くなる。3D でも 1 ノードを超えて rank を増やしても速くならない。

## 11. 未解決の問題

### 11.1 手法の問題

- **低密度での ES-SVV の剛性と 1 格子点の穴（8.3 節）。**
  M_s = 4 の `turb4` と `turb4b` では、ρ が格子 1 点の厚さで 0 に向かい、dt_visc がそれより速く 0 に向かった。
  δB を弱めた `turb4b` でも起きたので、磁気圧が支配的な初期値に限った問題ではない。
  推定した機構は 2 つの要素からなる。
  1 つは、m が 2/3 マスクで帯域を限られているため、穴の点の dρ/dt = −div_N m が ρ → 0 でも O(1) で残ることである。
  もう 1 つは、ε_d を箱全体の max(|u_d| + c_f,d) で決めているため、穴の中の v_A ∝ ρ_min^(−1/2) が全体の SVV の強さを決めることである。
  ρ の重みのついた SVV の剛性 F_svv ∝ 1/ρ_min と合わせると、λ_svv ∝ ρ_min^(−3/2) になる。
  この推定は cfl.dat の時系列と restart の 1 時刻から立てたもので、2 つの要素を個別に外す試験はしていない。
- **η_shock による CP 波の偽の成長（5.4 節）。**
  滑らかな解でも η ≥ 0 の整流によって curl(η J0) が摂動の 1 次の源になり、3D の N = 32 で物理の成長率の上限を超えた。
  多次元では C_eta の既定値を 0 とした。
- **SVV の費用（4.3 節）。**
  SVV が step の 41–51%、収支の計算が 17–22% を占める。
  M_s ≈ 4 では λ_svv が線形の上限 Σ_d ε_d k_d,max² の 7.0–7.9 倍で、dt を移流の 1/8.7 に縮める。
  原因はエントロピー変数のヤコビアンの |u|²/c_s² の項と推定しているが、確かめていない。

### 11.2 検証の残り

- OT の t ≥ 4 の各点の量（ρ_min、ρ_max）は N = 512 まで収束しない（7.6 節）。プラズモイド不安定性によると判断したが、物理の抵抗率を与えた比較はしていない。
- C_eta = 2 の OT の ε の最大値は、N = 256 と 512 で 6.1% 違い、条件の 5% を超えた（7.5 節）。
- B_t が反転する構造を N ≥ 2048 相当で分解する多次元の問題で C_eta = 2 が FV 参照解との距離を縮めるかは、確かめていない（6.4 節）。
- RDpc の質量の誤差が N によらない理由は、多次元でも調べていない（6.3 節）。
- OT の t = 1 の k_eff は N^0.64 でしか増えず、N = 512–1024 の比 1.55 は条件の [1.7, 2.3] に入らない（7.7 節）。N = 512 のスペクトルが N = 1024 から離れる k = 51 は、SVV のかかり始める m_N = 85 より小さいので、SVV の帯域では説明できない。原因は調べていない。
- OT の t = π の ρ_min は N = 128–1024 で単調に変わらず、N = 512–1024 で 9.5% 違う（7.7 節）。最小の点は中央の電流層の中の幅の狭い構造にある。
- `turb1` の 64³ と 128³ は、ε の最大の時刻、ε_shock の割合、t = 3τ0 の ρ_min と ρ_max で条件を満たさず、収束を示せていない（8.4 節）。256³ と比べていないので、128³ で解像できる帯域も分からない。

### 11.3 計算の運用

- **複数ノードの FFT（9.2 節）。** 2D の x-z 面は 1 次元分割なので、転置は全 rank の all-to-all になる。1024² の 1 step は、1 ノード 256 rank の 0.136 s に対して、2 ノード 512 rank で 1.85 s、4 ノード 1024 rank で 4.3–4.9 s（推定）だった。3D の 256³（2 次元分割）も、2 ノードと 4 ノードで 1 ノードの 0.571 s から 0.628 s と 0.510 s にしかならない。小さいメッセージの数が時間を決めるという推定は、通信の時間を測って確かめていない。今の実装では、2D の実行は 1 ノード（P ≤ 256）に収める。
- **PAR のピン留め。** 1 ノードを埋める実行をピン留めなしで走らせると、1 step が 0.15 s から数 s まで不規則に遅くなった。ノードを丸ごと使う実行だけピン留めするようにした（3.4 節）。ノードを分け合う実行はピン留めしていない。
- **dt の外挿。** 64³ の dt から 128³ の dt を見込む式は、`turb1` で 128³ の dt_visc を大きく見積もった（見込み 1/2.1、実際 1/2.58、8.3 節）。
- **'decrement' は dt を上げない。** `turb1_N128_a` は t = 2.78 から先、dt_cfl の約 1/3.5 の dt で走った。`src/time.F90` の `increase_dt` は、dt_cfl がその値を超えたときに dt をその値に戻す固定の値で、既定（huge）では働かない。dt_cfl に追従して dt を上げる仕組みはない。
- **out3d の書き出しの不具合（5.5 節）。** 全モデルに共通の `src/mpiio_write_var.F90` にあり、読み出し側で補正しただけで直していない。

## 13. 次の段階

次の 7 つを、優先する順に挙げる。
1 と 6、7 は離散化か全モデルに共通のファイルを変えるので、計画を立ててユーザーの確認を取ってから行う。
2 は合意した計算資源を超えるので、資源を相談してから行う。

1. **M_s = 4 の穴の機構を切り分ける（11.1 節）。**
   推定した 2 つの要素を 1 つずつ外した試験で、どちらが dt の縮みを決めるかを確かめる。
   1 つは ε_d を箱全体の max でなく局所の波速で決める変更、もう 1 つは SVV の ρ の重みを外す変更である。
   どちらも SVV の項がエネルギーを散逸する性質に関わるので、変更後も半離散の恒等式（R_svv）が成り立つ形にできるかを先に調べる。
   λ_svv が線形の上限の 7.0–7.9 倍になる原因（エントロピー変数のヤコビアンの |u|²/c_s² の項という推定）も、同じ試験で確かめる。
2. **`turb1` の 256³ を t_end まで走らせる（10.2 節）。**
   128³ との比較で、ε の最大の時刻と ε_shock の割合が収束に向かうか、128³ で解像できる帯域がどこまでかを求める。
   A_dev では約 13 時間（26 本）かかる。
3. **機構別の散逸スペクトル ε_X(k)（計画の C4）を実装する。**
   OT の t = 1 の k_eff が N^0.64 でしか増えない原因（11.2 節）と、衝撃波粘性と SVV がそれぞれどの波数で散逸するかを調べる。
4. **SVV と収支の計算の費用を減らす（4.3 節、9 章）。**
   1 ノードの実行では、step の 39–51% を SVV が、17–23% を収支の計算が占める。
   get_svv_es、svv_power、stage_budget が行う FFT を数え、同じ場の変換を共有できるかを調べる。
5. **複数ノードでの FFT の遅さの原因を調べる（9.2 節）。**
   2D の 1024² は 2 ノードで 1 ノードの 13.6 倍遅く、3D の 256³ も 1 ノードを超えて速くならない。
   転置の通信の時間と局所の変換の時間を分けて測り、メッセージの大きさと数で説明できるかを確かめる。
6. **out3d の書き出しの不具合を直す（5.5 節）。**
   全モデルに共通の `src/mpiio_write_var.F90` にあるので、ほかのモデルの出力と既存のデータの読み出しへの影響を調べてから直す。
7. **'decrement' のもとで dt を上げる仕組みを足す（11.3 節）。**
   全モデルに共通の `src/time.F90` の変更になる。乱流のように dt_cfl が時間とともに大きく変わる実行で、step 数を減らせる。
