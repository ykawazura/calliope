## 1. 結論

- **P、D1–D4、O1–O4 は合格した。** FFT の計画を ESTIMATE に固定したペアでは、旧（s3g、s4）と新（s13d）の出力が 52 組（P の 14 組と D5 の原因を調べた 38 組）すべてでバイト単位で一致した。旧と同じ MEASURE で走らせた本番では、1D の解の旧との差が 1.03e-12 以下（D3）、OT の t ≤ π の新旧の相対差が conservation.dat と面で 1.1e-12 以下（O4）だった。OT の収束の判定は、新旧で同じ項目が不合格になった（O3）。
- **D5（182 本の記録の比較）は不合格だった。** 57 本で、基準を外れる項目があった。原因を調べたが、コードの違いによる差は見つからなかった。差は、実行の継ぎ目で書く行の違い、再開ごとにやり直す λ_svv の冪乗法、FFT の計画の違いから生じた。外れたのは、分子が丸め誤差で決まる比と、λ_svv とそれから求める量だけである。D5 の許容差を、計画だけが違う実行の差から決めていなかったことが誤りだった（5.2 節）。
- したがって、1D の収束の試験（conv）を除き、Stage 3 と Stage 4 で確かめた性質は s13d でも成り立つ。

この結論には次の限定がある（8 章）。
MEASURE の再実行は旧とビット単位では一致しないので、コードが同じことの直接の根拠は ESTIMATE のペアに限られ、ペアは OT の N ≥ 256 と多ランクの 1D を覆わない。
OT の N = 1024 は旧と同じく t = π までである。
λ_svv から dt を決める実行では、再開の位置で dt が変わりうるが、この Stage の試験はすべて dt を固定しているので確かめていない。

## 2. 方法

ユーザーの依頼は「1D MHD の Riemann 問題, 2D の OTを最終盤で走り直させて。」で、範囲は「N=1024 まで」とした。
Stage 3 の 1D の収束の試験（conv）は走らせていない。

入力は、生成スクリプトで作り直さず、旧のケース（`runs/stage3_f`、`runs/stage4/ot`）から複製した。
作り直すと、Stage 4 以降に増えた既定値で calliope.in の字面が変わりうるからである。
複製したのは calliope.in、nproc、case.json、profile1d.dat（1D）、ic/（OT）だけで、250 本の入力の md5 は元と一致した。
旧のディレクトリには書いていない。
始める前に `runs/stage14/.stamp` を置き、終わった後に `find runs/stage3_f runs/stage4 -newer runs/stage14/.stamp` が空であることを確かめた。

FFTW の計画は旧と同じ MEASURE とした。
MEASURE は FFT の計算法を実行時の時間計測で選ぶので、同じ入力と同じ実行ファイルでも、実行ごとに FFT の丸め誤差が変わりうる。
このため、新旧の MEASURE の実行がビット単位で一致することは期待できない。
コードが同じかどうかは、計画を ESTIMATE に固定して旧と新を走らせたペアで確かめた（P、4 章）。

## 5. 1D Riemann 問題

### 5.1 完走、試作との一致、旧との一致、分割（D1–D4）

D1–D4 はすべて合格した。

| 基準 | 新（s13d） | 旧（Stage 3、s3g） |
|---|---|---|
| D1 完走 | 207 本が complete | 207 本が complete |
| D2 試作との差の最大 | suite 3.49e-12（RDp_w0_N2048）、eta_suite 5.11e-12（C2_N4096_eta2） | suite 2.70e-12、eta_suite 4.42e-12 |
| D3 旧 Fortran との差の最大 | suite 1.03e-12（TDA_w0pre_N2048）、eta_suite 6.9e-13、decomp 6.9e-15、eta_decomp 6.2e-15 | — |
| D4 `_x_np1` との差の最大 | decomp 1.15e-14、eta_decomp 6.86e-15 | decomp 1.15e-14、eta_decomp 4.93e-15 |

D3 では、207 本のうち 56 本で旧との差が 0 だった。
残りの差は 1e-12 以下で、D2 の試作との差と同じ大きさである。

D1 のジョブ（128 コア）は 30 分の上限の中で 197 本を終え、10 本（C1、C2 の N = 4096 の 4 本と、TDA の N = 2048 の 6 本）は予算で止まった。
この 10 本は restart から続け、2 本目のジョブで終えた。
旧でも、同じ系統のケースを続けて終えていた。

### 5.2 記録の比較（D5）

D5 は不合格だった。
182 本のうち 57 本で、基準を外れる値があった。
57 本は、続けて終えた 17 本（以下 A）と、1 回の実行で終えた 40 本（以下 B）に分かれる。
A は、新旧の両方で続けた 10 本（C1、C2 の N = 4096 の 4 本と、TDA の N = 2048 の 6 本）と、旧だけが続けた 7 本である。
計画に従い、ラベルを付ける前に両方の原因を調べた。判定は FAIL のまま変えていない。

#### A: 継ぎ目の行の違い

A の差の大半は、実行の継ぎ目で .dat に書く行が新旧で違うことから生じる。

- 旧（s3g）は、予算で止まった実行の最後のステップの budget.dat の行を書かない。
- 新（s13d）はその行を書く。そのかわり、続きの実行の最初の conservation.dat の行が継ぎ目のステップを繰り返す。
- 予算で止まるステップは実行の速さで決まるので、継ぎ目の位置も新旧で違う。

D5 の基準を決めたとき、`fortran.runs` が同じなら行の数え方も同じだと仮定した。この仮定は誤りだった。
行の数（`budget.n`、`cons.n`）が違えば、行の和でとる積分（`int_*`）も変わる。

そこで、新の .dat から旧より多い行を落とした写しを `runs/stage14/seams` に作り、記録を作り直した（`analyze_stage14.py seams`）。
落とした行は、各ケースで budget.dat の 1 行と、新旧の両方で続けた 10 本の conservation.dat の 1 行だけである。
旧にあって新にない行はなく、cfl.dat には違いがなかった。
写しで作り直すと、17 本のうち 6 本は基準を満たし、残る 11 本の差は次の項目に限られた。

| ケース | 残った項目の数 | 項目と相対差の最大 |
|---|---|---|
| C1_N4096、C1_N4096_eta2、C2_N4096_eta2、TDS_w1_N2048 | 各 1 | dM/dt の比（1.1e-9–2.4e-8） |
| TDA_w0pre_N2048 | 1 | err_t の比（5.2e-8） |
| TDS_w0_N1024、TDS_w0pre_N1024 | 4、2 | λ_svv の検査の行の最大 dt λ（4.2e-4、2.2e-4）ほか |
| TDA_w1_N2048、TDA_w1pre_N2048 | 7、8 | λ_svv とそれで決まる dt の上限（9.4e-6、1.3e-5）。TDA_w1pre_N2048 は err_t の比も |
| TDA_w4_N2048、TDA_w4pre_N2048 | 12、11 | λ_svv（5.4e-7、2.7e-6）、R_ζ と R_svv の比（最大 0.21）、err_t の比（1.0e-2、2.0e-3） |

λ_svv の項目の差は、再開のたびに冪乗法の予定がやり直されるために生じる。
冪乗法のベクトルは restart ファイルに書かず、各実行の最初のステップで `svv_pi_init` = 50 回反復する（3.4 節の仕様、REPORT_stage1）。
`svv_pi_check` の間隔も実行ごとのステップ数で数えるので、精密に反復する検査のステップの集合が継ぎ目の位置で変わる。
たとえば TDS_w0_N1024 の検査の行は新が 267 行、旧が 268 行で、旧にだけ step 21845 の検査がある。
同じステップの λ_svv を cfl.dat の各行で比べると、新旧の差は最初の継ぎ目（新旧のどちらかが再開したステップ）の前後で桁が変わる（`analyze_stage14.py lam`）。
最初の継ぎ目より前では、17 本すべてで差が 3.8e-9 以下だった。
継ぎ目より後では、差は TDS の N = 1024 で 8.8e-7、C1 で 3.0e-5、TDA で 3.1e-4、C2、F2、RDpc で 3.0e-3–1.6e-2 まで広がる。
冪乗法は検査以外のステップで 1 回しか反復しないので、再開の直後の推定値は 50 回の反復の値から少しずつしか近づかない。
最大の 1.6e-2 は、REPORT_stage1 の 7.5 節の restart の試験で、λ_svv が継がない実行から相対 1.6e-2 ずれたのと同じ大きさである。
試験はすべて dt を固定しているので、この差は記録した λ_svv にだけ現れ、解には影響しない（D3 の差は 1e-12 以下）。

dM/dt、err_t、R_ζ、R_svv の比は、分子が丸め誤差で決まる量である。
たとえば TDS_w4pre_N256 の err_t の最大 3.3e-11 は、ε|E|/dt（ε は倍精度の丸めの単位）の約 240 倍で、N と同程度である。
t = 0 の dM/dt も 1.2e-12 で、εM/dt と同じ大きさになる。
FFT の計画が変われば丸め誤差の値も変わるので、これらの比が新旧で 1e-9 の相対精度で一致することは期待できない。
D5 の基準を決めたとき、これらの項目の新旧の差を MEASURE の 2 回の実行で見積もっていなかった。

#### B: 1 回の実行で終えた 40 本

B の 40 本は、新旧のどちらも 1 回の実行で終えたので、継ぎ目はない。
基準を外れた値は 40 本で計 90 個あり、15 の項目に限られた。
項目は 2 種類に分かれる。
一つは、A でも残った、分子が丸め誤差で決まる比（err_t、dM/dt、R_ζ、R_svv の比）である。
もう一つは、λ_svv とそれから求める量（F_svv、dt λ_svv、dt と上限の比、dt_visc）である。

差がコードによるのか FFT の計画によるのかを分けるため、計画に従い、40 本のうち 38 本を ESTIMATE の s3g と s13d で走らせた（`gen_stage14.py estimate`、ジョブ 488993、24 コア、10 分 57 秒、約 4.4 core-h）。
除いた 2 本（TDS_w1pre_N2048、TDS_w4pre_N2048）は 1 回の実行が 20 分を超え、ほかのケースと同じジョブに詰めると、予算で止まって続きの実行が要るおそれがあった。
続ければ継ぎ目の位置が新旧で変わり、A と同じ差が混じる。

38 組はすべて、P と同じ比較でバイト単位で一致した（各 82 ファイル。各実行の FFT の計画は 12 個か 24 個で、すべて ESTIMATE）。
したがって、計画を固定すれば、この 38 本で s3g と s13d は同じ計算をする。

次に、ESTIMATE の記録 E を、MEASURE の新 N（s13d）と旧 O（s3g）の記録と、D5 の基準で比べた（`analyze_stage14.py explain`）。
E と N、E と O の間にも、N と O の間と同じ種類の項目に、同じ大きさの差があった。
コードが同じで計画だけが違う実行の間の差（E と N、E と O）が、新旧の差（N と O）と同じ大きさなので、新旧の差は計画の違いで説明できる。

| 項目 | N と O | E と N | E と O |
|---|---|---|---|
| err_t の比 | 23 本、8.1e-2 | 21 本、9.1e-2 | 20 本、8.1e-2 |
| dM/dt の比 | 9 本、8.3e-2 | 9 本、1.0e-1 | 5 本、1.2e-1 |
| R_ζ の比（3 項目） | 4 本、4.9e-1 | 2 本、6.8e-1 | 4 本、4.8e-1 |
| R_svv の比（2 項目） | 5 本、1.8e-1 | 5 本、2.0e-1 | 5 本、2.8e-1 |
| λ_svv とそれから求める量（7 項目） | 9 本、2.2e-6 | 5 本、9.7e-7 | 5 本、1.2e-6 |
| いずれかの項目 | 38 本 | 32 本 | 31 本 |

各欄は、38 本のうち基準を外れた本数と、相対差の最大である。

4 本（C2_N1024、C2_N256、P1b_N256_eta2、RDp_w8_N1024）では、N と O の間だけで外れた項目がある。
これらの項目では、E は N と O の間の値をとり、どちらとも基準の中に収まった。
たとえば C2_N256 の λ_svv の最大は、N が 31171.118798768628、O が 31171.118760929847（相対差 1.2e-9）で、E は 31171.118787565636 である。

λ_svv の項目の相対差は最大 2.2e-6 で、解の差（D3、1e-12 以下）に比べて大きい。
これは、冪乗法が Jv を差分 (G(U + hv) − G(U))/h（h = 1e-7、`svv_power`）で求めるので、G の丸め誤差が 1/h = 1e7 倍になって Jv に入るためである。
B の試験も dt を固定しているので、λ_svv の差は記録にだけ現れる。

ESTIMATE で走らせなかった 2 本は、どちらも err_t の比の 1 項目だけが外れた（TDS_w1pre_N2048 は相対差 9.2e-8、TDS_w4pre_N2048 は 3.8e-2）。
err_t の比は、38 本で E と N の間でも 21 本が外れた項目で、その差の最大 9.1e-2 はこの 2 本の差より大きい。
ただし、この 2 本の差が計画によることは、ペアでは確かめていない。

#### D5 の原因のまとめ

D5 は事前に固定した基準なので、判定は FAIL のまま変えない。
57 本の差のうち、コードの違いによる差は見つからなかった。
A の差は、継ぎ目の行の数え方と、再開ごとにやり直す冪乗法の予定から生じた。
B の差は、38 本では FFT の計画の違いから生じたことを確かめ、残る 2 本も同じ種類の項目だけが外れた。
外れた項目は、分子が丸め誤差で決まる比と、差分で丸め誤差を 1e7 倍にする λ_svv だけである。
D5 の許容差 1e-9 を決めたとき、これらの項目が計画の違いでどれだけ変わるかを見積もっていなかった。
許容差を、計画だけが違う 2 回の実行（E と N のような組）の差から決めていれば、この誤りは避けられた。

10 ステップ後の差は、基準の 1e-12 を下回った。
分割による差は、新でも旧と同じく丸め誤差の水準にとどまった。

### 6.2 収束の判定（O3）

O3 は合格した。
新旧とも、収束の判定（`conv`）は C_η = 0、2 の両方で不合格で、不合格の項目は新旧で同じだった。

- C_η = 0（N = 512 と 1024、t = π まで）: t = 1 の k_eff の比、t = π の ρ_min
- C_η = 2（N = 256 と 512、t = 2π まで）: ε の最大値、t = 1 の a90 の比、t = 5、6、2π の k_eff の比、t = 2π の ρ_min、ρ_max、E_K、E_M

これらの項目が不合格になる理由は、REPORT_stage4 の 7.5–7.7 節に書いた。
t ≥ 4 ではプラズモイドができ、各点の量は N を上げても収束しない。

k_eff の比と a90 の比は、すべての時刻で新旧が一致した。
各実行の ζ の面積比と a90 も一致した。
判定に使う値（N の大きい 2 本の間の相対差）の新旧の差は、ε_shock の割合を除いて相対 5.3e-10 以下だった（最大は C_η = 0 の ε の最大値）。

ε_shock の割合の判定の値は、C_η = 0 で 0.0045155 と 0.0045154（新旧の相対差 2.8e-5）、C_η = 2 で 0.092377 と 0.092386（1.0e-4）と、新旧で違った。
この差は、5.2 節 A と同じ継ぎ目の行から生じる。
旧の budget.dat には、新にある次の行がない。

- N = 1024: step 2296、13386、24559（t = 0.287、1.672、3.068）
- N = 512、C_η = 2: step 13945（t = 3.912）
- N = 512、C_η = 0: step 20401（t = 5.723）

新の budget.dat からこれらの行を落として割合を求め直すと、新旧の割合の相対差は 2.1e-14 以下になった（N = 1024 では 7.2e-16）。
旧にあって新にない行はなかった。
割合の判定は、新旧とも基準の 0.10 の中にある。

### 6.3 t ≤ π の新旧の差（O4）

O4 は合格した。
7 本の t ≤ π で、相対差の最大は次のとおりである。

| 実行 | conservation.dat | 面の ρ、u、B | S4.3 のスカラー |
|---|---|---|---|
| N = 128、C_η = 0 | 1.2e-14 | 4.4e-14 | 2.6e-15 |
| N = 256、C_η = 0 | 3.0e-14 | 7.3e-14 | 2.7e-15 |
| N = 512、C_η = 0 | 5.9e-14 | 1.2e-13 | 4.0e-12（ε の最大値） |
| N = 1024、C_η = 0 | 1.5e-13 | 1.1e-12 | 1.3e-7（ε_shock の割合） |
| N = 128、C_η = 2 | 6.5e-15 | 3.3e-14 | 1.9e-15 |
| N = 256、C_η = 2 | 1.4e-14 | 2.6e-14 | 4.6e-12（ε の最大値） |
| N = 512、C_η = 2 | 4.7e-14 | 9.7e-14 | 1.9e-11（ε の最大値） |

最大は N = 1024 の ε_shock の割合の 1.3e-7 で、基準の 1e-6 を下回った。
この差は、6.2 節の継ぎ目の 3 行から生じ、行を落とすと 7.2e-16 になる。
N = 1024 のスカラーで次に大きいのは、t = π の ρ_min の 9.7e-14 である。

ε の最大値は、4 本で新旧がビット単位で一致し、3 本で 4.0e-12–1.9e-11 違った。
この差は面や conservation.dat の差より大きい。
ε は 1 ステップの E の差を dt で割った量なので、E の相対的な丸め誤差が E/(ε dt) 倍になって ε に入る。
この倍率は N = 256 で約 1.1e4、N = 512 で約 2.7e4–2.8e4 である。
3 本の差をこの倍率で割ると 1.4e-16–7.2e-16 で、倍精度の丸めの単位 2.2e-16 の 0.6–3.3 倍に当たる。

ε の最大の時刻、ζ の面積比、a90 のように、数え上げやステップの選択で決まる量は、7 本すべてで新旧が一致した。

### 6.4 t > π の新旧の差

t = π より後は、基準を置かず、差の増え方だけを見た（図 `runs/stage14/fig_s14_ot_diff.png`）。
t = 2π の面の差の最大は次のとおりである。

| N | C_η = 0 | C_η = 2 |
|---|---|---|
| 128 | 1.3e-13 | 4.2e-14 |
| 256 | 3.1e-12 | 1.3e-12 |
| 512 | 2.2e-10 | 6.7e-12 |

N = 512、C_η = 0 の面の差は、t = 0 の 5.7e-16 から t = 3 の 1.2e-13 までゆっくり増え、その後 t = 3.5 の 1.1e-12、t = 4.5 の 1.9e-11、t = 2π の 2.2e-10 と速く増えた。

## 7. 物理的な妥当性

新の解は、1D と OT の両方で、旧の解と丸め誤差の水準で一致した（D3 と O4）。
したがって、REPORT_stage3 と REPORT_stage4 の 7 章で確かめた物理的な性質は、s13d でもそのまま成り立つ。
OT の主な統計量を、新の値で示す。

| 実行 | 質量の相対誤差 | div B の最大 | dt/上限の最大 | dt λ_svv の最大 | ρ の範囲 | ε_shock の割合 | ε_η の割合 |
|---|---|---|---|---|---|---|---|
| N = 128、C_η = 0 | 1.4e-7 | 5.3e-18 | 0.84 | 1.21 | 0.189–4.07 | 0.685 | — |
| N = 256、C_η = 0 | 1.4e-7 | 3.8e-18 | 0.95 | 1.44 | 0.152–5.83 | 0.719 | — |
| N = 512、C_η = 0 | 8.9e-8 | 2.7e-18 | 0.91 | 1.30 | 0.135–7.68 | 0.732 | — |
| N = 1024、C_η = 0 | 3.6e-8 | 1.1e-18 | 0.66 | 0.95 | 0.284–4.20 | 0.930 | — |
| N = 128、C_η = 2 | 7.9e-8 | 3.4e-18 | 0.79 | 1.15 | 0.223–3.88 | 0.409 | 0.547 |
| N = 256、C_η = 2 | 7.7e-8 | 2.6e-18 | 0.85 | 1.26 | 0.186–4.40 | 0.473 | 0.486 |
| N = 512、C_η = 2 | 4.8e-8 | 1.8e-18 | 0.74 | 1.15 | 0.154–6.99 | 0.521 | 0.437 |

割合は、収支の各項の和（E の変化率）を時間で積分した値に対する比で、N ≤ 512 は [0, 2π]、N = 1024 は [0, π] でとった。
残りはほぼ ES-SVV の寄与で、たとえば N = 512、C_η = 0 では ρ、m の SVV が 0.207、B の SVV が 0.061 である。
N = 512 の 2 本の割合は、継ぎ目の行のため新旧で相対 1.6e-5、1.0e-5 違う（6.2 節）。
dt/上限は、固定した dt と各ステップの min(dt_adv, dt_visc) の比である。
dt λ_svv の最大は 0.95–1.44 で、RK3 の安定域の 2.51 を下回った。

E が増えたステップは、N = 1024 の 7 ステップ（step 5–9、11、12。t = 6.2e-4–1.5e-3）だけで、旧も同じ 7 ステップだった。
これらのステップの E の増分は 1.4e-13–3.0e-12 である。
同じステップで、収支の各項の和 dE/dt は負（−8.5e-11 から −9.9e-10）で、1 ステップの散逸は 1.1e-14–1.2e-13 にとどまる。
N = 256 の分割の試験で、分割だけを変えた実行の間の E の差は、t ≤ 0.01 で 4.5e-12–1.6e-11 だった。
E の増分はこれより小さいので、散逸がまだ小さい最初の数ステップで、E の和の丸め誤差が散逸を上回ったと判断した。
この増分は収支の残差 err_t に入り、各段の寄与の和には入らない。

OT の時間積分の誤差（実測の E の変化と、各段の寄与を RK の重みで積分した値の差）は −4.2e-5 から −1.5e-4 で、E の変化（−32 から −83）の 6.5e-7–2.5e-6 倍である。
新旧の記録で相対 1e-6 より大きく違った統計量は、丸め誤差で決まる量（運動量の誤差、div B、恒等式の残差 R_ζ、R_svv/A_svv、R_η、R_svv/D_svv）と、継ぎ目の行が違う 3 本（N = 512 の 2 本、N = 1024）の行の和でとる積分だけだった。
前者の大きさは、新で運動量の誤差が 3.7e-13 以下、div B が 5.3e-18 以下、R_ζ が 5.1e-14 以下、R_svv/A_svv が 2.3e-16 以下、R_η が 2.6e-15 以下である（REPORT_stage4 の 7.2 節と同じ水準）。
R_svv/D_svv（SVV の散逸 D_svv で割った残差）は、新の N ≥ 512 の 3 本で 0.46–0.52 になる。
この最大は最初の 2 ステップにあり、そこでは D_svv 自体が 1e-27 程度と丸め誤差の水準にある。t > 0.01 では 7 本とも 1.5e-5 以下である。
このため、判定には丸めの尺度 A_svv で割った R_svv/A_svv を使う（`analyze_stage4.svv_res_rel`）。

安定化のための density floor、圧力の floor、一様な粘性は足していない。
人工散逸の係数と設定は、Stage 3、4 の入力のままである。

## 8. 限界

- MEASURE の再実行は、旧とビット単位では一致しない。コードが同じことの直接の根拠は、ESTIMATE のペアだけである。ペアは、1D の N = 256（1 ランク）の 12 本、OT の N = 128（4 ランク）の 2 本、B の 38 本（N ≤ 2048、1–2 ランク）を覆う。OT の N ≥ 256 と多ランクの 1D のペアはない。
- 1D の試作との比較（D2）は、最終状態だけで行った。全スナップショットとの比較は、P のペアの範囲にとどまる。
- 1D の収束の試験（conv、I1 と RDpc の N = 4096、8192）は走らせていない。REPORT_stage3 の 10.6 節の結果は s3g のままである。
- OT の N = 1024 は t = π までで、C_η = 2 は走らせていない。どちらも旧と同じ範囲である。
- D5 の B のうち 2 本（TDS_w1pre_N2048、TDS_w4pre_N2048）は、ESTIMATE のペアで確かめていない。
- λ_svv の冪乗法の予定は再開のたびにやり直される（5.2 節 A）。この Stage の試験はすべて dt を固定しているので、λ_svv の差は記録にだけ現れた。dt を λ_svv から決める実行（3D 乱流の `track` など）では、再開の位置によって dt が変わりうる。この影響は確かめていない。
