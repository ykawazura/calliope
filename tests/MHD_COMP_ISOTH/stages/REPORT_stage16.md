### 2.3 時刻をそろえた K（事後の判定）

量と判定の規則は Stage 15 と同じである（Stage 15 報告の 3 章）。
T は 128³ の実行と参照のスペクトルの窓平均の比、k_× は n ≥ 3 で |ln T| が初めて ln 1.25 を超える殻、κ = k_×/k_c（k_c = 128/3）、D は [3, 32] での |ln T| の平均である。
窓は W1 = [0.75, 1.25]τ0 と W2 = [1.5, 2.0]τ0 で、128³ の記録は 0.125τ0 ごとにある。
ES-256 の記録は W1 で 0.818–1.156τ0 の 8 つ、W2 で 1.500、1.503、1.763、2.000τ0 の 4 つで、128³ の記録と時刻がそろっていない。

Stage 16 では、比をとる前に 128³ のスペクトルを ES-256 の記録の時刻にそろえた。

- 補間: 128³ の実行の窓の記録を時刻の順に並べ、先に残した記録から 1e-3τ0 以内の記録を落とす。殻ごとに ln E を t の 1 次式で補間し、ES-256 の記録の時刻 t_j での値を作る。t_j が記録の範囲から 0.01τ0 以内だけ外れるときは最も近い記録を使い、それより外れたら止める。
- κ と D: ES-256 の窓の重み w_j（和は 1）で両者の窓平均をとり、その比 T から求める。ES-256 の窓平均は、保存済みの窓平均と同じになる。
- σ: 記録ごとの比 E_X(t_j)/E_R(t_j) から κ_j を求め、その重み付きの標準偏差 σ² = Σ w_j (κ_j − κ̄)²/(1 − Σ w_j²) をとる（κ̄ = Σ w_j κ_j）。重みが等しければ、ddof = 1 の標準偏差に一致する。重みを付けたのは、ES-256 の 1.49995τ0 と 1.50264τ0 のように近い記録を、独立な標本として数えないためである。
- Δ_interp: 128³ の記録を 1 つおき（0.25τ0 ごと）にして求めた κ と、全記録で求めた κ の差の最大である。最大は、判定に入る 128³ の全実行（ES、H(8)、L(1)、L(2)）の全組でとる。補間の誤差が記録の間隔の 2 乗に比例するなら、この差は実際の誤差の約 3 倍になる。
- Δ_rerun: ES-128 と Stage 8 の対照（e0.5_C2）の、W1 での κ の差の最大である。Stage 8 の記録も同じ方法で ES-256 の時刻にそろえた。
- δ = max(2/k_c, 2 hypot(σ_ES, σ_B*), Δ_rerun, Δ_interp)。

判定の規則は Stage 15 と同じにした。
B* は、128³ の標準の散逸のうち 4 組の κ の平均が最大のものである。
「ES が優る」は、ES が δ を超えて大きい組が need 以上、B* が δ を超えて大きい組が 0、D が ES で小さい組が need 以上のときである。
参照は ES-256 だけなので、4 組のうち need = 3 とし、判定に印を付けた。
費用の規則も同じで、c_ES/c_B* < (k̄_ES/k̄_B*)⁴ のとき費用対効果があるとする（k̄ は 4 組の k_× の幾何平均）。

版は 2 つ並べた。
版 A（主な判定）は、κ、D、σ をすべて時刻をそろえて求める。
版 B（感度）は、κ、D、d を Stage 15 のままにし、σ だけを時刻をそろえた σ に替える。
版 B は κ を補間しないので Δ_interp を足さず、Δ_rerun には Stage 15 の方法の値（0.0020）を使う。
M_s = 0.5 の (64, 128) の自己収束による参考の判定と、M_s = 1 の (64, 128)、(128, 256) の報告も、同じ方法で作り直した（参照は大きい N の実行）。
(64, 128) は記録の時刻がほぼ 1e-3τ0 以内でそろうので、Δ_interp を足さない。

これらの定義は、判定を計算する前に todo.md に書いた。
しかし、Stage 15 の d（E_B W1 +0.236、E_B W2 +0.209、E_m W1 +0.248、E_m W2 −0.121）と、σ が窓の中の減衰を含んでいたことは、定義を決める前に知っていた。
版 B で「ES が優る」になるのは、前の 3 組の δ がそれぞれの d より小さく、E_m W2 の δ が 0.121 以上のときだけである。
このことも、計算の前に todo.md に書いた。
版 A では d も変わるので、結果は計算するまでわからなかった。

### 2.4 H-F による 2 本目の参照

Stage 15 では、256³ の H が H(8)、H(32) とも止まり、参照は ES-256 だけになった。
標準の散逸はすべて ln ρ のフィルタ（filter_lnrho = T）付きで走らせたので、H の崩れがフィルタによるものかは切り分けていなかった。
HF は、H の filter_lnrho を F にした方式で、係数は H と同じである。
HF も ln ρ に超拡散（lmd_h）を掛けるので、質量は保存しない。

版 A の判定が「ES が優る」だったので、計画どおり HF を段階的に走らせた。

| 段階 | 走らせるもの | 関門 |
|---|---|---|
| F1（64³） | HF(r)、r = 1/4、1/2、…、16 の 7 本 | r*_HF: その段とそれより大きい段がすべて完走する最小の r |
| F2（128³） | HF(r*_HF)、HF(2r*_HF)、HF(4r*_HF) | r_C,F: 完走する最小の段。どれも完走しなければ止まって相談する |
| F3（256³） | HF(r_C,F) を 1 本 | 途中で止まったら、設定を変えずに止まって相談する |

F3 が完走すれば、ES-256 と HF-256 の 2 本の参照で判定する予定だった（8 組、need = 6。Stage 15 の元の規則）。
上限は 500 core-h とした。

したがって、Stage 3 の未解決の問題（C_η = 2 の解と FV の解の差が、極限の違いによるのか、前漸近的な振る舞いなのか）は、この Stage でも残る。

## 4. 時刻をそろえた K

### 4.1 補間の確かめ

- ES-256 の時刻にそろえた ES-256 の窓平均は、保存済みの窓平均と相対 4.2e-16 で一致した。

### 4.4 σ が小さくなった理由

Stage 15 の σ は、各記録のスペクトルを参照の窓平均と比べた κ_j から求めていた。
窓の端の記録では、窓の中の減衰のためにスペクトルが窓平均からずれた。

時刻をそろえると、κ_j は同じ時刻の ES-256 と比べた値になり、窓の中の減衰は比に入らない。
σ は、ES で 0.005–0.012（E_m の W2 は 0.075）、H(8) で 0.014–0.023（E_m の W2 は 0.212）に下がった。
図 `runs/stage16/fig_s16_kappa_t.png` に、ES と H(8) の κ_j を時刻に対して、Stage 15 の値と並べて描いた。

E_m の W2 に残る σ は、2.0τ0 の記録で両方式の κ_j が下がることによる。
1.500、1.503、1.763、2.000τ0 の κ_j は、ES で 0.466、0.465、0.422、0.305、H(8) で 0.552、0.552、0.559、0.162 である。

## 6. out3d の記録の抜け

共通の主プログラム `src/calliope.F90` の `check_write_now`（182–192 行）は、floor(t/intvl) と floor((t + dt)/intvl) が違うときに書き出しを決める。
主ループでは `solve` の後に呼ばれ、dt は終わったばかりの step の値である。
次の step の dt は、次の `solve` の Runge–Kutta の 1 段目で CFL から決まる。
そのため、dt が増える step で書き出しの境界をまたぐと、書き出しが抜ける。

HF(8)-128 では、t = 5.49663 で直前の dt = 1.14e-3 から見込んだ時刻 5.49777 が、境界 14π/8 = 5.497787 に 1.7e-5 届かなかった。
次の step は dt = 1.30e-3 で 5.49793 に進んだので、境界をまたいだ step で書かなかった。
2.0τ0 に 2 つある記録のうち後の 1 つは、ループの後の最後の書き出しで、時刻をそろえる補間では落とす（1e-3τ0 以内）。

窓の重みと時刻をそろえる補間は記録の抜けを扱えるが、抜けた区間では補間の間隔が 2 倍になる（5.3 節）。
直すには、書き出しの判定を次の step の dt が決まった後に行うなど、全モデルに共通の主プログラムの変更が要る。
Stage 16 では Fortran を変えないので、直していない。

## 10. 物理的な妥当性

時刻をそろえる補間は、殻ごとの ln E を 0.125τ0 の間で 1 次式とみなす。
減衰乱流のスペクトルはこの間隔で滑らかに変わるので、補間の誤差は小さい。
実際に、間隔を 2 倍にしたときの κ の差（Δ_interp）は最大 0.012 で、殻 1 つ分の 1/k_c = 0.023 より小さい。

版 A で ES と H(8) の差を決めたのは、3 組とも高波数のスペクトルの違いである。
H(8) の窓平均のスペクトルは n = 21–23 で ES-256 の 0.8 倍を下回り、ES は n = 31–32 まで 0.8 倍以上にとどまる。
これは、H(8) の散逸が k_c(128) = 42.7 より手前の波数に掛かることと整合する。
H の減衰率をその波数の渦の速さで割った値は r (k/k_c)^{22/3} で（Stage 15 報告の 9 章）、H(8) では k = 21 で約 0.04、k = 32 で約 0.97 である。
一方、ES の E_m は W2 で n = 19–30 に ES-256 を上回り、最大は n = 26–27 にある。
最大の位置は、SVV が掛かり始める |k_d| > 0.5k_c(128) = 21.3 より上で、Stage 15 で見た n ≈ 27 の超過と同じである。
この超過の原因は調べていない。

HF(8)-256 の崩れは、密度の穴で dt が ρ_min とともに下がる型で、H(8)-256 と同じである（5.2 節）。
安定化のための density floor、圧力の floor、一様な粘性は足していない。
HF は 2 本目の参照として走らせたもので、ES の係数は Stage 6 以来の既定値（svv_eps0 = 0.5、C_shock = 2）のままである。
止まった HF(8)-256 は係数を上げて通さず、5.2 節で崩れの型を調べた。

## 11. 限界

- K の判定は事後の判定である。定義は Stage 15 の d と σ の欠陥を知った後に決めた。
- 256³ の参照は ES-256 の 1 本だけである。H(8)、H(32)、HF(8) の 256³ はどれも止まった。参照が ES と同じ方式なので、K の判定は ES に有利な側にずれうる。
- 時刻をそろえた比較は、ES-256 の記録の時刻だけで行う。W1 では 0.818–1.156τ0 の記録しかないので、窓の端（0.75–0.82τ0、1.16–1.25τ0）は比べていない。
- 実現は 1 つ（seed は 1 つ）で、減衰乱流だけを扱った。
- 費用対効果の規則は、B* が高い解像度でも同じ κ で走れることを仮定するが、H(8) は 256³ で完走しなかった。
- M_s = 0.5 の判定は (64, 128) の自己収束による参考にとどまる。
- 2.0τ0 の E_m の中間の殻の超過（4.4 節）と、ES の E_m の W2 の n = 19–30 の超過の原因は調べていない。
- conv の次数の解釈（Stage 3 からの未解決の問題）は、この Stage では決めていない。
- HF も ln ρ に超拡散を掛けるので、HF は「ln ρ に散逸を掛けない H」ではない。
