## 1. 結論

- 事前に固定した基準（5 章）での判定は「中間」である。次の手として、svv_eps0 と C_shock を変えた計算で係数への依存を確かめること（手順 3）を提案する。手順 3 には計算ノードのジョブが要るので、この Stage では実行していない。
- 密度 PDF の本体は N によらない。1τ0 の s = ln ρ の標準偏差 σ_s は、64³、128³、256³ で 0.366、0.387、0.399 だった。N による違いが大きいのは低密度の裾で、1τ0 の体積比 F_V(ρ < 0.2) の 256³ と 128³ の比は 1.36 だった。128³–256³ の組の裾は、6 時刻のうち 2 時刻で「収束」、4 時刻で「中間」と判定され、総合は「中間」になった。
- 256³ で解析した 36 個の穴のうち、理想 MHD の機構で説明できない（数値由来の疑いがある）ものは 12 個（33%）で、「多い」の基準（半数以上）に届かなかった。格子の奇偶振動のある穴はなかった。
- ただし、ρ_min を決める各時刻の最小点に限れば、256³ の 9 時刻のうち 6 時刻（0.818–1.0τ0 のすべて）で疑いに入る。この数え方は基準にないので判定には使わない。これで数えると「多い」に当たり、次の手は手順 3 に ES-SVV の最小値原理の見直しを加えたものになる。どちらで数えても手順 3 は要る。
- 最も深い穴（0.893–0.921τ0、ρ = 0.011–0.021）は、曲率幅がどの方向にも 0.6–1.0 セルで、|B| が周りの 1.5 倍あり、全圧が周りより高い（Π = −0.52 から −0.86）。この穴では −div m が ρ を下げ、SVV の項が ρ を上げて、2 つがほぼ打ち消している。

## 2. 問い

Stage 6 で、turb1 の ρ_min（conservation.dat の全時刻での最小）は 64³ で 0.085、128³ で 0.057、256³ で 0.0090 と、解像度を上げるほど下がった（REPORT_stage6 の 8.7 節）。
256³ では、この穴のために dt が 1/10 に縮んだ。

この Stage では、この穴が次のどちらに当たるかを判別する。

- 物理的な構造: 理想 MHD の機構（全圧のつり合い、磁力線に沿った排出、磁場に垂直な膨張）で説明でき、ILES では散逸のスケール、つまり格子幅まで細くなる。
- 数値由来の構造: スキームが作った構造で、理想 MHD の機構では説明できない。

判別の結果で、次に手順 3（係数を変えた再実行）、手順 4（物理粘性の DNS との比較）、ES-SVV の見直しのどれに進むかを決める。
ユーザーが承認したのは、ジョブの要らない 2 つの手順（密度 PDF の裾の比較と、穴の周りの圧力のつり合いの解析）だけである。

## 4. 方法

新規の `tests/MHD_COMP_ISOTH/analyze_stage7.py` で解析した。
サブコマンドは selftest、tail、hole、judge の 4 つで、依存するのは numpy と matplotlib（どちらも ps1 にある）だけである。
selftest は、回転させた異方的なガウス型の穴の曲率幅と主軸、合成した場での Π、Λ、χ_∥、D_∥、D_⊥、周期境界をまたぐ局所最小の数え方と穴の選び方、13 方向の断面、奇偶振動の判定、帯域の mask の 12 項目を確かめ、すべて通った。
解析は ps1 のログインノードで 64³、128³、256³ の順に回し、手元には JSON と PNG だけを持ち帰った。

### 4.1 密度 PDF の裾（tail）

各スナップショットで次の量を求めた。

- ρ_min、ρ_max、σ_s、s の体積で重みを付けた PDF（幅 0.1）
- θ ∈ {0.5, 0.3, 0.2, 0.1, 0.05, 0.03, 0.02} ごとの体積比 F_V(ρ < θ)、質量比 F_M(ρ < θ)、セル数 n(ρ < θ)
- 局所最小（周期境界で 26 近傍より低い点）のうち、ρ < 0.2、0.1、0.05 のものの数

### 4.2 穴の構造と圧力のつり合い（hole）

256³ の 0.5–1.0τ0 の 9 時刻と、64³ と 128³ の 0.5τ0 と 1τ0 で、全体の最小点と、ρ < 0.1 の局所最小のうち深い順に 4 つ（互いに 8 セル以上離れたもの）を穴として取った。
64³ と 128³ では、どの時刻も穴は最小点の 1 つだけになった。128³ の 1τ0 には ρ < 0.1 の局所最小が最小点を含めて 4 つあるが、残りの 3 つはどれも最小点から 8 セル以内にある。

穴の点 x0 で次の量を求めた（b̂ = B/|B| は x0 での値）。
長さは格子間隔 Δx = 2π/N を単位にしたセル数で示す（箱の一辺は 2π）。

- 速度の発散 D = ∇·u と、その分解 D_∥ = b̂b̂:∇u、D_⊥ = D − D_∥（スペクトル微分）
- 局所の背景: x0 から 4–8 セルの球殻での中央値（ρ_bg、P_B,bg、P_tot,bg、(|B|/ρ)_bg）。穴の深さは ρ_bg/ρ(x0) とする。
- 形: s の Hessian（3×3×3 近傍の差分）の固有値 λ_i から求めた曲率幅 w_i = sqrt(2/λ_i) と、最も細い軸 n̂。ρ < sqrt(ρ_min ρ_bg) で x0 につながる領域（26 近傍）のセル数と主軸の長さ。
- 指標 Π = (P_tot,bg − P_tot(x0)) / (P_th,bg − P_th(x0))
  - 0 なら全圧がつり合う。1 なら P_B が平らで、熱圧の窪みが補われていない。負なら P_B の盛り上がりが熱圧の窪みより大きく、全圧が周りより高い。
- 指標 Λ = (|B|/ρ)(x0) / (|B|/ρ)_bg
  - 理想 MHD では、流体素片に沿って d ln(|B|/ρ)/dt = D_∥ が成り立つ。磁場に垂直な膨張だけで穴ができたなら Λ ≈ 1、磁力線に沿った排出だけなら Λ ≈ 深さになる。
- 指標 χ_∥ = ln(ρ_bg,∥/ρ(x0)) / (Δu_∥/2c_s)
  - Δu_∥ は b̂ に最も近い格子方向の ±4 セルでの u_∥ = u·b̂ の差、ρ_bg,∥ はその 2 点の ρ の平均である。等温の対称な希薄波なら 1 になる。磁力線に沿う 1 次元の運動にはローレンツ力が効かないので、この比較は理想 MHD で厳密である。
- 深さの帯域の内訳: s = s_L + s_M + s_H と分け、各帯域の (s_b(x0) − 球殻の中央値)/(s(x0) − 球殻の中央値) を求めた。L は全方向で |k_d| ≤ m_N k_c,d、M は 2/3 mask の内側で L 以外、H は 2/3 mask の外側である（`svv3d.SVV` と同じ方向ごとの定義）。コードは s に mask をかけない（filter_lnrho = F）ので、s には H の成分がある。
- 格子の奇偶振動: 3 軸の ±8 セルの断面で、s の 2 階差分の符号が 4 回以上続けて交互に変わるかを見た。
- 穴の点の dρ/dt の内訳: −div m と SVV の項（A_L と A_H の部分）。`svv3d.SVV` の eps と tend を out3d の状態に当てて求めた。

### 4.3 N の比較と時間の追跡

- 0.5τ0 と 1τ0 で、256³ の各穴について、64³ と 128³ の同じ位置から粗い格子の 2 セル以内にある ρ の最小値を求めた。細い軸に近い格子方向に沿った ρ の断面も、3 つの N で重ねた。
- 256³ では、隣り合うスナップショットの間で最小点の移動距離と |u|Δt を比べ、前の時刻の ρ を今の最小点で読んで、同じ穴かどうかを見た。

## 5. 事前に固定した判定の基準

次の基準は計画の段階（結果を見る前）に固定し、`tasks/todo.md` に記録した。
判定はこの基準だけで行い、後から変えていない。

- 密度 PDF の裾（N の組と時刻ごとに、粗い格子で n ≥ 100 の θ だけを使う。F は体積比 F_V で判定し、F_M は併記する）
  - 収束: 使える θ のすべてで |F_fine/F_coarse − 1| ≤ 0.25。かつ細かい格子で ρ < ρ_min,coarse のセルが 100 個以下。
  - 太る: θ ≤ 0.2 の 2 つ以上で F_fine/F_coarse ≥ 1.25。
  - どちらでもなければ中間とする。
  - 組の総合は、どれかの時刻で太れば「太る」、全時刻で収束すれば「収束」、それ以外は「中間」とする。
- 穴の機構（穴ごと）
  - 全圧のつり合い: |Π| ≤ 0.3
  - 磁力線に沿った排出: |D_∥| ≥ |D_⊥|、Λ が深さの 0.5–2 倍、χ_∥ ∈ [0.5, 2]
  - 垂直な膨張: |D_⊥| > |D_∥|、Λ ∈ [0.5, 2]
  - 上のどれにも当たらない穴と、奇偶振動のある穴は、理想 MHD の機構で説明できない（数値由来の疑い）とする。
  - 「疑いのある穴が多い」は、256³ で解析した穴の半数以上とする。
  - 帯域の内訳と、粗い格子に対応する穴があるかは、解釈の補助として報告し、判定には使わない。ILES では物理的な構造も格子幅まで細くなるためである。
- 次の手の対応（報告で提案するだけで、この Stage では実行しない）
  - 裾が収束し、穴が理想 MHD の機構で説明できる場合: 穴は散逸のスケールまで細くなった物理的な構造である。ρ_min は ILES では収束しない量として扱い、手順 4（DNS 参照）か、256³ を上限とする運用を検討する。
  - 裾が太るか、疑いのある穴が多い場合: 手順 3 と、ES-SVV の最小値原理の見直しに進む。
  - 中間の場合: 手順 3 で係数への依存を確かめる。

### 6.3 穴の機構の集計

| N | 穴の数 | 全圧のつり合い | 磁力線に沿った排出 | 垂直な膨張 | 奇偶振動 | 数値由来の疑い |

| 64³ | 2 | 0 | 0 | 0 | 0 | 2 |
| 128³ | 2 | 1 | 0 | 0 | 0 | 1 |
| 256³ | 36 | 24 | 2 | 0 | 0 | 12（33%） |

256³ の 2 つの排出の穴は、全圧のつり合いにも当たる。
36 個の穴に共通する性質は次のとおりである。

- 最も細い軸 n̂ と b̂ のなす角は 70–90°（中央値 83°）で、穴は磁力線に沿って延びている。
- Λ/深さは 1.00–1.54（中央値 1.12）で、すべての穴で排出の Λ の条件を満たし、垂直な膨張の条件（Λ ∈ [0.5, 2]）は満たさない。磁場に垂直な膨張だけでできた穴はない。
- χ_∥ が [0.5, 2] に入る穴は 4 個だけで、16 個は負、16 個は 2 を超えた。排出の条件を満たさない理由の多くは χ_∥ である。

疑いの 12 個は、どれも |Π| > 0.3 で全圧がつり合っておらず、排出と垂直な膨張の条件も満たさない。
12 個のうち 5 個は Π < −0.3（全圧が周りより高い）、7 個は Π > 0.3（熱圧の窪みが補われていない）である。

この穴の性質は次のとおりである。

- 曲率幅はどの方向にも 0.6–1.0 セルである。ρ < sqrt(ρ_min ρ_bg) の領域は、0.893τ0 で 76 セル、主軸の半長 13.1/2.2/1.1 セルで、最長軸と b̂ のなす角は 15° である。磁力線にほぼ沿った長さ約 26 セルの筋になっている。この領域は 0.921τ0 には 12 セルに縮んだ。
- |B| は周りの 1.45–1.52 倍で、Π = −0.52 から −0.86 と全圧が周りより高い。図 `fig/stage7_balance.png` に 0.893τ0 の断面を示す。n̂ に近い方向（左、n̂ から 25°）では熱圧が窪み、磁気圧がそれ以上に盛り上がって、全圧は x0 で極大になる。b̂ に近い方向（右、b̂ から 5°）でも、全圧は x0 の近くで極大になる。
- D > 0 で穴は膨らんでおり、D_∥ が D_⊥ より大きい。Λ = 69–132 は、理想 MHD の関係では、穴の流体素片が周りより ln Λ ≈ 4.2–4.9 だけ多く磁力線に沿って伸びたこと（∫D_∥dt の差）に当たる。
- −div m が ρ を下げ（−2.9 から −5.4）、SVV の項が ρ を上げて（+3.3 から +4.9）、2 つがほぼ打ち消している。0.9065τ0 と 0.921τ0 では、SVV の項の大部分が A_H の部分（+4.8、+5.1）で、A_L の部分は +0.07 と −0.98 だった。深さのうち H の帯域の割合は 0.14–0.21 である。
- 0.965τ0 には、この穴のあった位置の ρ は 1.23 に戻っていた。

0.965τ0 の最小点は、Π = +0.88、D = −14.3 で、熱圧の窪みが補われないまま圧縮され、埋まりつつある穴である。
1.0τ0 の最小点は、D_⊥（+15.5）が D_∥（+1.1）より大きいが、Λ = 37 なので垂直な膨張の条件を満たさない。

### 6.5 N の比較と時間の追跡

図 `fig/stage7_hole.png` に、256³ の最小点を通る ρ の断面を 3 つの N で重ねて示す。

- 0.5τ0 の 256³ の最小点（全圧のつり合い、w = 2.1/3.6/7.2 セル、深さの L の割合 0.97）は、3 つの N で同じ位置にある。その位置から粗い格子の 2 セル以内の ρ の最小値は、64³ で 0.466、128³ で 0.272、256³ で 0.152 で、N を 2 倍にするごとに 1.71 倍、1.79 倍深くなった。
- 1τ0 の 256³ の最小点 (69, 18, 6)（ρ = 0.042）には、粗い格子に対応する穴がない。同じ位置から 2 セル以内の ρ の最小値は、128³ でも 64³ でも 0.33 だった。
- 1τ0 の 256³ の 2 番目の穴 (160, 44, 14)（ρ = 0.054）では、同じ位置から 2 セル以内の ρ の最小値が 128³ で 0.132、64³ で 0.216 だった。128³ の最小点（ρ = 0.093）は、この穴から 256³ のセルで 15.6 離れている。

256³ の最小点は、0.893–0.921τ0 の同じ穴を除き、隣り合うスナップショットの間で別の穴に移った。
移動距離は 47–120 セルで、|u|Δt（1.6–18 セル）の 2.6 倍以上である。

## 7. 判定と次の手の提案

### 7.1 判定

- 裾: 128³–256³ の組の総合は「中間」である（6.2 節）。
- 穴: 256³ の疑いのある穴は 36 個のうち 12 個（33%）で、「多い」（半数以上）に当たらない（6.3 節）。
- 対応: 「中間」の行に当たり、次の手は手順 3（係数への依存を確かめる）である。

### 7.2 判定に使わなかった観察

次の 4 点は事前の基準にない数え方や量で、判定には使っていない。
判定の読み方に関わるので、ここに記録する。

1. 裾の基準の検出力: 粗い格子で n ≥ 100 になる θ は、どの時刻も 0.2 以上だった。128³ の 1τ0 で n(ρ < 0.1) は 9 個である。そのため「太る」（θ ≤ 0.2 の 2 つ以上で比 ≥ 1.25）は、この 3 つの N では成り立ちえず、裾の判定は「収束」か「中間」にしかならなかった。1τ0 の θ = 0.1 の比は 2.3 だが、128³ の 9 個のセルによる値である。
2. 最小点だけで数えた場合: ρ_min を決める 256³ の各時刻の最小点は、9 時刻のうち 6 時刻で疑いに入る（6.4 節）。これで「多い」を数えると、次の手は手順 3 に ES-SVV の最小値原理の見直しを加えたものになる。
3. 基準が瞬間の値で判定すること: Λ/深さは |B|(x0)/|B|_bg に等しく、すべての穴で 1 以上だった。穴の |B| は周りと同じかそれより強く、磁場の強さを保ったまま質量が抜けたことと矛盾しない。一方で、排出の条件の χ_∥ はその時刻の速度で判定するので、過去に排出されて今は流れの止まった穴は排出に当たらない。全圧がつり合わずに動いている途中の穴も、疑いに入る。疑いの 12 個のうち 8 個（最小点の 6 個はすべて）では、全圧の偏りの向きと D の符号が合っていた（全圧が高ければ D > 0、低ければ D < 0）。また Λ からは、質量が磁力線に沿った流れで抜けたのか、ρ と m にだけ働く散逸で抜けたのかを区別できない。
4. SVV の項の符号: 256³ の 36 個の穴のうち 17 個で、SVV の項が穴の点の ρ を下げていた。そのうち 15 個では −div m が ρ を上げていた。最も深い 3 時刻（0.893–0.921τ0）では逆に、SVV の項が ρ を上げている。ES-SVV の A_L の部分は、質量の流束を t = Q∂w + u·Q∂u（w = c_s² s − u²/2、Q∂ は SVV の核をかけた微分）に比例させて作る。Q を恒等にした連続の形では t = c_s²∂s となって ρ の拡散になり、局所最小を持ち上げる。Q をかけた形では Q∂(u²/2) と u·Q∂u が一致しないので t は c_s²Q∂s に等しくならず、高域通過の核 Q も最小値を保つ演算子ではない。そのため、局所最小で ρ を下げることがありうる。この機構はまだ確かめていない。

### 7.3 次の手の提案

手順 3 は計算ノードのジョブが要るので、実行の前にユーザーの承認を得る。
次の 2 段を提案する。

- 3a（128³、ジョブ 1 本）: svv_eps0 ∈ {0.25, 1.0} と C_shock ∈ {1, 4} の 4 ケースを、ほかは turb1 と同じにして 0 から 1.2τ0 まで回す。128³ の 'track' は 3τ0 を 12,052 step、0.098 s/step（128 rank）で進んだ。1.2τ0 なら 1 ケースが約 8 分の見込みで、svv_eps0 = 1.0 で dt が半分になっても 16 分に収まる。4 ケースを 2 ノード（512 rank）の 30 分のジョブ 1 本で回せる（約 256 core-h）。
- 3b（256³、3a の結果を見てから）: restart のコピー `stage6q/ana/c256_t1817`（0.578τ0）から、svv_eps0 か C_shock を変えて 1.0τ0 まで回す。基準の係数ではこの区間に 16,871 step、約 3.0 h（1 ノード、30 分のジョブ 7 本、約 770 core-h）かかった。係数で dt が変わるので、1 ケースあたり 7–14 本の見込みである。

3 の判定の基準（ρ_min と ρ < 0.1 の局所最小の数の係数への依存、SVV の項が ρ を下げる穴の割合など）は、実行の前に決めて記録する。
ES-SVV の最小値原理の見直しは設計の変更になるので、3 の結果とあわせてユーザーと相談する。
